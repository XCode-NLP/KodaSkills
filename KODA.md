# KodaSkills — репозиторий агентских навыков

## Обзор проекта

**KodaSkills** — это официальная коллекция переиспользуемых навыков (skills) для AI-ассистента [Koda](https://kodacode.ru).
Каждый навык представляет собой директорию с обязательным файлом `SKILL.md` и YAML frontmatter, содержащим инструкции для модели на конкретную тему или задачу.
Помимо `SKILL.md` директория навыка может содержать дополнительные файлы: скрипты, справочные материалы и статические ресурсы.

Репозиторий совмещает в себе:
- **Библиотеку навыков** — директория `skills/` с навыками.
- **Генератор метаданных** — Python-скрипт `generator.py`, который собирает метаданные из всех `SKILL.md` и файлов навыков и формирует `metadata.json`.
- **CI/CD автоматизацию** — GitHub Actions workflow для автоматического обновления `metadata.json` при изменениях.

## Технологии и архитектура

- **Язык генератора:** Python 3.11+
- **Зависимости:** `pyyaml>=6.0`, `jsonschema>=4.20`
- **Формат навыков:** Markdown с YAML frontmatter
- **Схема метаданных:** JSON Schema (`metadata-schema.json`)
- **Автоматизация:** GitHub Actions, Makefile
- **Форматирование:** EditorConfig (`.editorconfig`)

### Структура репозитория

```
.

```

### Формат SKILL.md

Каждый навык содержит YAML frontmatter с обязательными полями:

```yaml
---
name: skill-name              # Идентификатор в kebab-case, 1–64 символов
description: "Описание"       # Когда срабатывает навык, 1–1024 символа
license: MIT                  # Лицензия (опционально)
compatibility: "Требуется Python 3.11"  # Требования к окружению, до 500 символов (опционально)
allowed-tools: "read_file grep_search"  # Разрешённые инструменты через пробел (опционально)
metadata:
  author: koda                # Автор
  version: "1.0.0"            # Версия
---
```

Имя навыка должно совпадать с именем его директории.
Дополнительные файлы навыка располагаются рядом с `SKILL.md` и указываются в инструкциях относительными путями от корня навыка.

Все необязательные поля frontmatter (`license`, `compatibility`, `metadata`, `allowed-tools`) попадают в объект навыка в `metadata.json`. В карту `metadata` включаются только строковые значения; версия навыка хранится там как `metadata.version`, отдельного поля `version` на уровне навыка нет. Некорректное необязательное поле пропускается с предупреждением и не отбрасывает навык.

Подробная спецификация здесь: https://agentskills.io/specification

## Сборка и запуск

### Подготовка окружения

```bash
make install
```

Создаёт виртуальное окружение `.venv`, обновляет `pip` и устанавливает зависимости из `requirements.txt`.

### Генерация metadata.json

```bash
make metadata
```

Запускает `generator.py`, который:
1. Находит директории навыков `skills/*/` (только первый уровень вложенности). Директория считается навыком только при наличии `SKILL.md`; директории без этого файла пропускаются и не попадают в метаданные.
2. Парсит YAML frontmatter из каждого `SKILL.md`: проверяет обязательные поля и переносит необязательные (`license`, `compatibility`, `metadata`, `allowed-tools`) в объект навыка.
3. Собирает все файлы директории навыка, включая `SKILL.md` и дополнительные файлы.
4. Для каждого файла считает `sha256`, размер `size`, дату последнего изменения `lastUpdate` и хэш коммита `revision` (из истории Git, с откатом на время изменения файла для даты).
5. Формирует `metadata.json` со списком навыков и массивом `files`. В записи файла `name` — имя файла без пути, `path` — директория относительно `skills/` без имени файла, а `url.web` и `url.raw` привязаны к коммиту `revision`.
6. Проверяет результат по схеме `metadata-schema.json` перед записью.

Даты, ревизии и содержимое файлов берутся из Git, поэтому в CI используется полная история (`fetch-depth: 0`). Метаданные описывают закоммиченное состояние: незакоммиченные правки попадут в `metadata.json` только после коммита. Для файлов, которых ещё нет в Git, используются рабочая копия и ветка `main`, а поле `revision` не заполняется.

### Очистка окружения

```bash
make clean
```

Удаляет виртуальное окружение `.venv`.

### Ручной запуск генератора

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python generator.py
```

Переменная окружения `REPO_URL` позволяет переопределить URL репозитория (по умолчанию `https://github.com/XCode-NLP/KodaSkills`).

### CI/CD

При пуше в ветку `main` или слиянии Pull Request срабатывает workflow `.github/workflows/update-metadata.yml`:
1. Клонирует репозиторий с полной историей (`fetch-depth: 0`) — она нужна для дат последних коммитов в метаданных файлов.
2. Устанавливает Python 3.11 и зависимости.
3. Запускает `generator.py`.
4. Если `metadata.json` изменился, создаёт коммит от имени `github-actions[bot]` и пушит обратно.

## Правила разработки

### Добавление нового навыка

1. Создать директорию `skills/<имя-навыка>/`.
2. Добавить файл `SKILL.md` с корректным YAML frontmatter. Без `SKILL.md` директория не считается навыком и не попадает в `metadata.json`.
   - `name`: только строчные буквы, цифры и дефисы; без заглавных букв, без двойных дефисов, без дефисов в начале/конце; имя должно совпадать с именем директории.
   - `description`: чётко описывать, когда навык срабатывает.
3. При необходимости добавить дополнительные файлы: `scripts/`, `references/`, `assets/` и любые другие. Они автоматически попадут в `metadata.json`.
4. Убедиться, что frontmatter валиден — `generator.py` пропускает файлы с некорректными или отсутствующими полями `name` и `description`.
5. После пуша в `main` `metadata.json` обновится автоматически.

### Форматирование

- `.editorconfig` требует:
  - `charset = utf-8`
  - `end_of_line = lf`
  - `insert_final_newline = true`
  - `indent_style = space`, `indent_size = 4` (для общих файлов)
  - `indent_size = 2` (для `*.yml`, `*.yaml`)
  - `indent_style = tab` (для `Makefile`)

### Тестирование

Явных тестов в репозитории нет. Корректность работы проверяется запуском `make metadata`: генератор автоматически валидирует полученный `metadata.json` по схеме `metadata-schema.json` и завершается с ошибкой при несоответствии.

## Использование навыков

Навыки предназначены для установки в продукты Koda:

| Продукт                   | Путь установки                          |
|---------------------------|-----------------------------------------|
| Плагин (VSCode/JetBrains) | `.koda/skills/<имя_навыка>/SKILL.md`    |
| CLI                       | `.kodacli/skills/<имя_навыка>/SKILL.md` |
| Универсальный             | `.agents/skills/<имя_навыка>/SKILL.md`  |
| Глобально (все проекты)   | `~/.koda/skills/<имя_навыка>/SKILL.md`  |

После установки навык необходимо активировать через интерфейс продукта (панель «Навыки» в режиме Агент или команды `/skill enable` / `/skill reload` в CLI).

## Ключевые файлы

| Файл                                    | Назначение                                                                                     |

| `Makefile`                              | Команды: `install`, `metadata`, `clean`, `help`                                                |

| `.github/workflows/update-metadata.yml` | CI workflow для автокоммита обновлённого `metadata.json`                                       |
