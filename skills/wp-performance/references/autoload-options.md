# Автозагружаемые опции

Автозагружаемые опции загружаются при *каждом запросе*, поэтому большие объёмы автозагрузки
вредят производительности всего сайта.

## Быстрые проверки

- Общий объём автозагрузки в байтах:
  - `wp option list --autoload=on --format=total_bytes`
- Найти самые крупные автозагружаемые опции:
  - `wp option list --autoload=on --fields=option_name,size_bytes | sort -n -k 2 | tail`

Документация:

- `wp option list`: https://wpcli.dev/docs/option/list
- в `wp doctor` есть проверка `autoload-options-size`:
  - https://make.wordpress.org/cli/handbook/doctor-default-checks/

## Шаблоны исправления

- Перестань автозагружать большие блоки данных:
  - храни большие данные в опциях без автозагрузки (`autoload=off`);
  - переноси большие вычисляемые данные в транзиенты и объектный кэш.
- Удаляй устаревшие опции, оставшиеся от удалённых плагинов и тем (осторожно: перед удалением
  убедись, что они не используются).
