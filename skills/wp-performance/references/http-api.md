# HTTP API (удалённые запросы)

Используй этот файл, когда профилирование показывает медленные внешние запросы (`wp_remote_get`
и т.п.).

Шаблоны исправления:

- добавь таймауты и быстрое завершение при ошибке;
- кэшируй ответы там, где уместно (транзиенты, объектный кэш);
- объединяй запросы в пакеты и не обращайся к удалённым API при каждой загрузке страницы;
- по возможности выноси тяжёлую удалённую работу в асинхронную обработку (cron, очередь).

Инструменты:

- Query Monitor умеет показывать вызовы HTTP API (включая время) через данные конверта REST.
