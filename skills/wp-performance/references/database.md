# Производительность базы и запросов

Используй этот файл, когда профилирование указывает на время базы или большое число запросов.

Частые исправления:

- избегай шаблонов N+1 (пакетные запросы, предварительный прогрев кэшей, отсутствие поиска по
  каждой строке отдельно);
- предпочитай `fields => 'ids'`, когда нужны только идентификаторы;
- по возможности избегай дорогих запросов к метаданным; рассмотри индексы или изменения схемы;
- используй объектное кэширование для повторяющихся чтений.

Инструменты (только бэкенд):

- Query Monitor (заголовки и конверт REST) для списков запросов и трассировок стека;
- `wp db query` для точечного SQL и `explain` (осторожно в рабочем окружении).

Ссылки:
