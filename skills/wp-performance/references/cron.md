# Производительность WP-Cron

Используй этот файл, когда cron вызывает пики или замедляет обработку запросов.

Инструменты для работы только с бэкендом:

- `wp cron test` — здоровье запуска задач;
- `wp cron event list`;
- `wp cron event run --due-now`.

Ссылка:

- Пакет команд cron для WP-CLI: https://github.com/wp-cli/cron-command

Шаблоны исправления:

- устраняй дубликаты запланированных событий и по возможности снижай частоту;
- следи, чтобы задачи были идемпотентными и короткими;
- выноси тяжёлую работу из обработки запроса: cron, выполняющийся при загрузке страницы, вредит
