# Query Monitor (без интерфейса, только бэкенд)

Query Monitor изначально ориентирован на интерфейс, но умеет отдавать полезные данные
инструментам, работающим только с бэкендом.

## Что он показывает

Query Monitor помогает отлаживать:

- запросы к базе (медленные, дубликаты, ошибки), хуки и действия, вызовы HTTP API, ошибки PHP.

Страница плагина:

- https://wordpress.org/plugins/query-monitor/

Константы конфигурации:

- https://querymonitor.com/help/configuration-constants/

## Запросы к REST API (браузер не нужен)

Query Monitor умеет добавлять сведения о производительности и ошибках в аутентифицированные
ответы REST.

Документация:

- https://querymonitor.com/wordpress-debugging/rest-api-requests/

Подход на верхнем уровне:

1. Пройди аутентификацию (nonce или пароль приложения).
2. Сделай запрос REST и посмотри заголовки ответа, например `x-qm-overview-*`.
3. Если запросить ответ в конверте (`?_envelope`), можно получить свойство `qm` с:
   - подробностями запросов к базе, статистикой кэша, подробностями вызовов HTTP API и т.п.

## Ограничения

- Query Monitor даёт накладные расходы; не включай его в рабочем окружении без согласования.
- Если его уже установила платформа (например, VIP), может понадобиться выдать право
  `view_query_monitor`.
