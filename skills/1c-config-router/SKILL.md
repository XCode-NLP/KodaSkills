# /1c-config-router - Маршрутизатор задач 1С

Определяет какой workflow-скил или отдельный навык использовать для задачи пользователя.

## Таблица маршрутизации

### Комплексные задачи (цепочки навыков)

| Задача | Порядок навыков |
|--------|-----------------|
| Создать конфигурацию с нуля | `/1c-cf-init`, затем `/1c-meta-compile`, `/1c-subsystem-compile`, `/1c-role-compile`, `/1c-form-compile` |
| Добавить объект в конфигурацию | `/1c-meta-compile`, `/1c-cf-edit`, `/1c-subsystem-edit`, `/1c-form-add`, `/1c-meta-validate` |
| Создать обработку полностью | `/1c-epf-init`, `/1c-form-add`, `/1c-mxl-compile`, `/1c-epf-build` |
| Создать расширение полностью | `/1c-cfe-init`, `/1c-cfe-borrow`, `/1c-cfe-patch-method`, `/1c-cfe-validate` |

### Конфигурация (cf-*)

| Задача | Скил |
|--------|------|
| Создать пустую конфигурацию | `/1c-cf-init` |
| Посмотреть состав конфигурации | `/1c-cf-info` |
| Изменить свойства конфигурации | `/1c-cf-edit` |
| Проверить конфигурацию | `/1c-cf-validate` |

### Расширения (cfe-*)

| Задача | Скил |
|--------|------|
| Создать расширение | `/1c-cfe-init` |

| Проверить расширение | `/1c-cfe-validate` |

| Задача | Скил |
|--------|------|
| Создать объект (справочник, документ, регистр...) | `/1c-meta-compile` |

## Как использовать

1. Определи задачу пользователя
2. Найди подходящий workflow или скил в таблице
3. Если задача комплексная - используй workflow-скил
4. Если задача точечная - используй конкретный скил
5. Если непонятно - спроси пользователя
