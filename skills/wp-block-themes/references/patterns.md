# Паттерны (файловые паттерны)

Используй этот файл, когда добавляешь паттерны, которые должны быть доступны в панели
вставки.

## Файловые паттерны

- Клади паттерны в `patterns/*.php`.
- Ядро WordPress регистрирует паттерны автоматически по заголовкам файлов.

Источник:

- https://developer.wordpress.org/themes/patterns/

## Практические ограничения

- Держи разметку паттернов стабильной: изменение имён блоков внутри паттернов может
  незаметно сломать старое содержимое.
- Если паттерн не должен вставляться пользователями напрямую, помечай его как
  недоступный для вставки или внутренний (по соглашениям о заголовках из документации).
