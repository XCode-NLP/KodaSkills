# Приложения Notion

## Подтверди доступ к альфа-версии

Прежде чем запускать команды или изучать проект приложения, попроси пользователя подтвердить, что он участвует в альфа-версии приложений Notion. Аутентификация в командной строке, включённый эксперимент командной строки или локально работающий SDK доступ к альфа-версии не подтверждают. Если пользователь ответил «нет» или не может подтвердить, объясни, что код на SDK может собраться локально, но для развёртывания нужен доступ к альфа-версии, и прекрати работу с приложением.

## Подготовка и заготовка проекта

После подтверждения доступа проверь, установлена ли командная строка Notion: `ntn --version`. Если её нет, установи командой для платформы пользователя:

```bash
# macOS и Linux
curl -fsSL https://ntn.dev | bash

# Windows
winget install Notion.ntn
```

Создай заготовку нового проекта приложения с установленными зависимостями и инициализированным Git:

```bash
ntn apps new --install --git <app-directory>
```

Всегда указывай каталог назначения явно. Агенты не могут пользоваться интерактивным запросом каталога в командной строке. Указывай `.`, когда текущий каталог пуст и подходит как корень проекта; иначе определи подходящий каталог из запроса пользователя или окружающего контекста. Если безопасный каталог определить нельзя, спроси, где размещать проект, прежде чем создавать заготовку. Если команда `apps` недоступна, включи её через `ntn experiments enable apps` и повтори попытку.

Когда проект создан, работай из его корня и полностью прочитай `AGENTS.md`. В этом файле описаны проектирование приложения, реализация, возможности и развёртывание для созданного проекта. Следуй ему и указаниям установленного SDK для твоей версии на протяжении всей задачи.
