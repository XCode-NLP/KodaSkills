# Оптимизация запросов 1С: продвинутые приёмы

Продвинутые приёмы оптимизации запросов. Базовые оптимизации (ВЫРАЗИТЬ, ПРЕДСТАВЛЕНИЕ, временные таблицы вместо подзапросов, ОБЪЕДИНИТЬ ВСЕ, индексы, СКД) — в навыке о составлении запросов. Антипаттерны (запрос в цикле, обращение через точку) — там же.

## Проверка запроса через AI-EDT

Если сервер AI-EDT подключён (инструменты `ai-edt` доступны), проверяй оптимизированный запрос через `validate_query`: убедись, что после рефакторинга нет синтаксических и семантических ошибок. Для запросов СКД передавай `dcsMode=true`.

## Когда использовать

- сложная многошаговая обработка данных;
- оптимизация соединений и подзапросов;
- реализация отчётов на СКД;
- обработка больших объёмов данных частями.

## Временные таблицы

Используй временные таблицы для:

- сложной многошаговой обработки данных;
- соединения данных из нескольких источников;
- переиспользования промежуточных результатов.

### Соединение вместо подзапроса

```bsl
// ПРЕДПОЧТИТЕЛЬНО: соединение (обычно быстрее)
"ВЫБРАТЬ
|	Заказы.Ссылка КАК Заказ,
|	Контрагенты.ИНН КАК ИНН
|ИЗ
|	Документ.ЗаказКлиента КАК Заказы
|		ЛЕВОЕ СОЕДИНЕНИЕ Справочник.Контрагенты КАК Контрагенты
|		ПО Заказы.Контрагент = Контрагенты.Ссылка"

// ИЗБЕГАЙ: подзапрос в списке выборки (проблема N+1)
"ВЫБРАТЬ
|	Заказы.Ссылка КАК Заказ,
|	(ВЫБРАТЬ К.ИНН ИЗ Справочник.Контрагенты КАК К
|	 ГДЕ К.Ссылка = Заказы.Контрагент) КАК ИНН
|ИЗ
|	Документ.ЗаказКлиента КАК Заказы"
```

### Не агрегируй в подзапросе

```bsl
// МЕДЛЕННО: подзапрос с агрегацией
"ВЫБРАТЬ
|	Номенклатура.Ссылка,
|	(ВЫБРАТЬ СУММА(Остатки.Количество) ...) КАК Остаток
|ИЗ
|	Справочник.Номенклатура КАК Номенклатура"

// БЫСТРО: соединение с заранее агрегированными данными
"ВЫБРАТЬ
|	Номенклатура.Ссылка КАК Номенклатура,
|	ЕСТЬNULL(Остатки.КоличествоОстаток, 0) КАК Остаток
|ИЗ
|	Справочник.Номенклатура КАК Номенклатура
|		ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки КАК Остатки
|		ПО Номенклатура.Ссылка = Остатки.Номенклатура"
```
