Покажи задачи, назначенные на текущего пользователя в Yougile.

Аргументы: `$ARGUMENTS` — необязательный, передай `done` или `all`, чтобы включить выполненные задачи.

Шаги:
1. Вызови `list_users`, чтобы получить список участников
2. Спроси пользователя, какое имя его, если оно не известно из контекста
3. Вызови `get_user_tasks` с именем пользователя

Покажи результат с группировкой по колонкам, активные колонки первыми: в работе, бэклог, тестирование, доработка.

Для каждой группы покажи таблицу Markdown с колонками: Код | Название | Исполнитель

Пропускай колонку выполненных задач, если пользователь явно не попросил показать выполненные или не передал `done` либо `all` в аргументах.

В конце покажи итоговую строку: «Всего активных задач: N»
