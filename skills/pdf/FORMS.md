**ВАЖНО: выполни эти шаги строго по порядку. Не переходи к написанию кода раньше времени.**

Если нужно заполнить форму PDF, сначала проверь, есть ли в PDF заполняемые поля формы. Запусти скрипт из директории этого файла:
`python scripts/check_fillable_fields.py <file.pdf>` — и в зависимости от результата переходи к разделу «Заполняемые поля» или «Незаполняемые поля» и следуй тамошним инструкциям.

# Заполняемые поля

Если в PDF есть заполняемые поля формы:

- Запусти скрипт из директории этого файла: `python scripts/extract_form_field_info.py <input.pdf> <field_info.json>`. Он создаст JSON-файл со списком полей в таком формате:

```
[
  {
    "field_id": (уникальный ID поля),
    "page": (номер страницы, начиная с 1),
    "rect": ([left, bottom, right, top] рамка в координатах PDF, y=0 — низ страницы),
    "type": ("text", "checkbox", "radio_group", или "choice"),
  },
  // У флажков есть свойства "checked_value" и "unchecked_value":
  {
    "field_id": (уникальный ID поля),
    "page": (номер страницы, начиная с 1),
    "type": "checkbox",
    "checked_value": (присвой полю это значение, чтобы поставить флажок),
    "unchecked_value": (присвой полю это значение, чтобы снять флажок),
  },
  // У групп радиокнопок есть список "radio_options" с возможными вариантами.
  {
    "field_id": (уникальный ID поля),
    "page": (номер страницы, начиная с 1),
    "type": "radio_group",
    "radio_options": [
      {
        "value": (присвой полю это значение, чтобы выбрать этот вариант),
        "rect": (рамка радиокнопки для этого варианта)
      },
      // Другие варианты
    ]
  },
  // У полей выбора есть список "choice_options" с возможными вариантами:
  {
    "field_id": (уникальный ID поля),
    "page": (номер страницы, начиная с 1),
    "type": "choice",
    "choice_options": [
      {
        "value": (присвой полю это значение, чтобы выбрать этот вариант),
        "text": (отображаемый текст варианта)
      },
      // Другие варианты
    ],
  }
]
```

- Преобразуй PDF в PNG (по изображению на страницу) этим скриптом (запускай из директории этого файла):
`python scripts/convert_pdf_to_images.py <file.pdf> <output_directory>`
Затем изучи изображения и определи назначение каждого поля формы (не забудь перевести координаты рамки из системы PDF в координаты изображения).
- Создай файл `field_values.json` в таком формате со значениями для каждого поля:

```
[
  {
    "field_id": "last_name", // должен совпадать с field_id из `extract_form_field_info.py`
    "description": "Фамилия пользователя",
    "page": 1, // должен совпадать со значением "page" в field_info.json
    "value": "Simpson"
  },
  {
    "field_id": "Checkbox12",
    "description": "Флажок, который ставится, если пользователю 18 или больше",
    "page": 1,
    "value": "/On" // если это флажок, используй его "checked_value", чтобы поставить его. Если это группа радиокнопок, используй одно из значений "value" из "radio_options".
  },
  // остальные поля
]
```

- Запусти скрипт `fill_fillable_fields.py` из директории этого файла, чтобы создать заполненный PDF:
`python scripts/fill_fillable_fields.py <input pdf> <field_values.json> <output pdf>`
Скрипт проверит, что указанные ID полей и значения корректны; если он выведет сообщения об ошибках, исправь соответствующие поля и попробуй снова.

# Незаполняемые поля

Если в PDF нет заполняемых полей формы, нужно добавить текстовые аннотации. Сначала попробуй извлечь координаты из структуры PDF (это точнее), и только при необходимости переходи к визуальной оценке.

## Шаг 1: сначала попробуй извлечь структуру

Запусти этот скрипт, чтобы извлечь текстовые метки, линии и флажки с их точными координатами в PDF:
`python scripts/extract_form_structure.py <input.pdf> form_structure.json`

Он создаст JSON-файл, содержащий:

- **labels**: каждый текстовый элемент с точными координатами (x0, top, x1, bottom в пунктах PDF)
- **lines**: горизонтальные линии, задающие границы строк
- **checkboxes**: небольшие квадратные прямоугольники, являющиеся флажками (с координатами центра)
- **row_boundaries**: верхние и нижние границы строк, вычисленные по горизонтальным линиям

**Проверь результат**: если в `form_structure.json` есть осмысленные метки (текстовые элементы, соответствующие полям формы), используй **подход А: координаты из структуры**. Если PDF сканированный или состоит из изображений и меток мало или нет, используй **подход Б: визуальная оценка**.

---

## Подход А: координаты из структуры (предпочтительный)

Используй его, когда `extract_form_structure.py` нашёл в PDF текстовые метки.

### А.1: разбери структуру

Прочитай `form_structure.json` и определи:

1. **Группы меток**: соседние текстовые элементы, образующие одну метку (например, «Last» + «Name»).
2. **Структуру строк**: метки с близкими значениями `top` находятся в одной строке.
3. **Столбцы полей**: области ввода начинаются после окончания метки (x0 = label.x1 + отступ).
4. **Флажки**: используй координаты флажков прямо из структуры.

**Система координат**: координаты PDF, где y=0 находится в ВЕРХУ страницы, а y растёт вниз.

### А.2: проверь пропущенные элементы

Извлечение структуры может не найти все элементы формы. Частые случаи:

- **Круглые флажки**: как флажки определяются только квадратные прямоугольники.
- **Сложная графика**: декоративные элементы или нестандартные элементы управления.
- **Бледные или светлые элементы**: могут не извлекаться.

Если на изображениях PDF видны поля формы, которых нет в `form_structure.json`, для этих конкретных полей нужно использовать **визуальный анализ** (см. «Смешанный подход» ниже).

### А.3: создай fields.json с координатами PDF

Для каждого поля вычисли координаты области ввода по извлечённой структуре:

**Текстовые поля:**

- начало ввода x0 = label x1 + 5 (небольшой отступ после метки)
- конец ввода x1 = x0 следующей метки или граница строки
- верх ввода top = тот же, что у метки
- низ ввода bottom = линия границы строки ниже или label bottom + высота строки

**Флажки:**

- используй координаты прямоугольника флажка прямо из `form_structure.json`
- entry_bounding_box = [checkbox.x0, checkbox.top, checkbox.x1, checkbox.bottom]

Создай `fields.json`, используя `pdf_width` и `pdf_height` (это указывает на координаты PDF):

```json
{
  "pages": [
    {"page_number": 1, "pdf_width": 612, "pdf_height": 792}
  ],
  "form_fields": [
    {
      "page_number": 1,
      "description": "Поле ввода фамилии",
      "field_label": "Last Name",
      "label_bounding_box": [43, 63, 87, 73],
      "entry_bounding_box": [92, 63, 260, 79],
      "entry_text": {"text": "Smith", "font_size": 10}
    },
    {
      "page_number": 1,
      "description": "Флажок «гражданин США — да»",
      "field_label": "Yes",
      "label_bounding_box": [260, 200, 280, 210],
      "entry_bounding_box": [285, 197, 292, 205],
      "entry_text": {"text": "X"}
    }
  ]
}
```

**Важно**: используй `pdf_width`/`pdf_height` и координаты прямо из `form_structure.json`.

### А.4: проверь рамки

Перед заполнением проверь рамки на ошибки:
`python scripts/check_bounding_boxes.py fields.json`

Скрипт ищет пересекающиеся рамки и области ввода, слишком маленькие для заданного размера шрифта. Исправь все найденные ошибки до заполнения.

---

## Подход Б: визуальная оценка (запасной вариант)

Используй его, когда PDF сканированный или состоит из изображений, а извлечение структуры не нашло пригодных текстовых меток (например, весь текст выглядит как шаблоны `(cid:X)`).

### Б.1: преобразуй PDF в изображения

`python scripts/convert_pdf_to_images.py <input.pdf> <images_dir/>`

### Б.2: первичное определение полей

Изучи изображение каждой страницы, определи разделы формы и получи **грубые оценки** расположения полей:

- метки полей формы и их примерное положение;
- области ввода (линии, рамки или пустые места для текста);
- флажки и их примерное расположение.

Для каждого поля отметь примерные координаты в пикселях (пока они не обязаны быть точными).

### Б.3: уточнение по увеличенному фрагменту (критично для точности)

Для каждого поля вырежи область вокруг предполагаемого места, чтобы точно уточнить координаты.

**Создай увеличенный фрагмент через ImageMagick:**

```bash
magick <page_image> -crop <width>x<height>+<x>+<y> +repage <crop_output.png>
```

Где:

- `<x>, <y>` — левый верхний угол области вырезки (грубая оценка минус отступ);
- `<width>, <height>` — размер области вырезки (область поля плюс около 50 пикселей отступа с каждой стороны).

**Пример:** чтобы уточнить поле «Name» с оценкой около (100, 150):

```bash
magick images_dir/page_1.png -crop 300x80+50+120 +repage crops/name_field.png
```

(Если команда `magick` недоступна, попробуй `convert` с теми же аргументами.)

**Изучи вырезанное изображение**, чтобы определить точные координаты:

1. Найди точный пиксель, где начинается область ввода (после метки).
2. Найди, где область ввода заканчивается (перед следующим полем или краем).
3. Найди верх и низ линии или рамки ввода.

**Переведи координаты вырезки обратно в координаты полного изображения:**

- full_x = crop_x + crop_offset_x
- full_y = crop_y + crop_offset_y

Пример: если вырезка началась в (50, 120), а рамка ввода начинается в (52, 18) внутри вырезки:

- entry_x0 = 52 + 50 = 102
- entry_top = 18 + 120 = 138

**Повтори для каждого поля**, группируя близкие поля в одну вырезку, когда это возможно.

### Б.4: создай fields.json с уточнёнными координатами

Создай `fields.json`, используя `image_width` и `image_height` (это указывает на координаты изображения):

```json
{
  "pages": [
    {"page_number": 1, "image_width": 1700, "image_height": 2200}
  ],
  "form_fields": [
    {
      "page_number": 1,
      "description": "Поле ввода фамилии",
      "field_label": "Last Name",
      "label_bounding_box": [120, 175, 242, 198],
      "entry_bounding_box": [255, 175, 720, 218],
      "entry_text": {"text": "Smith", "font_size": 10}
    }
  ]
}
```

**Важно**: используй `image_width`/`image_height` и уточнённые координаты в пикселях, полученные при анализе увеличенных фрагментов.

### Б.5: проверь рамки

Перед заполнением проверь рамки на ошибки:
`python scripts/check_bounding_boxes.py fields.json`

Скрипт ищет пересекающиеся рамки и области ввода, слишком маленькие для заданного размера шрифта. Исправь все найденные ошибки до заполнения.

---

## Смешанный подход: структура и визуальный анализ

Используй его, когда извлечение структуры работает для большинства полей, но пропускает часть элементов (например, круглые флажки, нестандартные элементы управления).

1. **Примени подход А** для полей, найденных в `form_structure.json`.
2. **Преобразуй PDF в изображения** для визуального анализа пропущенных полей.
3. **Используй уточнение по фрагменту** (из подхода Б) для пропущенных полей.
4. **Объедини координаты**: для полей из структуры используй `pdf_width`/`pdf_height`. Для полей, оценённых визуально, обязательно переведи координаты изображения в координаты PDF:
   - pdf_x = image_x * (pdf_width / image_width)
   - pdf_y = image_y * (pdf_height / image_height)
5. **Используй одну систему координат** в `fields.json` — приведи всё к координатам PDF с `pdf_width`/`pdf_height`.

---

## Шаг 2: проверь перед заполнением

**Всегда проверяй рамки перед заполнением:**
`python scripts/check_bounding_boxes.py fields.json`

Скрипт проверяет:

- пересекающиеся рамки (из-за них текст наложится);
- области ввода, слишком маленькие для заданного размера шрифта.

Исправь все найденные ошибки в `fields.json` перед продолжением.

## Шаг 3: заполни форму

Скрипт заполнения сам определяет систему координат и выполняет преобразование:
`python scripts/fill_pdf_form_with_annotations.py <input.pdf> fields.json <output.pdf>`

## Шаг 4: проверь результат

Преобразуй заполненный PDF в изображения и проверь расположение текста:
`python scripts/convert_pdf_to_images.py <output.pdf> <verify_images/>`

Если текст расположен неверно:

- **Подход А**: проверь, что используешь координаты PDF из `form_structure.json` с `pdf_width`/`pdf_height`.
- **Подход Б**: проверь, что размеры изображения совпадают, а координаты заданы точными пикселями.
- **Смешанный подход**: убедись, что преобразование координат для визуально оценённых полей выполнено верно.
