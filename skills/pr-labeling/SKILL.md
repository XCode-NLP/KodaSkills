# Разметка пул-реквеста проекта командной строки навыков

1. Вызови `read_pull_request` с номером из сообщения-триггера. Прочитай заголовок, описание, текущие метки и патчи изменённых файлов. Если последний коммит больше не совпадает с тем, который вызвал запуск, остановись, чтобы более новый запуск разметил пул-реквест.
2. Если у пул-реквеста уже есть `bug`, `documentation` или `enhancement`, остановись. Сохраняй метки, выбранные сопровождающими или прошлыми запусками.
3. Выбери одну метку по основному изменению, которое подтверждает патч:
   - `documentation`: меняется только документация, примеры или пояснительный текст, без изменения поведения командной строки.
   - `bug`: исправляется существующее поведение командной строки, включая установку, проверку обновлений, разбор источников, определение агента или проверки безопасности.
   - `enhancement`: добавляется или намеренно расширяется поведение командной строки, команды, поддержка агентов или поддержка интеграций.
4. Если патч обрезан, неоднороден или его недостаточно для уверенной классификации, остановись, не добавляя метку. Не выводи метку только из заголовка.
5. Вызови `add_label` один раз, указав номер пул-реквеста из триггера и выбранную метку.
