# Юнит-экономика позиции

Через MCP-сервер `marketplaces-mcp-ru`. Нет сервера — `uvx marketplaces-mcp-ru`.

Главное отличие этого расчёта от прикидок в табличке: тарифы берутся из API
площадки на сегодня, а не по памяти. Они меняются, и меняются не в вашу пользу.

## Что собрать

| составляющая | Wildberries | Ozon |
|---|---|---|
| цена продажи | `wb_prices_list` | `ozon_prices_get` |
| комиссия категории | `wb_get_api_tariffs_commission` | из отчёта реализации |
| логистика | `wb_get_api_tariffs_box`, `wb_get_api_tariffs_pallet` | `ozon_finance_realization` |
| возвраты | `wb_get_api_tariffs_return` | `ozon_finance_transactions` |
| фактические удержания | — | `ozon_finance_realization` |

Себестоимость и налог человек называет сам: в API их нет. Если он не знает
себестоимость — так и скажи, что без неё расчёт неполный, и не подставляй
«обычно процентов сорок».

## Как считать

```
остаётся = цена − комиссия − логистика − хранение − эквайринг − возвраты
           − себестоимость − налог
```

Возвраты считай по факту, а не по нормативу: доля возвратов видна из разницы
между `wb_stats_orders` и `wb_stats_sales`.

## Что выдать

Таблица по позициям: цена, каждое удержание отдельной колонкой, остаётся, маржа
в процентах. Отсортируй по остатку в рублях на единицу, по возрастанию — сверху
окажется то, что тянет вниз.

Отдельно назови позиции с отрицательным остатком. Это и есть ответ на «выручка
есть, а денег нет».

## Чего не делать

Не советуй снижать цену «для оборота», не посчитав, что остаётся после снижения.
На маркетплейсах комиссия берётся с цены продажи, поэтому скидка бьёт по марже
сильнее, чем кажется.
