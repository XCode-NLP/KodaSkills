# Настройка PHPStan для WordPress

Этот справочник описывает минимальную, дружественную к WordPress настройку PHPStan
и порядок работы с базовым набором ошибок.

## Минимальный шаблон `phpstan.neon`

Опирайся на существующую раскладку репозитория. Пример ниже намеренно
консервативен, его следует подстроить под реальные каталоги проекта.

```neon
# Подключай базовый набор, только если файл существует.
includes:
    - phpstan-baseline.neon

parameters:
    level: 5
    paths:
        - src/
        - includes/

    excludePaths:
        - vendor/
        - vendor-prefixed/
        - node_modules/
        - tests/

    ignoreErrors:
        # Точечные исключения добавляй, только когда это необходимо.
```

Правила:

- анализируй по возможности только свой код;
- исключай всё сгенерированное и вендорное;
- держи шаблоны `ignoreErrors` узкими и сгруппированными по зависимости.

## Работа с базовым набором ошибок

Базовый набор помогает внедрить PHPStan в старый код, не принимая при этом новые
регрессии.

```bash
# Сгенерировать базовый набор (явное имя файла)
vendor/bin/phpstan analyse --generate-baseline phpstan-baseline.neon

# Обновить существующий базовый набор (значения по умолчанию)
vendor/bin/phpstan analyse --generate-baseline
```

Практика:

- не добавляй в базовый набор новые ошибки, исправляй новый код;
- относись к изменениям базового набора как к изменениям кода: просматривай их в
  пул-реквестах;
- сокращай базовый набор постепенно, убирая записи по мере исправления корневых
  причин.
