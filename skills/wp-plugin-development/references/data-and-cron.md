# Хранение данных, cron и обновления

Используй этот файл, когда добавляешь постоянное хранилище, фоновые задачи или
процедуры обновления.

## Хранение данных

- для небольшой конфигурации и состояния предпочитай Options API;
- свои таблицы используй, только когда это необходимо; храни версию схемы и
  предусматривай пути обновления.

## Cron

- обеспечивай идемпотентность задач (они могут выполниться позже или несколько
  раз);
- предусмотри путь ручного запуска для отладки (WP-CLI или действие только для
  административной части).

## Замечание о безопасности базы данных

Если используешь `$wpdb->prepare()`, не собирай запросы склейкой пользовательского
ввода. В последних версиях WordPress есть заполнители для идентификаторов (`%i`),
но нельзя предполагать их наличие, не проверив возможности или целевые версии.
