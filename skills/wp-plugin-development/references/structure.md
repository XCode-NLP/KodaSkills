# Структура и загрузка плагина

Используй этот файл, когда вводишь или перерабатываешь архитектуру плагина.

## Основные понятия

- главный файл плагина содержит заголовок и запускает плагин;
- предпочитай предсказуемую инициализацию:
  - минимальный файл запуска;
  - загрузчик или класс, регистрирующий хуки;
  - код только для административной части за административными хуками.
