# Доступ к ALGOPACK и диагностика

## Подписка и настройка ключа

- Зарегистрируйся и войди в DataShop: `https://data.moex.com`.
- Выбери доступный уровень доступа на Data MOEX и DataShop. «Стартовый» — бесплатный тариф с API-токеном; `Promo` — платный доступ по подписке. Набор продуктов, задержка и покрытие полей зависят от выбранного тарифа.
- Подпишись на ALGOPACK со страницы продукта, когда нужен платный или расширенный доступ: `https://data.moex.com/products/algopack`.
- Сгенерируй API-ключ в личном кабинете: `https://data.moex.com/personal-account`.
- Считай коммерческие условия, цены, срок жизни ключа и текущую подписку деталями аккаунта, которые могут меняться.
- Никогда не вставляй реальные API-ключи в исходники, ноутбуки, историю команд, логи, скриншоты или ответы в чате.

Шаблон прямого REST:

```bash
curl -L "https://apim.moex.com/iss/datashop/algopack/eq/obstats.json?date=2025-01-10" \
  -H "Authorization: Bearer ${APIKEY}"
```

Шаблон библиотеки Python:

```bash
python -m pip install "moexalgo[dataframe]" python-dotenv
```

```python
import os
from dotenv import load_dotenv
from moexalgo import session, Market

load_dotenv()
session.TOKEN = os.environ["APIKEY"]

eq = Market("EQ")
data = eq.obstats(date="2025-01-10")
```

Задай `APIKEY=...` в локальном файле `.env` и не добавляй этот файл в систему контроля версий. Установка `session.TOKEN` переключает базовый адрес библиотеки на `https://apim.moex.com/iss` и добавляет `Authorization: Bearer ...`.

## Уровни доступа

Используй эту краткую сводку тарифов, когда спрашивают, что даёт токен или подписка. Отправляй пользователей в Data MOEX и DataShop за актуальными коммерческими условиями, текущей подпиской и ценами.

| Тариф | Что даёт |
| --- | --- |
| «Стартовый», бесплатный API-токен | Свечи и сделки с задержкой 15 минут, FUTOI на уровне `T - 15 дней`, карта рынка, визуализации на сайте, доступ к API и библиотека Python. |
| «Стартовый», запланировано | SuperCandles, Mega Alerts и HI2 на уровне `T - 1 день` запланированы для бесплатного тарифа. Проверь фактическую доступность, прежде чем обещать её. |
| `Promo`, платная подписка | FUTOI, онлайн-стаканы, онлайн-свечи, онлайн-сделки, SuperCandles, Mega Alerts, HI2, карта рынка, визуализации на сайте, доступ к API, библиотека Python и машиночитаемый календарь. |

Данные в реальном времени, онлайн или полностью актуальные требуют валидного токена Bearer и соответствующей подписки. Публичные данные ISS могут быть с задержкой, урезаны по полям или недоступны для наборов только по подписке. Не обещай запланированные возможности бесплатного тарифа как уже доступные, пока это не подтвердит аккаунт пользователя или текущие условия DataShop.

## Диагностика ошибок

| Симптом | Вероятная причина | Что делать |
| --- | --- | --- |
| `401` | Токен Bearer отсутствует, искажён, истёк или отклонён | Проверь `APIKEY`, заголовок Bearer, перевыпуск ключа и состояние аккаунта |
| `403` на наборах по подписке | Нет действующей подписки, нет токена, неверный хост или эндпоинт вне тарифа | Используй `apim.moex.com`, задай токен и заголовок, проверь подписку и покрытие эндпоинта |
| `403` с «Too Many Requests» или внезапные блокировки | Ограничение частоты или сетевой защиты | Замедли запросы, добавь паузы, работай пакетами по датам и тикерам, избегай высокой конкурентности |
| `429` | Ограничение частоты | Повторяй с экспоненциальной паузой и снизь конкурентность |
| Ответ не в JSON в коде библиотеки | Часто это авторизация, подписка или несовпадение маршрута | Посмотри код статуса и заголовки прямым запросом |
| Пустые данные | Нет данных за дату, рынок закрыт, неподдерживаемый инструмент или дата, задержка публикации или нет подписки | Проверь календарь, попробуй заведомо ликвидный тикер и дату, посмотри сырой эндпоинт |

В заметках вики упоминается возможная блокировка при очень высокой частоте запросов, обычное использование на низкой частоте при этом работает. Рекомендуй осторожное ограничение частоты, а не расчёт на предельные значения.

## Границы продукта

ALGOPACK даёт:

- Исторические данные для исследований, гипотез и бэктестов.
- Онлайн-рыночные данные для систем алгоритмического принятия решений.
- Аналитику вроде SuperCandles, FUTOI, HI2 и Mega Alerts.

ALGOPACK не отправляет биржевые заявки. Для задач «купить», «продать», «выставить», «отменить» или «провести заявку» направляй пользователя к API его брокера или к другому авторизованному торговому интерфейсу.

## Эскалация в поддержку

Для проверки подписки по аккаунту, вопросов оплаты или сбоев генерации ключа направляй пользователей в личный кабинет DataShop и каналы поддержки. В локальной документации указаны `algopack@moex.com`, `@moex_algopack` и `@moex_algopack_news` для вопросов о продукте и сообществе.
