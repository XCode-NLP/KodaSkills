Покажи подробную информацию о задаче Yougile.

Аргументы: `$ARGUMENTS` — код задачи, например ID-582.

Примеры:
- `/yougile-task ID-582`
- `/yougile-task ID-1061`

Шаги:
1. Выдели код задачи из `$ARGUMENTS`
2. Если кода нет, спроси пользователя
3. Вызови обе команды параллельно:
   - `get_task` с кодом задачи
   - `get_task_comments` с кодом задачи
4. Покажи детали задачи:
   - **Код**: код задачи
   - **Название**: название
   - **Статус**: название колонки
   - **Проект**: название проекта
   - **Доска**: название доски
   - **Исполнители**: назначенные пользователи
   - **Цвет**: цвет, если задан
   - **Срок**: срок, если задан
   - **Выполнена**: да или нет
   - **Описание**: описание, если есть
5. Если есть комментарии, покажи их в хронологическом порядке:
   - Автор и дата
   - Текст сообщения
6. Если комментариев нет, напиши «Комментариев нет»
