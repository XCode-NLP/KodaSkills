# Навыки поверх MCP

Навыки позволяют серверу поставлять переиспользуемые рабочие инструкции вместе с инструментами.
Предпочитай навык, когда задача требует повторяемого многошагового процесса, политик, справочных
материалов, шаблонов или скриптов, которые иначе раздували бы описания инструментов.

Не заменяй исполняемую возможность прозой: инструменты выполняют действия, ресурсы публикуют
содержимое, подсказки возвращают готовые для модели сообщения, а навыки учат агента безопасно их
сочетать.

## Добавление навыка

Создай обычную директорию `skills/` рядом с точкой входа сервера. Её наличие автоматически
включает обнаружение.

```text
skills/
  process-refund/
    SKILL.md
    references/
      policy.md
    templates/
      confirmation.md
```

Каждому навыку нужен `SKILL.md` с совпадающим именем директории, краткой триггерной информацией и
инструкциями по задаче:

```md
---
name: process-refund
description: Check refund eligibility and process approved customer refunds
---

# Process refunds

Read `references/policy.md` before deciding eligibility.
Use `templates/confirmation.md` after a successful refund.
```

Держи `SKILL.md` процедурным и небольшим. Подробные политики и предметные знания кладите в
справочники, детерминированные операции — в скрипты, шаблоны вывода и бинарные материалы — в
поддерживающие файлы. Ссылайся на каждый поддерживающий файл прямо из `SKILL.md` и указывай, когда
его читать или использовать.

## Настройка обнаружения

Обычно не указывай `skills` в конфигурации `MCPServer`. Используй явный параметр, только когда
поведение должно отличаться:

```ts
new MCPServer({ name: "shop", version: "1.0.0", skills: true });
new MCPServer({ name: "shop", version: "1.0.0", skills: false });
new MCPServer({
  name: "shop",
  version: "1.0.0",
  skills: { directory: "server-skills" },
});
```

- `true` требует обычной директории.
- `false` игнорирует обычную директорию.
- собственная директория задаётся относительно проекта;
- при `--mcp-dir` автоматическое обнаружение идёт от директории исходников MCP, а явная
  собственная директория остаётся относительно проекта.

## Понимание обнаружения и проверки

Сервер объявляет черновое расширение «навыки поверх MCP». Хосты изучают каталог через
`skills/list`, получают навык через `skills/get` и читают поддерживающее содержимое через чтение
директорий и файлов ресурсов. SDK не вставляет текст навыка в инструкции сервера или описания
инструментов: активация остаётся решением хоста.

Публикуй только доверенные навыки. Хост должен требовать надлежащего согласия пользователя, прежде
чем активировать навык или разрешённые им инструменты.

Во время `mcp-use dev` некорректные навыки логируются и пропускаются, пока их не исправят.
`mcp-use build` строг: он падает при некорректном каталоге, а затем встраивает проверенный снимок в
рабочую сборку.
