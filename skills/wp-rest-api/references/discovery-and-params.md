# Обнаружение и глобальные параметры (кратко)

## Обнаружение API

- корень REST API обнаруживается по заголовку `Link` с
  `rel="https://api.w.org/"`;
- страницы HTML также содержат элемент
  `<link rel="https://api.w.org/" href="...">`;
- при невключённых постоянных ссылках используй `?rest_route=/`.

## Глобальные параметры

- `_fields` ограничивает набор полей ответа (поддерживает вложенные ключи
  метаданных);
- `_embed` включает связанные ресурсы в `_embedded`;
- `_method` или `X-HTTP-Method-Override` позволяют через POST имитировать PUT и
  DELETE;
- `_envelope` переносит заголовки и код состояния в тело ответа;
- `_jsonp` включает JSONP для устаревших клиентов.

## Постраничный вывод

- коллекции принимают `page`, `per_page` (от 1 до 100) и `offset`;
- заголовки постраничного вывода: `X-WP-Total` и `X-WP-TotalPages`.
