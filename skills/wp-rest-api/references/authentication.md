# Аутентификация (кратко)

## Аутентификация по кукам (в административной части и на том же сай)

- стандарт для административной части и JavaScript темы или плагина;
- нужен nonce REST (`wp_rest`), передаваемый заголовком `X-WP-Nonce` или
  параметром `_wpnonce`;
- если nonce нет, запрос считается неаутентифицированным, даже когда куки есть.

## Пароли приложений (внешние клиенты)

- доступны с WordPress 5.6;
- используй HTTPS и basic auth с паролем приложения;
- предпочтительнее устаревшего плагина basic auth.

## Плагины аутентификации

- для внешних приложений часты плагины OAuth 1.0a и JWT;
- применяй только при необходимости, следуй документации плагина и правилам
  безопасности.
