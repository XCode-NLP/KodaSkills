# Ответы и поля (кратко)

## Не удаляй поля ядра

- удаление или изменение полей ядра ломает клиентов, включая административную
  часть;
- предпочитай добавлять новые поля или ограничивать размер ответа через `_fields`.

## register_rest_field

- используй для вычисляемых и своих полей;
- укажи `get_callback`, при необходимости `update_callback` и `schema`;
- регистрируй на `rest_api_init`.

## Сырой и отрисованный текст

- для записей `content.rendered` отражает фильтры (плагины вроде оглавления
  вставляют HTML);
- используй `?context=edit` (с аутентификацией), чтобы получить `content.raw`;
- добавляй `_fields=content.raw`, когда нужен только редактируемый текст.

## register_meta, register_post_meta, register_term_meta

- используй, когда данные хранятся как метаданные;
- задай `show_in_rest => true`, чтобы показать их в `.meta`;
- для типов `object` и `array` опиши схему JSON в `show_in_rest.schema`.

## Ссылки и встраивание

- добавляй ссылки через `WP_REST_Response::add_link( $rel, $href, $attrs )`;
- используй `embeddable => true`, чтобы разрешить `_embed`;
- применяй отношения IANA или своё отношение-адрес; компактные отношения можно
  зарегистрировать через `rest_response_link_curies`.
