# Механика навыков

Ветвь справочника [`writing-for-agents`](SKILL.md), посвящённая навыкам: что
меняется, когда документ — это навык (метаданные, выбор способа вызова и навыки-
маршрутизаторы). Всё остальное о написании остаётся общим справочником в
`SKILL.md`.

## Способ вызова

Два варианта с разной ценой по двум нагрузкам:

- **Вызываемый моделью** навык сохраняет `description`, поэтому агент может
  запустить его сам, и другие навыки могут до него дойти. Имя при этом всё равно
  можно набрать: вызов моделью всегда _включает_ доступ человека; описание только
  добавляет обнаружение агентом и никогда не отнимает доступ у человека. Описание —
  верхний указатель навыка в контексте, вынужденный оставаться загруженным всегда:
  постоянная нагрузка на контекст в обмен на обнаружимость. Вызываемый моделью
  навык, содержимое которого целиком справочное, заодно служит общим домом для
  справочных сведений: другой навык может его вызвать, поэтому справочные сведения,
  нужные нескольким навыкам, живут в одном месте. Механика: не задавай
  `disable-model-invocation` и напиши описание для модели, несущее ветви-триггеры
  (правила написания указателей из `SKILL.md` действуют полностью).
- **Вызываемый пользователем** навык убирает описание из доступа агента: вызвать
  его может только человек, набрав имя, и ни один другой навык до него не дойдёт.
  Нагрузки на контекст нет, но тратится нагрузка на человека: именно ты служишь
  индексом, который должен помнить о существовании навыка. Механика: задай
  `disable-model-invocation: true`; `description` становится описанием для
  человека: одна строка итога без списков триггеров.

Выбирай вызов моделью, только если агент должен доходить до навыка сам или до него
должен доходить другой навык. Если навык запускается только вручную, сделай его
вызываемым пользователем и не плати нагрузкой на контекст.

Общие справочные сведения, нужные двум вызываемым пользователем навыкам, не могут
жить ни в одном из них: без описаний ни один не запустит другой. Вынеси их в
обычный файл вне системы навыков: внешние справочные сведения, на которые может
указать любой навык.

## Деление по способу вызова

Разрез деления по способу вызова (разрез по последовательности описан в
`SKILL.md`): отделяй вызываемый моделью навык, когда у тебя есть отдельное ведущее
слово, которое должно запускать его само (слово-триггер, которое ты действительно
используешь в запросах), или до него должен доходить другой навык. За новое
постоянно загружаемое описание ты платишь нагрузкой на контекст, поэтому
независимый доступ должен это оправдывать.

## Навыки-маршрутизаторы

Когда вызываемых пользователем навыков становится больше, чем ты помнишь,
накопленную нагрузку на человека лечит **навык-маршрутизатор**: один вызываемый
пользователем навык, который называет остальные и говорит, когда к какому
обращаться, чтобы человеку нужно было помнить один навык вместо многих. Он может
только подсказывать и никогда не запускать их: у вызываемых пользователем навыков
нет описания, поэтому дойти до них может только человек.
