# Антишаблоны

Частые ошибки, которые дают обобщённые, сломанные или недоступные паттерны.

## Контрольный список качества дизайна

- [ ] **Не обобщённый**: паттерн содержит минимум 3 выразительных дизайнерских решения
- [ ] **Разнообразие раскладки**: нет ухода в три равные колонки или однообразные симметричные
  раскладки
- [ ] **Ритм цвета**: секции чередуют или меняют фон, а не выглядят одинаково
- [ ] **Контраст типографики**: заголовки явно отличаются от основного текста (размером,
  семейством или насыщенностью)
- [ ] **Осмысленность пространства**: отступы и промежутки меняются по контексту, а не
  одинаковы везде
- [ ] **Осмысленное содержимое**: текст-заполнитель отражает реальное использование, кнопки
  описывают действия
- [ ] **Конкретная структура**: сравнения, хронологии, расписания, цены, меню и карточки
  документации имеют подписи, понятные без опоры только на визуальное положение
- [ ] **Сдержанно, но выразительно**: корпоративные и профессиональные паттерны всё равно
  содержат ясную иерархию, акцент или выбор раскладки; игровые паттерны не превращаются в
  однообразную палитру или повторяющийся градиент

## Технические антишаблоны

### Встроенные стили и собственный CSS

```html
<!-- НЕВЕРНО: встроенный тег <style> -->
<style>.my-custom-hero { background: linear-gradient(...); }</style>

<!-- НЕВЕРНО: собственный CSS-класс не из блоков -->
<div class="my-custom-card">

<!-- ВЕРНО: используй атрибуты блока -->
<!-- wp:group {"style":{"color":{"gradient":"linear-gradient(...)"}}} -->
```

### Зашитые в код цвета

```json
// НЕВЕРНО: зашитый hex, когда пресет существует
{"style":{"color":{"background":"#000000","text":"#ffffff"}}}

// ВЕРНО: используй пресеты темы для совместимости с темой
{"backgroundColor":"contrast","textColor":"base"}
```

Используй зашитые значения, только когда подходящего `preset` нет, а дизайн требует конкретного
цвета.

### Отсутствие экранирования и интернационализации

```php
// НЕВЕРНО: сырой текст, не переводится, не экранируется
<h2>Our Services</h2>

// НЕВЕРНО: переводится, но не экранируется
<h2><?php _e( 'Our Services', 'theme-slug' ); ?></h2>

// ВЕРНО: экранируется и переводится
<h2><?php esc_html_e( 'Our Services', 'theme-slug' ); ?></h2>
```

### PHP, зависящий от запроса

```php
// НЕВЕРНО: выполняется на этапе регистрации, а не отрисовки
<?php $recent = get_posts( array( 'numberposts' => 3 ) ); ?>

// ВЕРНО: используй блок Query Loop для динамического содержимого
<!-- wp:query {"query":{"perPage":3,"postType":"post"}} -->
```

### Незакрытые или несовпадающие блоки

```html
<!-- НЕВЕРНО: нет закрывающего комментария -->
<!-- wp:group -->
<div class="wp-block-group">
  <!-- wp:heading -->
  <h2>Title</h2>
  <!-- /wp:heading -->
<!-- Отсутствует: /wp:group -->

<!-- НЕВЕРНО: несовпадающая вложенность -->
<!-- wp:group -->
  <!-- wp:columns -->
<!-- /wp:group -->
  <!-- /wp:columns -->
```

### URL заглушек для изображений

```html
<!-- НЕВЕРНО: внешний сервис заглушек -->
<img src="https://via.placeholder.com/800x400" alt=""/>

<!-- ВЕРНО: используй ресурсы темы или описательную заглушку -->
<img src="<?php echo esc_url( get_theme_file_uri( 'assets/images/placeholder.webp' ) ); ?>"
     alt="<?php esc_attr_e( 'Featured image', 'theme-slug' ); ?>"/>
```

## Проблемы доступности

### Отсутствует альтернативный текст

```html
<!-- НЕВЕРНО -->
<!-- wp:image -->
<figure class="wp-block-image"><img src="photo.jpg" alt=""/></figure>
<!-- /wp:image -->

<!-- ВЕРНО: описательный alt для информативных изображений -->
<!-- wp:image {"alt":"Team members collaborating around a whiteboard"} -->
```

Декоративные изображения (фоны, разделители) могут иметь пустой alt, но информативные должны
описывать содержимое.

### Пропущенные уровни заголовков

```html
<!-- НЕВЕРНО: переход с h2 на h5 -->
<!-- wp:heading {"level":2} --> Section Title
<!-- wp:heading {"level":5} --> Subsection

<!-- ВЕРНО: последовательные уровни -->
<!-- wp:heading {"level":2} --> Section Title
<!-- wp:heading {"level":3} --> Subsection
```

В паттернах верхним уровнем должен быть `h2` (h1 — заголовок страницы). Спускайся
последовательно: h2 → h3 → h4.

### Недостаточный контраст цвета

На тёмных фонах проверяй, что пресеты текста дают достаточный контраст:

- `{"backgroundColor":"contrast","textColor":"base"}` — обычно безопасно (тёмный фон, светлый
  текст);
- собственные сочетания цветов должны соответствовать WCAG 2.1 AA (4.5:1 для основного текста,
  3:1 для крупного).

### Неописательный текст кнопок

```html
<!-- НЕВЕРНО -->
<a class="wp-block-button__link">Click Here</a>
<a class="wp-block-button__link">Read More</a>

<!-- ВЕРНО: описывает действие или назначение -->
<a class="wp-block-button__link"><?php esc_html_e( 'View Our Services', 'theme-slug' ); ?></a>
<a class="wp-block-button__link"><?php esc_html_e( 'Download the Report', 'theme-slug' ); ?></a>
```

### Отсутствует ARIA у декоративных элементов

Блоки-распорки должны содержать `aria-hidden="true"` (WordPress добавляет это автоматически).
Если генерируешь собственные паттерны разделителей, убедись, что декоративные элементы не
объявляются программам чтения с экрана.

## Контрольный список технической проверки

- [ ] У каждого `<!-- wp:block -->` есть парный `<!-- /wp:block -->`
- [ ] JSON в комментариях блоков корректен (без висячих запятых, строки в двойных кавычках)
- [ ] Все видимые пользователю строки используют `esc_html_e()` или `esc_html__()`
- [ ] Все URL используют `esc_url()`
- [ ] Все значения атрибутов с переводимым текстом используют `esc_attr_e()` или `esc_attr__()`
- [ ] Информативные изображения имеют описательный переведённый alt; декоративные намеренно
  используют пустой alt
- [ ] Уровни заголовков последовательны (h2 → h3 → h4, без пропусков)
- [ ] Слаги пресетов — корректные значения по умолчанию или документированы как специфичные для
  темы
- [ ] `Slug` в заголовке использует правильное пространство имён: `theme-slug/pattern-name`
- [ ] Нет встроенного `<style>`, нет `<script>`, нет собственных CSS-классов
- [ ] Нет PHP-функций, зависящих от запроса
- [ ] Подписи кнопок и ссылок конкретны по действию; избегай расплывчатых подписей вроде
  «Click Here» или «Read More»
- [ ] Обновление существующего паттерна сохраняет `Slug`, если намеренно не создаётся новый
  паттерн
