# Примеры запросов

## Секция-герой

> «Создай смелый паттерн-герой с крупным заголовком, подзаголовком и двумя кнопками призыва к
> действию. Тёмный фон, на всю ширину, для темы креативного агентства.»

Ожидается: блок обложки или группы с фоном `contrast`, ограниченный внутренний контейнер,
заголовок с `xx-large` и шрифтом заголовков, абзац вторичного цвета, блок кнопок с основным и
контурным стилями.

## Сетка отзывов

> «Создай сетку отзывов из трёх колонок с аватаром, цитатой, именем и должностью. Чередующиеся
> фоны карточек.»

Ожидается: обёртка-группа, нативная сеточная или колоночная раскладка (три колонки, адаптивная),
внутренние группы-карточки с чередующимися фонами `tertiary` и `base`, блок изображения для
аватара (со скруглением через `border-radius`), абзац для цитаты (курсив), заголовок h3 для
имени, абзац `small` для должности.

## Список записей блога

> «Создай стартовый паттерн страницы для главной блога с героем из избранной записи и сеткой
> последних записей из трёх колонок ниже.»

Ожидается: заголовок `Block Types: core/post-content`, цикл запроса для избранной записи
(`perPage` 1, крупная раскладка), второй цикл запроса для сетки (`perPage` 3, сеточная
раскладка с `post-template`), ясное визуальное разделение секций.

## Подвал с колонками

> «Создай паттерн подвала из четырёх колонок с логотипом, ссылками навигации, контактными
> данными и иконками соцсетей. Тёмный фон.»

Ожидается: заголовок `Block Types: core/template-part/footer`, группа на всю ширину с фоном
`contrast`, колонки (4), блок логотипа сайта, блоки навигации или списков, блоки абзацев для
контактов, блок иконок соцсетей, `Inserter: no`.
