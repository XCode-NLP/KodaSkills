# Дизайн на токенах

Как перевести дизайнерский замысел в атрибуты блоков WordPress, используя пресеты `theme.json`.

## Дизайнерские решения

### Назначение

Что этот паттерн даёт конечному пользователю? Герой конвертирует посетителей. Сетка отзывов
создаёт доверие. Таблица цен подталкивает к сравнению. Пусть назначение определяет каждый
последующий выбор.

### Тон

| Тон | Стратегия цвета | Типографика | Раскладка |
|------|---------------|------------|--------|
| **Смелый, энергичный** | Высокий контраст, акцентные фоны, градиенты | Заголовки XX-large, плотный межбуквенный интервал, акценты заглавными | На всю ширину, асимметричные колонки, большие отступы |
| **Минималистичный, изысканный** | Только base и contrast, тонкие третичные секции | Сдержанные размеры, щедрая высота строки | Ограниченная ширина, щедрое пустое пространство, по центру |
| **Редакционный, журнальный** | Тёмные секции чередуются со светлыми | Смешение семейств шрифтов, разные масштабы заголовков | Асимметричные разбиения (66/33), блоки «медиа и текст» |
| **Игровой, творческий** | Несколько акцентных цветов, яркие фоны | Крупные дисплейные размеры, разная насыщенность | Сеточные раскладки, неожиданные пропорции колонок, скруглённые углы |
| **Корпоративный, профессиональный** | Нейтральная палитра, primary только для призывов к действию | Согласованный масштаб, доминирует шрифт основного текста | Равные колонки, структурная сетка, минимум декора |

### Пространственная композиция

Основные стратегии раскладки:

- **Ограниченная по центру** — классическая ширина содержимого с широкими выходами;
- **Секции на всю ширину** — чередующиеся полосы фона;
- **Асимметричное разбиение** — колонки 60/40 или 70/30 с содержимым и медиа;
- **Сетка** — нативные сеточные или колоночные раскладки блоков для карточек, участников
  команды, элементов портфолио;
- **Вертикальный стек** — flex-колонка с разными промежутками для редакционного ощущения.

### Иерархия типографики

Спланируй шкалу шрифтов до написания разметки:

- **Заголовок героя**: `fontSize:"xx-large"` + `fontFamily:"heading"` + плотный `lineHeight`;
- **Заголовок секции**: `fontSize:"x-large"` + `fontFamily:"heading"`;
- **Подзаголовок или лид**: `fontSize:"large"` + `textColor:"secondary"` или
  `fontFamily:"body"`;
- **Основной текст**: `fontSize:"medium"` или по умолчанию;
- **Подпись или метаданные**: `fontSize:"small"` + `textColor:"secondary"`.

Добавь хотя бы один типографический акцент:

- заглавные с межбуквенным интервалом для меток:
  `{"style":{"typography":{"textTransform":"uppercase","letterSpacing":"0.1em"}}}`;
- плотный межбуквенный интервал на дисплейных заголовках:
  `{"style":{"typography":{"lineHeight":"1.1"}}}`;
- курсив для выносных цитат;
- моноширинный шрифт для технического содержимого и кода;
- щедрый интерлиньяж в основном тексте: `{"style":{"typography":{"lineHeight":"1.8"}}}`.

### Стратегия цвета

Спланируй цветовой поток по секциям:

- **Светлая секция**: фон `base`, текст `contrast` (по умолчанию);
- **Тёмная секция**: фон `contrast`, текст `base` (инверсия);
- **Акцентная секция**: фон `primary` или `tertiary`;
- **Градиентная секция**: блок обложки с градиентным наложением.

Паттерн из нескольких секций должен менять фоны: не используй один и тот же фон для каждой
секции.

## Основной принцип

В паттернах блоков **весь визуальный дизайн** выражается через:

1. **слаги `preset`** — ссылки на значения `theme.json` по имени (предпочтительно);
2. **атрибуты стилей** — собственные значения прямо в JSON блока (запасной вариант);
3. **вложенность блоков** — раскладка и композиция через блоки-контейнеры.

Никогда не используй встроенные теги `<style>`, собственные CSS-классы, не порождённые блоками,
и произвольный HTML вне обёрток блоков.

## Сопоставление пресетов `theme.json`

### Палитра цветов (пресеты по умолчанию в WP 6.7+)

| Слаг | Типичное использование | Роль в дизайне |
|------|-------------|-------------|
| `base` | Фон | Фон страницы или секции |
| `contrast` | Текст на base | Основной текст, тёмные секции |
| `primary` | Акцент бренда | Призывы к действию, ссылки, выделения |
| `secondary` | Вспомогательный акцент | Метки, второстепенные кнопки |
| `tertiary` | Тонкий фон | Карточки, чередующиеся секции |

Использование в атрибутах блоков:

```json
{"backgroundColor":"tertiary","textColor":"contrast"}
```

Собственные темы определяют свои слаги. Паттерны для распространения должны использовать общие
слаги выше или давать запасные hex-значения.

### Пресеты размеров шрифта

| Слаг | CSS-переменная | Типичное использование |
|------|-------------|-------------|
| `small` | `--wp--preset--font-size--small` | Подписи, метаданные |
| `medium` | `--wp--preset--font-size--medium` | Акцент в основном тексте |
| `large` | `--wp--preset--font-size--large` | Подзаголовки, вводный текст |
| `x-large` | `--wp--preset--font-size--x-large` | Заголовки секций |
| `xx-large` | `--wp--preset--font-size--xx-large` | Заголовки героя, дисплейный текст |

Использование: `{"fontSize":"xx-large"}` у блоков заголовка и абзаца.

Для собственных «плавающих» размеров в атрибуте стиля:

```json
{"style":{"typography":{"fontSize":"clamp(2rem, 4vw, 4.5rem)"}}}
```

### Пресеты семейств шрифтов

Частые слаги тем:

- `"fontFamily":"heading"` — шрифт заголовков и дисплейного текста;
- `"fontFamily":"body"` — шрифт основного текста;
- `"fontFamily":"system-sans-serif"` — системный запасной вариант;
- `"fontFamily":"monospace"` — код и технический текст.

### Шкала отступов

Пресеты отступов по умолчанию используют числовые слаги от `20` до `80`:

| Слаг | CSS-переменная | Позиция в шкале |
|------|-------------|----------------|
| `20` | `--wp--preset--spacing--20` | Очень малый |
| `30` | `--wp--preset--spacing--30` | Малый |
| `40` | `--wp--preset--spacing--40` | Средний (по умолчанию) |
| `50` | `--wp--preset--spacing--50` | Большой |
| `60` | `--wp--preset--spacing--60` | Очень большой |
| `70` | `--wp--preset--spacing--70` | Вдвое больше большого |
| `80` | `--wp--preset--spacing--80` | Втрое больше большого |

Ссылка в атрибутах стиля: `"var:preset|spacing|50"`.

## Перевод дизайна в атрибуты

| Дизайнерский замысел | Атрибут блока |
|---------------|----------------|
| Крупный заголовок героя | `{"level":1,"fontSize":"xx-large","fontFamily":"heading"}` у `wp:heading` |
| Приглушённый подзаголовок | `{"fontSize":"medium","textColor":"secondary"}` у `wp:paragraph` |
| Фон секции | `{"backgroundColor":"tertiary"}` у внешнего `wp:group` |
| Тёмная секция | `{"backgroundColor":"contrast","textColor":"base"}` у `wp:group` |
| Карточка с отступами | `{"style":{"spacing":{"padding":{"top":"var:preset|spacing|50",...}}}}` у `wp:group` |
| Акцентная рамка слева | `{"style":{"border":{"left":{"width":"4px","color":"var:preset|color|primary"}}}}` |
| Скруглённые углы | `{"style":{"border":{"radius":"12px"}}}` у `wp:group` или `wp:image` |
| Основная кнопка призыва к действию | `{"backgroundColor":"primary","textColor":"base"}` у `wp:button` |
| Контурная кнопка | `{"className":"is-style-outline"}` у `wp:button` |
| Секция по центру | `{"layout":{"type":"constrained"},"align":"full"}` у `wp:group` |

## Приёмы пространственного ритма

### Вертикальный ритм

Используй согласованные пресеты отступов у групп-секций:

```json
{"style":{"spacing":{"padding":{"top":"var:preset|spacing|60","bottom":"var:preset|spacing|60"}}}}
```

Меняй `blockGap` между внутренними элементами для иерархии:

- плотная группировка (связанные элементы): `"blockGap":"var:preset|spacing|20"`;
- обычный поток: `"blockGap":"var:preset|spacing|40"`;
- щедрое пространство для дыхания: `"blockGap":"var:preset|spacing|60"`.

### Горизонтальная композиция

- **Асимметричные колонки**: `{"width":"66.66%"}` + `{"width":"33.33%"}` — избегай
  постоянного использования равных разбиений;
- **Смещённое содержимое**: используй ограниченную раскладку с собственным `contentSize` уже
  `wideSize`;
- **Сетка с разными пролётами**: CSS-сетка на группе с `columnCount` и `columnSpan` у детей.

### Создание визуального веса

- **Большие отступы** у групп создают пространство для дыхания и ощущение важности;
- **Инверсия контраста** (тёмный фон и светлый текст) привлекает внимание к секциям;
- **Акцентные рамки** (слева, снизу) создают иерархию без тяжести;
- **Блоки-распорки** между секциями: используй отступы `preset`, а не произвольные пиксели.

## Пресеты градиентов и теней

Градиенты в атрибутах:

```json
{"gradient":"vivid-cyan-blue-to-vivid-purple"}
```

Или собственные в стиле:

```json
{"style":{"color":{"gradient":"linear-gradient(135deg,#1a1a2e 0%,#16213e 100%)"}}}
```

Пресеты теней (WP 6.7+):

```json
{"shadow":"var:preset|shadow|natural"}
```

Частые: `natural`, `deep`, `sharp`, `outlined`, `crisp`.

## Дуотон на изображениях

Применяй фильтр дуотона к изображениям и обложкам:

```json
{"style":{"color":{"duotone":["#000000","#ffffff"]}}}
```

Или используй пресет: `{"style":{"color":{"duotone":"var:preset|duotone|dark-grayscale"}}}`.
