# Категории и типы паттернов

## Категории паттернов по умолчанию

WordPress регистрирует эти категории по умолчанию:

| Слаг | Подпись | Типичное содержимое |
|------|-------|-----------------|
| `banner` | Баннер | Секции-герои, объявления на всю ширину |
| `buttons` | Кнопки | Группы кнопок и раскладки призывов к действию |
| `call-to-action` | Призыв к действию | Секции, нацеленные на конверсию |
| `columns` | Колонки | Многоколоночные раскладки |
| `contact` | Контакты | Формы обратной связи, сведения, карты |
| `featured` | Избранное | Секции с выделенным содержимым |
| `footer` | Подвал | Раскладки подвала сайта |
| `gallery` | Галерея | Галереи изображений и сетки |
| `header` | Шапка | Раскладки шапки и навигации сайта |
| `media` | Медиа | Секции с изображениями и видео |
| `posts` | Записи | Раскладки списков записей блога |
| `pricing` | Цены | Таблицы цен и сравнение |
| `services` | Услуги | Показ услуг и возможностей |
| `team` | Команда | Показ участников команды |
| `testimonials` | Отзывы | Обзоры, цитаты, социальное доказательство |
| `text` | Текст | Текстовые секции и статьи |
| `about` | О нас | Секции страницы «О нас» |
| `portfolio` | Портфолио | Показ портфолио и работ |
| `newsletter` | Рассылка | Секции подписки на письма |
| `query` | Запрос | Пользовательские запросы и циклы записей |

### Как выбирать категории

- используй **несколько категорий**, когда паттерн подходит более чем к одной (например,
  `banner, call-to-action`);
- секция-герой с формой подписки → `banner, call-to-action, newsletter`;
- сетка команды с биографиями → `team, about`;
- раскладка блога → `posts, query`.

## Стартовые паттерны (паттерны страниц)

Стартовые паттерны появляются, когда пользователь создаёт новую страницу, и предлагают готовые
раскладки целой страницы.

Регистрируются установкой `Block Types` в `core/post-content`:

```php
<?php
/**
 * Title: About Page
 * Slug: theme-slug/page-about
 * Categories: about, featured
 * Block Types: core/post-content
 * Post Types: page
 */
?>
```

Стартовые паттерны должны быть **полными раскладками страницы**, а не отдельными секциями.

Указывай `Block Types: core/post-content`, если паттерн не предназначен специально для шаблона
или части шаблона.

## Паттерны шаблонов

Паттерны, которые предлагаются при редактировании конкретного типа шаблона в редакторе сайта.

Регистрируются через `Template Types`:

```php
<?php
/**
 * Title: Blog Home Template
 * Slug: theme-slug/template-home
 * Categories: posts
 * Template Types: home, front-page
 * Inserter: no
 */
?>
```

### Поддерживаемые типы шаблонов

| Тип | Описание |
|------|-------------|
| `404` | Страница ошибки 404 |
| `archive` | Архив (категория, метка, дата) |
| `author` | Архив автора |
| `category` | Архив категории |
| `date` | Архив по дате |
| `front-page` | Статическая главная страница |
| `home` | Главная блога или страница записей |
| `index` | Запасной шаблон по умолчанию |
| `page` | Отдельная страница |
| `search` | Результаты поиска |
| `single` | Отдельная запись |
| `singular` | Отдельная запись или страница |
| `tag` | Архив метки |
| `taxonomy` | Архив пользовательской таксономии |
| `attachment` | Страница вложения |
| `comments` | Секция шаблона комментариев |

## Паттерны Query Loop

Используй `core/query` с `core/post-template`, блоками заголовка, отрывка, даты и избранного
изображения записи, **пагинацию** при необходимости и **`core/query-no-results`** там, где это
уместно.

Для шаблонов архива, поиска, категории и автора **предпочитай унаследованный контекст запроса**
(`"inherit":true`) вместо собственного PHP или зашитых в код аргументов запроса.

Для списков пользовательских типов записей и событий до генерации разметки подтверди слаг типа
записи, допущения о таксономиях и датах и доступные блоки.

## Паттерны сравнения, цен, хронологий и расписаний

Используй ясные заголовки, структуру списка, таблицы или карточек с подписями и выделение
избранных состояний не только цветом.

## Паттерны соцсетей, навигации и поиска

Используй нативные блоки и проверь доступные подписи, текст ссылок и контекст поиска. В
паттернах 404 сочетай блок поиска с текстом восстановления, который объясняет, что пользователь
может попробовать дальше.

## Связи с типами блоков

Связывай паттерны с конкретными типами блоков, чтобы они появлялись как варианты для этих
блоков:

| Тип блока | Сценарий |
|------------|----------|
| `core/post-content` | Стартовые паттерны страниц |
| `core/template-part/header` | Паттерны части шаблона шапки |
| `core/template-part/footer` | Паттерны части шаблона подвала |
| `core/query` | Вариации раскладки цикла запроса |
| `core/columns` | Отправные точки колоночных раскладок |

Пример — паттерн части шаблона шапки:

```php
<?php
/**
 * Title: Header with Navigation
 * Slug: theme-slug/header-nav
 * Categories: header
 * Block Types: core/template-part/header
 * Inserter: no
 */
?>
```

Установка `Inserter: no` скрывает такие паттерны из общей панели вставки: они появляются только
в контексте (например, при выборе дизайна части шаблона шапки).

## Скрытие паттернов из панели вставки

Используй `Inserter: no` для:

- паттернов шаблонов (показываются только при выборе шаблона в редакторе сайта);
- паттернов частей шаблонов (показываются только при выборе дизайна части шаблона);
- внутренних паттернов, которые используют другие паттерны или код темы.

Такие паттерны всё равно зарегистрированы и доступны — просто их нельзя просмотреть в общей
панели вставки.
