# Сохранённые шаблоны

**Когда читать:** пользователь просит письмо «по шаблону X», «из моих шаблонов», показать его сохранённые шаблоны, либо изменить, переименовать, создать или скопировать сохранённый шаблон.
**Что вернуть:** к основному порядку работы в `SKILL.md` — §3 для правок; для письма по шаблону ещё §1–§2 и §4–§5.

**Выбор шаблона** — `client_visual_template_list`. Шаблон назван словами, но точного совпадения по имени нет либо кандидатов несколько — покажи их и дай пользователю выбрать. Никаких «похожих».

## Письмо по сохранённому шаблону

`visual_template_get` отдаёт блоки сохранённого шаблона как JSX; его вид приходит только из настроек сохранённого шаблона, которые берутся в предпросмотр и сохранение.

1. **Цель.** §1–§2 основного порядка работы; новая кампания — сначала «Новая кампания с нуля».
2. **Чтение.** `visual_template_get` сохранённого шаблона.
3. **Общие стили**, когда генератору они нужны, — `visual_template_theme_get` на сохранённом шаблоне: после сохранения у письма стили шаблона, а не кампании.
4. **Подтверждение** — §4, со строкой об общих стилях «ширина, фон, CSS и общие стили письма берутся из шаблона <имя>», плюс «и меняются этим документом», если в нём есть `<Theme>`.
5. **Сохранение** — §5 с настройками сохранённого шаблона, только в это одно сохранение. Следующие правки сохраняются без них: настройки уже в кампании, а повторная передача перезапишет то, что пользователь изменил в редакторе с тех пор.

## Изменение, создание и копирование сохранённого шаблона

1. **Изменение содержимого** — `visual_template_get` сохранённого шаблона; правки и предпросмотр — §3 и правила предпросмотра, где сохранённый шаблон стоит там, где они называют шаблон кампании; запись — `client_visual_template_edit`.
2. **Копия** — «сохрани это письмо как шаблон», «шаблон на основе X»: `client_visual_template_create` как копия шаблона кампании или шаблона X. Редактор копирует то, что сохранено, вместе с настройками; его JSX не читается. Кампания — сначала `campaign_get`; несколько A/B-вариантов или две перечисленные версии (активная и черновик) — спроси, какую; состояние кампании значения не имеет. Изменения содержимого — одно подтверждение перед копированием, с названием копии и изменения, затем пункт 1 на копии. У письма в этом разговоре есть изменения, не сохранённые в кампанию, — это не копия: пункт 3 с этим JSX и настройками шаблона кампании.
3. **Из JSX** — `client_visual_template_create` с новым содержимым из JSX генератора и настройками того шаблона, чей вид называет пользователь, либо шаблона кампании из пункта 2. Без них шаблон получает умолчания платформы.
4. **Имя** нового шаблона или копии — за пользователем: попроси его, если запрос имени не даёт.
5. **Подтверждение** перед записью JSX — `client_visual_template_edit` для JSX и `client_visual_template_create` из JSX: имя шаблона, изменение и строка об общих стилях — для изменения строка из §4; для нового шаблона «ширина, фон, CSS и общие стили шаблона берутся из <шаблон>» либо «… это умолчания платформы», плюс «и меняются этим документом», если в нём есть `<Theme>`. Переименование и копирование делаются по запросу.
