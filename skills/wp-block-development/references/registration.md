# Образцы регистрации (сначала PHP)

Используй этот файл, когда нужно надёжно регистрировать блоки в репозиториях
разного вида (плагин, тема, сайт).

## Предпочитай регистрацию по метаданным

Предпочитай:

- `register_block_type_from_metadata( $path_to_block_dir, $args = [] )`.

Почему:

- метаданные остаются авторитетными (`block.json`);
- поддерживается динамическая отрисовка (`render`) и другие поля из метаданных;
- получается более чистая работа с ресурсами.

Источник:

- https://developer.wordpress.org/reference/functions/register_block_type_from_metadata/

## Где регистрировать

- плагины: регистрируй на `init` в загрузчике плагина или отдельном загрузчике;
- темы: регистрируй на `init` (или `after_setup_theme`, если сначала нужны
  возможности темы), но держи это предсказуемым.

## Соответствие динамической отрисовки

Если в `block.json` указан `render`, убедись, что файл существует относительно
корня блока. Внутри файла отрисовки используй `get_block_wrapper_attributes()` для
атрибутов обёртки.
