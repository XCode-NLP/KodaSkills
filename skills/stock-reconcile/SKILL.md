# Свести остатки по кабинетам

Работает через MCP-сервер `marketplaces-mcp-ru`. Если сервер не установлен, скажи
об этом и дай команду `uvx marketplaces-mcp-ru`, дальше не продолжай.

## Порядок

1. Выясни, на каких площадках человек торгует. Не спрашивай про все четыре, если
   в конфигурации сервера заданы ключи не для всех.
2. Собери остатки по каждой площадке:

| площадка | метод | что вернёт |
|---|---|---|
| Wildberries | `wb_stats_stocks` | остатки по складам WB |
| Wildberries FBS | `wb_analytics_warehouse_remains` | детальные остатки по складам |
| Ozon | `ozon_stocks_info` | остатки FBO и FBS |
| Ozon FBS | `ozon_stocks_by_warehouse_fbs` | разбивка по складам |
| Яндекс Маркет | `ym_get_offer_mappings` | карточки с остатками |
| Авито | `avito_get_stocks_info` | остатки объявлений |

3. Если подключён `moysklad-mcp-ru`, возьми остаток на собственном складе — он и
   есть точка отсчёта для сверки.
4. Сведи по артикулу продавца, а не по внутреннему id площадки: у каждой площадки
   свой идентификатор, общий только артикул.

## Что выдать

Таблица: артикул, название, остаток по каждой площадке, остаток на складе, итог.

Отдельным блоком — три списка, и только те, что непустые:

- **кончается** — остаток меньше недельной продажи (продажи возьми из `wb_stats_sales`,
  `ozon_analytics_data`);
- **завис** — остаток есть, продаж за 30 дней нет;
- **расходится** — сумма по площадкам больше остатка на складе.

## Границы

Ничего не меняй. Обновление остатков — это `wb_fbs_stock_update`,
`ozon_stocks_update`, `avito_update_stocks`, все требуют `confirm_write`.
Предложи это отдельным шагом и только если человек попросил.
