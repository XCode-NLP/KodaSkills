## Правило

**Обращайся к подходящим или запрошенным навыкам ДО любого ответа и действия** — включая уточняющие вопросы, изучение проекта и проверку файлов. Если навык окажется неподходящим, применять его не обязательно.

**Перед переходом в режим планирования:** если ты ещё не проводили мозговой штурм, сначала обратись к навыку `brainstorming`.

Затем объяви «Использую навык [название] для [цель]» и следуй навыку буквально. Если в навыке есть контрольный список, создай отдельную задачу на каждый пункт.

## Приоритет навыков

Если подходят несколько навыков, первыми идут процессные: они задают подход, а затем навыки реализации (например, `frontend-design`) его выполняют. `brainstorming` и `systematic-debugging` — самые частые процессные навыки в Superpowers, но правило действует для любого из них.

- «Давай сделаем X» → сначала `superpowers:brainstorming`, затем навыки реализации.
- «Исправь эту ошибку» → сначала `superpowers:systematic-debugging`, затем предметные навыки.

## Тревожные сигналы

Если ты поймал себя на таких мыслях — ОСТАНОВИТЕСЬ, ты ищешь оправдание:

| Мысль | Действительность |
|---------|---------|
| «Это же просто вопрос» | Вопрос — это задача. Проверь навыки. |
| «Сначала мне нужен контекст» | Проверка навыков идёт ДО уточняющих вопросов. |
| «Сначала изучу проект» | Навыки подскажут, КАК его изучать. Сначала проверка. |
| «Я быстро посмотрю git и файлы» | В файлах нет контекста диалога. Проверь навыки. |
| «Сначала соберу информацию» | Навыки подскажут, КАК её собирать. |
| «Здесь не нужен формальный навык» | Если навык существует, используй его. |
| «Я помню этот навык» | Навыки меняются. Читай текущую версию. |
| «Это не считается задачей» | Действие — это задача. Проверь навыки. |
| «Навык здесь избыточен» | Простое быстро становится сложным. Используй его. |
| «Сначала сделаю вот это одно» | Проверяй ДО любого действия. |
| «Мне кажется, я продуктивен» | Недисциплинированные действия тратят время. Навыки это предотвращают. |
| «Я знаю, что это значит» | Знать понятие ≠ применять навык. Обратись к нему. |

## Инструкции пользователя

Инструкции пользователя (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md` и подобные файлы, а также прямые просьбы) важнее навыков, а навыки важнее поведения по умолчанию. Пропускай сценарии и указания навыков только тогда, когда человек явно об этом попросил.
