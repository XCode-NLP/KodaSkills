# Соответствие инструментов Hermes Agent

Навыки говорят действиями («запусти субагента», «создай задачу», «прочитай файл»). В Hermes Agent
они соответствуют инструментам ниже.

## Инструменты

| Действие из навыка | Инструмент Hermes |
|---|---|
| Прочитать файл | `read_file` |
| Создать файл | `write_file` |
| Отредактировать файл (точечная правка) | `patch` |
| Выполнить команду оболочки | `terminal` |
| Искать по содержимому файлов | `search_files` |
| Найти файлы по имени | `terminal` с `find` |
| Загрузить URL или прочитать веб-страницу | `web_extract(urls=[...])` |
| Искать в интернете | `web_search(query=...)` |
| Запустить субагента | `delegate_task(goal=..., context=..., toolsets=[...], role="leaf")` |
| Отслеживание задач | инструмент `todo` |
| Вызвать навык | `skill_view("skill-name")` |

## Файл инструкций

Когда навык упоминает «твой файл инструкций», в Hermes Agent это **`AGENTS.md`** в директории
проекта или **`SOUL.md`** глобально в `~/.hermes/SOUL.md`.

## Вызов навыка

В Hermes Agent есть набор инструментов `skills` с инструментами `skill_view` и `skills_list`.
Чтобы вызвать навык Superpowers, используй:

```
skill_view("brainstorming")
skill_view("test-driven-development")
```

Если `skill_view` не находит навык Superpowers (он может не появляться в каталоге, пока плагин не
зарегистрирует его полностью), прочитай `SKILL.md` напрямую:

```
read_file(path="~/.hermes/plugins/superpowers/skills/<skill-name>/SKILL.md")
```

Этот запасной путь — тот же механизм, которым пользуются другие среды без родной загрузки навыков.

## Запуск субагентов

Используй `delegate_task`, чтобы запускать изолированных субагентов для параллельных или
последовательных потоков работы:

```
delegate_task(goal="...", context="...", toolsets=[...], role="leaf")
```

Если `delegate_task` недоступен, делай работу сам, а не выдумывай вызовы инструментов.

## Отслеживание задач

Используй инструмент `todo` для отслеживания задач в рамках сеанса. Для досок задач нескольких
агентов используй CLI `hermes kanban`, если он доступен. Считай старые упоминания `TodoWrite` тем
же действием отслеживания задач.
