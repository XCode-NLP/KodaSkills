# Соответствие инструментов Pi

Навыки говорят действиями («запусти субагента», «создай задачу», «прочитай файл»). В Pi они
соответствуют инструментам ниже.

| Действие из навыка | Аналог в Pi |
| --- | --- |
| Запустить субагента (шаблон `Subagent (general-purpose):`) | Используй установленный инструмент субагентов, например `subagent` из `pi-subagents`, если он есть |
| Отслеживание задач («создай задачу», «отметь выполненной») | Используй установленный инструмент задач или списка задач, если он есть; иначе веди задачи в плане или `TODO.md` |

## Субагенты

В ядре Pi нет стандартного инструмента субагентов. Пакет `pi-subagents` — сильный необязательный
компаньон: он даёт инструмент `subagent` со сценариями одного агента, цепочки, параллельного
запуска, асинхронной работы, форкнутого контекста и возобновления со статусом. Если инструмента
субагентов нет, не выдумывай вызовы `Task`: выполняй работу последовательно в текущем сеансе или
объясни, что необязательная возможность субагентов не установлена.

## Списки задач

В ядре Pi нет стандартного инструмента списка задач. Если расширение задач установлено, используй
его документированный инструмент. Иначе для отслеживания задач используй файлы планов
Superpowers, контрольные списки в markdown или `TODO.md` в репозитории. Старые документы
Superpowers могут упоминать `TodoWrite`: считай это тем же действием отслеживания задач, что выше.
