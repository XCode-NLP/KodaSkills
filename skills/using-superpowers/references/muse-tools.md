# Соответствие инструментов Muse

Навыки говорят действиями («запусти субагента», «создай задачу», «прочитай файл»). В Muse они
соответствуют инструментам ниже.

| Действие из навыка | Аналог в Muse |
|----------------------|----------------|
| Прочитать файл | `read_file` |
| Прочитать несколько файлов | `read_file` (вызывай несколько раз) или `search` |
| Создать файл | `write_file` |
| Отредактировать файл | `edit_file` |
| Выполнить команду оболочки | `bash` |
| Искать по содержимому файлов | `search` |
| Найти файлы по имени | `search` с `glob` |
| Загрузить URL | `web_fetch` |
| Искать в интернете | `web_search` |
| Вызвать навык | `read_file` для `skills/<name>/SKILL.md` или родной инструмент навыков |
| Запустить субагента (шаблон `Subagent (general-purpose):`) | `subagent_spawn` с заполнением подсказки |
| Отслеживание задач («создай задачу», «отметь выполненной») | `write_todos` или файл задач через `bash` |
| Задать вопрос пользователю | `request_user_input` |

## Файл инструкций

Когда навык упоминает «твой файл инструкций», в Muse это **`CLAUDE.md`** или **`AGENTS.md`** в
корне проекта. Muse загружает их иерархически там, где это настроено.

## Вызов навыка

В Muse есть родная поддержка навыков через `muse skills`. Чтобы вызвать навык Superpowers, прочитай
его `SKILL.md` и следуй инструкциям. Загрузчик (`using-superpowers`) подставляется автоматически на
событии `SessionStart` через хук плагина: ты уже следуешь ему, не загружай его повторно.

## Запуск субагентов

Используй `subagent_spawn`, чтобы передать работу изолированным субагентам. Заполняй шаблоны
подсказок (например, `implementer-prompt.md`, `task-reviewer-prompt.md`) до запуска. Если
инструмента субагентов нет, делай работу сам, а не выдумывай вызовы инструментов.

## Отслеживание задач

Используй `write_todos` для ведения контрольного списка. Создавай по одной задаче на каждый пункт
контрольного списка навыка и отмечай `in_progress` и `completed` по ходу. Если `write_todos`
недоступен, веди файл задач в markdown через `write_file` и `edit_file`.
