# Заметки об инструментах Claude Code

Claude Code — эталонная среда: навыки говорят на её языке (`Agent` для запуска субагента,
списки задач, `Skill`). Здесь описано единственное место, где Claude Code может выполнить план
дешевле, чем в форме по умолчанию у навыков. Это включается по желанию твоего собеседника и не
меняет ничего, что требуют навыки.

## Более дешёвая оркестрация для разработки через субагентов

Сеанс контроллера — самое дорогое место в прогоне `superpowers:subagent-driven-development`: он
читает каждый результат запуска и каждый отчёт и обычно работает на самой сильной модели сеанса.
Claude Code поддерживает вложенных субагентов (по умолчанию три уровня ниже основного диалога;
`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` это настраивает), поэтому весь цикл можно опустить на
уровень ниже.

Когда твой собеседник просит об этом — или сказал, что модель сеанса слишком дорога для
координации, — запусти ОДНОГО субагента-оркестратора на модели среднего уровня, передав путь к
плану и указание использовать `superpowers:subagent-driven-development` от начала до конца.
Оркестратор сам запускает исполнителей и ревьюеров согласно выбору модели из этого навыка;
рабочая область и журнал лежат на диске, поэтому лишний уровень ничего не теряет. В его финальном
сообщении должен дословно идти список «Решения, которые я принял»: именно так решения доходят до
твоего собеседника, и ты передаёшь этот список, а не пересказываешь.

Делай так только для целого плана. Вложение запуска одной задачи ничего не даёт и добавляет
лишнее место.
