# Соответствие инструментов Antigravity CLI (`agy`)

Навыки говорят действиями («запусти субагента», «создай задачу», «прочитай файл»). В Antigravity CLI
(`agy`) они соответствуют инструментам ниже.

| Действие из навыка | Аналог в Antigravity CLI |
|----------------------|----------------------|
| Запустить субагента (шаблон `Subagent (general-purpose):`) | `invoke_subagent` со встроенным `TypeName` — `self` для работы с полными возможностями, `research` только для чтения |
| Отслеживание задач («создай задачу», «отметь выполненной») | **артефакт задачи** — `write_to_file` с `IsArtifact: true` и `ArtifactType: "task"` (см. [отслеживание задач](#отслеживание-задач)). **Не** `manage_task`, который управляет фоновыми процессами. |

## Отслеживание задач

В Antigravity **нет инструмента списка задач** (`manage_task` управляет фоновыми процессами —
`list`, `kill`, `status`, `send_input` — это *не* контрольный список). Когда навык говорит создать
список задач или отслеживать задачи, веди **артефакт задачи**: контрольный список в markdown,
сохранённый через `write_to_file` (`IsArtifact: true`,
`ArtifactMetadata.ArtifactType: "task"`) и правимый по ходу через `replace_file_content` или
`multi_replace_file_content`.

В начале любой многошаговой задачи создай артефакт задачи, перечисляющий каждый шаг твоего плана.
Завершая шаг, правь артефакт и отмечай его выполненным (`- [x]`). Если план меняется, обнови
контрольный список. Держи его актуальным: это твой источник истины о том, что осталось; когда
диалог становится длинным, перечитывай его перед началом каждого шага.
