# Соответствие инструментов Gemini CLI

Навыки говорят действиями («запусти субагента», «создай задачу», «прочитай файл»). В Gemini CLI они
соответствуют инструментам ниже.

| Действие из навыка | Аналог в Gemini CLI |
|----------------------|----------------------|
| Прочитать файл | `read_file` |
| Прочитать несколько файлов сразу | `read_many_files` |
| Создать файл | `write_file` |
| Отредактировать файл | `replace` |
| Выполнить команду оболочки | `run_shell_command` |
| Искать по содержимому файлов | `grep_search` |
| Найти файлы по имени | `glob` |
| Перечислить файлы и поддиректории | `list_directory` |
| Загрузить URL | `web_fetch` |
| Искать в интернете | `google_web_search` |
| Вызвать навык | `activate_skill` |
| Запустить субагента (шаблон `Subagent (general-purpose):`) | `invoke_agent` с `agent_name: "generalist"` (вызывается синтаксисом чата `@generalist` — см. [поддержку субагентов](#поддержка-субагентов)) |
| Несколько параллельных запусков | Несколько вызовов `invoke_agent` в одном ответе |
| Отслеживание задач («создай задачу», «отметь выполненной») | `write_todos` (статусы: pending, in_progress, completed, cancelled, blocked) |

## Файл инструкций

Когда навык упоминает «твой файл инструкций», в Gemini CLI это **`GEMINI.md`**. Gemini CLI
загружает `GEMINI.md` иерархически: глобальный в `~/.gemini/GEMINI.md`, файлы уровня проекта в
директориях рабочей области и их предках, а также `GEMINI.md` в поддиректориях, когда инструмент
обращается к файлам в этих директориях.

## Личная директория навыков

Навыки уровня пользователя лежат в **`~/.gemini/skills/`**, а **`~/.agents/skills/`** служит
межсредовым псевдонимом (общим с Codex и Copilot CLI). Когда в одной области есть обе директории,
приоритет у `.agents/skills/`. Каждый навык — поддиректория с файлом `SKILL.md` (с полями
frontmatter `name` и `description`).

## Поддержка субагентов

Gemini CLI запускает субагентов инструментом `invoke_agent`, который принимает параметры
`agent_name` и `prompt`. Тот же запуск доступен сокращением в чате: ввод `@generalist <prompt>`
эквивалентен вызову `invoke_agent` с `agent_name: "generalist"`. Встроенные имена агентов включают
`generalist`, `cli_help`, `codebase_investigator` и (при включённых инструментах браузера)
`browser_agent`.

Навыки запускают через `Subagent (general-purpose):` и либо ссылаются на файл шаблона подсказки
(например, `./implementer-prompt.md` из `superpowers:subagent-driven-development`), либо дают
подсказку прямо в тексте. В Gemini CLI:

| Форма запуска в навыке | Аналог в Gemini CLI |
|---------------------|----------------------|
| Ссылка на шаблон `*-prompt.md` (исполнитель, ревьюер задачи, ревьюер кода и т.д.) | Заполни шаблон, затем `invoke_agent` с `agent_name: "generalist"` и заполненной подсказкой |
| Ссылка на `./code-reviewer.md` из `superpowers:requesting-code-review` | `invoke_agent` с `agent_name: "generalist"` и заполненным шаблоном ревью |
| Подсказка прямо в тексте (без шаблона) | `invoke_agent` с `agent_name: "generalist"` и твоей подсказкой |

### Заполнение подсказок

Навыки дают шаблоны подсказок с заполнителями вида `{WHAT_WAS_IMPLEMENTED}` или
`[FULL TEXT of task]`. Заполни все заполнители, прежде чем передать готовую подсказку в
`invoke_agent`. Сам шаблон содержит роль агента, критерии ревью и ожидаемый формат вывода —
субагент будет ему следовать.

### Параллельный запуск

Gemini CLI поддерживает параллельный запуск субагентов. Выполни несколько вызовов `invoke_agent` в
одном ответе (или несколько вызовов `@generalist` в одной подсказке), чтобы запустить независимую
работу субагентов параллельно. Держи зависимые задачи последовательными, но не выстраивай
независимые задачи субагентов в очередь только ради более простой истории.

## Дополнительные инструменты Gemini CLI

Эти инструменты есть только в Gemini CLI:

| Инструмент | Назначение |
|------|---------|
| `save_memory` (устаревший) | Сохранять факты между сеансами, когда `experimental.memoryV2 = false` |
| `get_internal_docs` | Искать во встроенной документации Gemini CLI |
| `ask_user` | Задавать пользователю структурированные вопросы (текст, один вариант, несколько вариантов) |
| `enter_plan_mode` / `exit_plan_mode` | Входить в режим плана только для чтения и выходить из него |
| `update_topic` | Обновлять тему текущего диалога и метаданные стратегического замысла |
| `complete_task` | Сообщать, что субагент Gemini завершил работу, и возвращать результат родительскому агенту |
| `tracker_create_task`, `tracker_update_task`, `tracker_get_task`, `tracker_list_tasks`, `tracker_add_dependency`, `tracker_visualize` | Расширенный трекер задач с зависимостями и визуализацией |
| `read_mcp_resource`, `list_mcp_resources` | Доступ к ресурсам MCP |
