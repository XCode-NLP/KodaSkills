## Платёжные функции

| Функция | Что даёт | Параметры |
|---|---|---|
| Оплата с фиксированной суммой | Сумма задаётся интеграцией | `products[i][name/price/quantity]` или `order_sum` |
| Оплата по свободной сумме | Покупатель сам вводит сумму на платёжной странице | ссылка без `products` |
| Подписки / автоплатежи | Рекуррентные списания | `subscription` + `subscription_limit_autopayments`, `subscription_date_start`; отмена `POST /rest/setActivity/`, скидка `POST /rest/setSubscriptionDiscount/`, перенос даты `POST /rest/setSubscriptionPaymentDate/`; детали — `payform-protocol.md` |
| Рассрочка | Оплата частями (банки-партнёры) | включена по умолчанию; `installments_disabled=1` отключает |
| Скидки | Скидка в валюте заказа | `discount_value` |
| Предвыбор метода оплаты | Открыть страницу с нужным методом | `payment_method` |
| Ограничение методов оплаты | По кодам (`AC`, `SBP`, `sbol`, `card`, `installment_0_0_6`, `invoice`…) или группам (`ru_payments`, `bank`, `ru_recurring`…) | `available_payment_methods`, `available_payment_method_groups` (через `\|`) |
| Срок действия ссылки | Ссылка протухает | `link_expired` |
| Лимит числа оплат | Одна ссылка — N оплат | `payments_limit` |

## Сервисные функции

| Функция | Что даёт | Как |
|---|---|---|
| Фискализация 54-ФЗ | Чеки формирует Prodamus | номенклатура + осознанные `tax`, `payment_object`, `payment_method` |
| Маркировка товаров | Передача кодов маркировки | REST `POST /rest/mark/addMarks/` («API маркировка товаров») |
| Возвраты (refund) | Возврат оплаты покупателю | штатного API и refund-события в webhook не подтверждено — скоуп согласуется с поддержкой отдельно; проектируй forward-compatible no-op (`payform-protocol.md`) |
| Тестовый режим | Оплаты без денег | `demo_mode=1` |

## Интеграционные функции

| Функция | Что даёт | Как |
|---|---|---|
| Webhook об оплате | Автоматическое отражение оплаты | `urlNotification` + подпись (`payform-protocol.md`) |
| Сквозные параметры | Маршрутизация/аналитика: вернутся в webhook как есть | `_param_*`, `utm_*` |
| Платёжный виджет | Оплата прямо на странице сайта | раздел «Интеграция платёжного виджета» живой документации |

## Подсказки по формулировкам для мерчанта

- «Оплата по свободной сумме» → «клиент сам вписывает сумму»
- «Рекуррентные списания» → «оплата продлевается автоматически»
- «Фискализация» → «чек уходит клиенту автоматически»
- «Сквозные параметры» → «пометки, чтобы понять, откуда пришла оплата»
