# Выполнение мутаций

Используй эти инструкции перед сборкой документа мутации, запросом подтверждения и выполнением мутации.

- Запрашивай минимальный ответ, достаточный для подтверждения изменения.
- Не выполняй смежные изменения, которые пользователь не просил и не подтверждал.

1. Опиши обычным языком конкретное изменение, целевые сущности и существенные значения.
2. Задай прямой вопрос на подтверждение, например: «Заказ 123 будет переведён в статус «Завершён». Применить изменение?»
3. Дождись отдельного явного подтверждения пользователя. Не считай подтверждением исходную просьбу внести изменение.
4. Если пользователь меняет любые параметры, пересобери документ, повтори обязательную проверку из шага 5 и снова запроси подтверждение.
5. Вызывай `GqlExecuteOperation` с тем же `schemaRef` только после подтверждения.

Полный GraphQL-документ не заменяет понятного подтверждения на уровне бизнес-действия. Не выполняй мутацию только ради проверки документа: после успешной проверки `GqlExecuteOperation` может применить изменение сразу.
