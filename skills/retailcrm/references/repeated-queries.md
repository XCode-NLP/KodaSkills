# Повторные запросы

Используй эти инструкции, когда один проверенный документ запроса нужно выполнить несколько раз с разными переменными.

1. Сначала выполни документ для одной показательной сущности.
2. Выполняй тот же документ для остальных значений переменных только после успешной проверки и выполнения.
3. После ошибки проверки не повторяй документ с другими переменными. Перепроверь накопленный SDL, исправь документ и повтори обязательную проверку документа.
4. Вызывай `GqlDescribeOperations` только для ещё не описанной операции, а `GqlDescribeTypes` — только для нового нужного типа. Не повторяй успешные вызовы описания.

Не считай повторное выполнение разрешением на обход в стиле N+1 или агрегацию по каждой сущности. Для массовой обработки читай [инструкции по списочным операциям](list-operations.md).

Не повторяй один и тот же документ только на чтение без изменения документа или переменных.
