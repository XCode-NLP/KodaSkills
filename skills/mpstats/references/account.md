# API аккаунта

Эндпоинты для проверки расхода и лимитов API вашего аккаунта.

Все эндпоинты: `GET` на `https://mpstats.io/api/<path>`

---

## Остаток лимита API

### GET user/report_api_limit

Возвращает остаток квоты вызовов API для текущего тарифа.

**Ответ:**

```json
{
  "available": 2500,
  "use": 38
}
```

| Поле       | Тип | Описание |
|-------------|------|-------------|
| `available` | int  | Всего вызовов API на вашем тарифе |
| `use`       | int  | Сколько вызовов уже израсходовано |

**Остаток вызовов** = `available - use`

---

Обёртка-скрипт: `scripts/account/account-limits.sh`.
