# Wildberries — категории и анализ ниш

Все эндпоинты: `GET` или `POST` на `https://mpstats.io/api/analytics/v1/wb/<path>`

---

## Рубрикатор

### GET category/list

Возвращает актуальный рубрикатор WB (полное дерево категорий).

**Ответ:**

```json
[
  { "url": "/catalog/premium-odezhda", "name": "Premium", "path": "Premium" },
  { "url": "/catalog/zhenshchinam/odezhda/svitshoty", "name": "Свитшоты", "path": "Женщинам/Одежда/Свитшоты" },
  { "url": "/catalog/elektronika/planshety", "name": "Планшеты", "path": "Электроника/Смартфоны и телефоны/Планшеты" }
]
```

| Поле | Тип   | Описание |
|-------|--------|-------------|
| `url` | string | Путь каталога WB |
| `name`| string | Название категории |
| `path`| string | Полный путь от корня |

## Категория: товары

### POST category/items

Возвращает товары категории за диапазон дат.

**Параметры запроса:**

| Параметр  | Тип   | Обязателен | Описание |
|--------|--------|----------|-------------|
| `d1`   | string | да      | Дата начала `YYYY-MM-DD` |
| `d2`   | string | да      | Дата окончания `YYYY-MM-DD` |
| `path` | string | да      | Путь категории в URL-кодировке (например, `Женщинам/Одежда`) |
| `fbs`  | int    | нет       | Учитывать FBS (1 — да) |

**Тело запроса:** см. `pagination-filter-sort.md`.

**Поля элемента в ответе:**

| Поле | Описание |
|-------|-------------|
| `id` | SKU на WB |
| `name` | Название товара |
| `brand` | Название бренда |
| `seller` | Название продавца |
| `supplier_id` | Идентификатор продавца |
| `color` | Цвет |
| `balance` | Текущий остаток |
| `balance_fbs` | Остаток FBS |
| `comments` | Количество отзывов |
| `rating` | Рейтинг (0–5) |
| `final_price` | Итоговая цена (₽) |
| `final_price_max/min/average/median` | Статистика цены |
| `basic_sale` | Базовая скидка, % |
| `basic_price` | Цена до скидки |
| `promo_sale` | Промо-скидка, % |
| `client_sale` | Клиентская скидка, % |
| `client_price` | Цена с клиентской скидкой |
| `start_price` | Исходная цена |
| `sales` | Продажи за период |
| `sales_per_day_average` | Средние продажи в день |
| `revenue` | Выручка за период (₽) |
| `revenue_potential` | Потенциальная выручка |
| `revenue_average` | Средняя выручка |
| `lost_profit` | Упущенная прибыль |
| `lost_profit_percent` | Упущенная прибыль, % |
| `days_in_stock` | Дней в наличии |
| `days_with_sales` | Дней с продажами |
| `average_if_in_stock` | Средние продажи при наличии |
| `is_fbs` | Признак FBS (1/0) |
| `subject_id` | Идентификатор предмета |
| `subject` | Название предмета |
| `purchase` | Добавления в корзину |
| `purchase_after_return` | Покупки после возврата |
| `country` | Страна происхождения |
| `gender` | Целевой пол |
| `sku_first_date` | Дата первого появления |
| `firstcommentdate` | Дата первого отзыва |
| `picscount` | Количество изображений |
| `has3d` | Есть 3D (1/0) |
| `hasvideo` | Есть видео (1/0) |
| `commentsvaluation` | Оценка качества комментариев |
| `cardratingval` | Значение рейтинга карточки |
| `categories_last_count` | Количество категорий |
| `category` | Путь основной категории |
| `category_position` | Позиция в категории |
| `product_visibility_graph` | Видимость во времени |
| `category_graph` | История позиции в категории |
| `graph` | Массив истории продаж |
| `stocks_graph` | Массив истории остатков |
| `price_graph` | Массив истории цен |
| `thumb` | URL миниатюры (маленькая) |
| `thumb_middle` | URL миниатюры (средняя) |
| `url` | URL товара на WB |
| `turnover_days` | Оборачиваемость в днях |
| `turnover_once` | Коэффициент оборачиваемости |

## Категория: подкатегории

### POST category/categories

Разбивка категории по подкатегориям.

**Параметры запроса:**

| Параметр  | Тип   | Обязателен | Описание |
|--------|--------|----------|-------------|
| `d1`   | string | да      | Дата начала |
| `d2`   | string | да      | Дата окончания |
| `path` | string | да      | Путь категории в URL-кодировке |
| `fbs`  | int    | нет       | Учитывать FBS |

**Поля элемента в ответе:**

| Поле | Описание |
|-------|-------------|
| `name` | Название подкатегории |
| `items` | Всего товаров |
| `items_with_sells` | Товаров с продажами |
| `brands` | Всего брендов |
| `brands_with_sells` | Брендов с продажами |
| `sellers` | Всего продавцов |
| `sellers_with_sells` | Продавцов с продажами |
| `sales` | Всего продаж |
| `revenue` | Общая выручка (₽) |
| `avg_price` | Средняя цена |
| `comments` | Среднее число отзывов |
| `rating` | Средний рейтинг |
| `items_with_sells_percent` | % товаров с продажами |
| `brands_with_sells_percent` | % брендов с продажами |
| `sellers_with_sells_percent` | % продавцов с продажами |
| `sales_per_items_average` | Средние продажи на товар |
| `sales_per_items_with_sells_average` | Средние продажи на продающий товар |
| `revenue_per_items_average` | Средняя выручка на товар |
| `revenue_per_items_with_sells_average` | Средняя выручка на продающий товар |

## Анализ ниши (предмета)

Предметы — это таксономия типов товаров WB (например, «Платья», «Кроссовки»).

### POST subject/list

Список предметов и ниш для выбора.

**Параметры запроса:** `date` (одна дата, YYYY-MM-DD).

---

### GET subject/{id}

Сведения о предмете по идентификатору.

**Параметры пути:** `id` — идентификатор предмета (число).

---

### POST subject/items

Товары предмета (ниши).

**Параметры запроса:** `d1`, `d2`, `path` (subject_id), `fbs`.
**Тело:** модель постраничной выдачи, фильтров и сортировки.

---

### POST subject/categories

Разбивка предмета по категориям.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).

---

### POST subject/brands

Разбивка предмета по брендам.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).

---

### POST subject/sellers

Разбивка предмета по продавцам.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).

---

### POST subject/trends

Данные о трендах предмета.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).

---

### POST subject/by_date

Метрики предмета по дням.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).

---

### POST subject/keywords

Данные по ключевым словам и поисковым запросам предмета.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).

---

### POST subject/geography

Географическое распределение предмета.

**Параметры запроса:** `path` (обязателен), `fbs` (необязателен). Для этого метода `d1` и `d2` не принимаются.

---

### POST subject/similar

Похожие предметы.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).

---

### POST subject/compare

Сравнение двух периодов по предмету.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).
**Тело:** модель постраничной выдачи, фильтров и сортировки.

---

### POST subject/warehouses

Данные по складам для предмета.

**Параметры запроса:** `d1`, `d2`, `path` (subject_id).

---

### GET subject/{id}/competitors

Быстрорастущие бренды и продавцы, конкурирующие в предмете.

**Параметры пути:** `id` — идентификатор предмета (число).
