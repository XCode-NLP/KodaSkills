# Wildberries — аналитика брендов и продавцов

Все эндпоинты: `GET` или `POST` на `https://mpstats.io/api/analytics/v1/wb/<path>`

---

## Бренды

### POST brand/items

Возвращает товары бренда.

**Параметры запроса:**

| Параметр  | Тип   | Обязателен | Описание |
|--------|--------|----------|-------------|
| `d1`   | string | да      | Дата начала `YYYY-MM-DD` |
| `d2`   | string | да      | Дата окончания `YYYY-MM-DD` |
| `path` | string | да      | Название бренда (URL-encoded) |
| `fbs`  | int    | нет       | Учитывать FBS (1 — да) |

**Тело:** см. `pagination-filter-sort.md`.

**Ответ:** те же поля товара, что у `category/items` (см. `wb-categories.md`).

---

### GET brand/list

Поиск брендов по названию.

**Параметры запроса:** поисковый запрос по бренду.

---

### GET brand/info

Сведения о бренде.

**Параметры запроса:** идентификатор бренда.

---

### POST brand/categories

Разбивка бренда по категориям.

**Параметры запроса:** `d1`, `d2`, `path`, `fbs`.

---

### POST brand/sellers

Продавцы бренда.

**Параметры запроса:** `d1`, `d2`, `path`, `fbs`.

---

### POST brand/trends

Данные о трендах бренда.

**Параметры запроса:** `d1`, `d2`, `path`, `fbs`.

---

### POST brand/by_date

Метрики бренда, агрегированные по дням.

**Параметры запроса:** `d1`, `d2`, `path`, `fbs`.

---

### POST brand/warehouses

Разбивка остатков бренда по складам.

**Параметры запроса:** `d1`, `d2`, `path`.

---

### POST brand/price_segmentation

Ценовая сегментация бренда.

**Параметры запроса:** `d1`, `d2`, `path`, `fbs`.

---

### POST brand/compare

Сравнение двух периодов по бренду.

**Параметры запроса:** `d1`, `d2`, `path`, `fbs`.
**Тело:** модель постраничной выдачи, фильтров и сортировки.

---

### POST brand/subjects

Предметы (типы товаров) бренда.

**Параметры запроса:** `d1`, `d2`, `path`.

---

### POST brand/keywords

Ключевые слова бренда.

**Параметры запроса:** `d1`, `d2`, `path`.

---

### POST brand/feedback/comments

Комментарии обратной связи по бренду.

### GET brand/feedback/comments/stats

Статистика комментариев обратной связи по бренду.

### GET brand/feedback/comments/graph

График комментариев обратной связи по бренду.
