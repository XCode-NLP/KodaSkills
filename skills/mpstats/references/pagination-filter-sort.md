# Постраничная выдача, фильтры и сортировка

Общая модель запроса и ответа для всех POST-эндпоинтов, которые возвращают списки товаров.

## Тело запроса (POST-эндпоинты)

```json
{
  "startRow": 0,
  "endRow": 100,
  "filterModel": {},
  "sortModel": []
}
```

| Поле        | Тип   | Описание |
|--------------|--------|-------------|
| `startRow`   | int    | Индекс начальной строки (с 0) |
| `endRow`     | int    | Индекс конечной строки. Не больше 5000 записей за запрос |
| `filterModel`| object | Фильтры, применяемые к результату |
| `sortModel`  | array  | Настройка сортировки |

## Тело ответа

```json
{
  "startRow": 0,
  "endRow": 100,
  "filterModel": {},
  "sortModel": [],
  "total": 42,
  "data": [...]
}
```

| Поле        | Тип   | Описание |
|--------------|--------|-------------|
| `startRow`   | int    | Начальная строка из запроса |
| `endRow`     | int    | Конечная строка из запроса |
| `filterModel`| object | Какие фильтры были применены |
| `sortModel`  | array  | Какая сортировка была применена |
| `total`      | int    | Всего строк без учёта постраничной выдачи |
| `data`       | array  | Массив результатов |

## Примеры фильтров

### Фильтр по числу

```json
{
  "filterModel": {
    "id": {
      "filterType": "number",
      "type": "equals",
      "filter": 13495594,
      "filterTo": null
    }
  }
}
```

### Типы фильтров

- `"type": "equals"` — точное совпадение;
- `"type": "greaterThan"` — больше чем;
- `"type": "lessThan"` — меньше чем;
- `"type": "inRange"` — диапазон (`filter` — минимум, `filterTo` — максимум).

## Примеры сортировки

```json
{
  "sortModel": [
    { "colId": "revenue", "sort": "desc" }
  ]
}
```

Направление сортировки: `"asc"` или `"desc"`.

Частые колонки сортировки: `revenue`, `sales`, `balance`, `rating`, `comments`, `final_price`.

## Параметры запроса (общие для эндпоинтов)

| Параметр | Тип   | Описание |
|---------|--------|-------------|
| `d1`    | string | Дата начала `YYYY-MM-DD` |
| `d2`    | string | Дата окончания `YYYY-MM-DD` |
| `fbs`   | int    | Учитывать FBS (0 — выключено, 1 — включено) |

Для практической работы опирайся на готовые shell-скрипты в `scripts/` и передавай лимиты и диапазон дат в них.
