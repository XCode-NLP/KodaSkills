# Авторизация и настройка

## Базовый URL

```
https://mpstats.io/api/
```

Все пути эндпоинтов в этой документации указаны относительно этого базового URL.

## Токен API

Токен выдаётся на https://mpstats.io/userpanel в блоке «API token».

Токен автоматически перегенерируется, когда:

- вы меняете пароль;
- вы нажимаете «Change API token» в настройках.

## Способы авторизации

### Заголовок (рекомендуется)

```
X-Mpstats-TOKEN: <your_token>
```

### Параметр запроса (альтернатива)

```
&auth-token=<your_token>
```

> Пример формата токена: `5a2a5f0e538dd5.6691914852255446e23a9bcac46ee5255625f5d5` — это заглушка, никогда не используй её в настоящих запросах. Настоящий токен всегда бери из `config/.env`.

## Обязательные заголовки

Каждый запрос должен содержать:

```
X-Mpstats-TOKEN: <token>
Content-Type: application/json
```

## Коды ответа

| Код | Значение |
|------|---------|
| 200  | Успех |
| 202  | Запрос принят, но ещё не выполнен — повтори позже |
| 401  | Ошибка авторизации — токен неверен или отсутствует |
| 429  | Превышен лимит частоты — подробности в поле `message`, время ожидания в секундах в заголовке `Retry-After` |
| 500  | Внутренняя ошибка сервера — подробности в поле `message` |

## Лимиты частоты

Лимиты зависят от тарифного плана. При 429:

- проверь поле `message` — там подробности;
- проверь заголовок ответа `Retry-After` — там время ожидания в секундах;
- повтори запрос после этого времени.

Чтобы узнать остаток квоты API: `GET user/report_api_limit`. Подробности в `account.md`.

## Правила выполнения

В агентских сценариях вызывай готовые shell-обёртки из `scripts/` и избегай сырых HTTP-примеров из справочников.
