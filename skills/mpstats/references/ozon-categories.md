# Ozon — аналитика категорий

Все эндпоинты относительно базового URL: `https://mpstats.io/api/analytics/v1/oz/`

---

## Рубрикатор

### POST category/list

Возвращает актуальный рубрикатор категорий Ozon.

**Параметры запроса:**

| Параметр  | Тип   | Обязателен | Описание |
|--------|--------|----------|-------------|
| `date` | string | нет       | Дата `YYYY-MM-DD` |
| `fbs`  | bool   | нет       | Учитывать FBS |

**Ответ:**

```json
[
  { "url": "/category/avtotovary-8500/", "path": "Автотовары", "name": "Автотовары" },
  { "url": "/category/chehly-i-nakidki-na-sidenya-8640/", "path": "Автотовары/Автоаксессуары и принадлежности/Чехлы и накидки на сиденья", "name": "Чехлы и накидки на сиденья" },
  { "url": "/category/semena-lna-9481/", "path": "Продукты питания/Орехи, снэки/Семена льна", "name": "Семена льна" }
]
```

| Поле  | Тип   | Описание |
|--------|--------|-------------|
| `url`  | string | Путь категории Ozon |
| `path` | string | Полный путь от корня |
| `name` | string | Название категории |

## Категория: товары

### POST category/items

Возвращает товары категории Ozon за диапазон дат.

**Параметры запроса:**

| Параметр  | Тип   | Обязателен | Описание |
|--------|--------|----------|-------------|
| `d1`   | string | да      | Дата начала `YYYY-MM-DD` |
| `d2`   | string | да      | Дата окончания `YYYY-MM-DD` |
| `path` | string | да      | Путь категории в URL-кодировке |
| `fbs`  | int    | нет       | Учитывать FBS (1 — да) |

**Тело:** см. `pagination-filter-sort.md`.

**Ответ:** список товаров с полями, близкими к WB (id, name, brand, seller, price, sales, revenue, balance, rating, comments и т. д.).

---

## Категория: подкатегории

### POST category/categories

Разбивка категории Ozon по подкатегориям.

**Параметры запроса:** `d1`, `d2`, `path`, `fbs`.

**Тело:** модель постраничной выдачи, фильтров и сортировки.

**Поля элемента в ответе:**

| Поле | Описание |
|-------|-------------|
| `name` | Название подкатегории |
| `items` | Всего товаров |
| `items_with_sells` | Товаров с продажами |
| `brands` | Всего брендов |
| `brands_with_sells` | Брендов с продажами |
| `sellers` | Всего продавцов |
| `sellers_with_sells` | Продавцов с продажами |
| `sales` | Всего продаж |
| `revenue` | Общая выручка (₽) |
| `avg_price` | Средняя цена |
| `comments` | Среднее число отзывов |
| `rating` | Средний рейтинг |
| `items_with_sells_percent` | % товаров с продажами |
| `brands_with_sells_percent` | % брендов с продажами |
| `sellers_with_sells_percent` | % продавцов с продажами |
| `sales_per_items_average` | Средние продажи на товар |
| `sales_per_items_with_sells_average` | Средние продажи на продающий товар |
| `revenue_per_items_average` | Средняя выручка на товар |
| `revenue_per_items_with_sells_average` | Средняя выручка на продающий товар |
