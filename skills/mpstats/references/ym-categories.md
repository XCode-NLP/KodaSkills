# Яндекс Маркет — категории, бренды, продавцы и аналитика SKU

Все эндпоинты: `GET` или `POST` на `https://mpstats.io/api/<path>`

Учти: у API Яндекс Маркета нет отдельного эндпоинта рубрикатора (дерева категорий). Начинай с известных путей категорий.

---

## Категория: товары

### POST ym/get/category

Возвращает товары категории Яндекс Маркета.

**Параметры запроса:**

| Параметр  | Тип   | Обязателен | Описание |
|--------|--------|----------|-------------|
| `d1`   | string | да      | Дата начала `YYYY-MM-DD` |
| `d2`   | string | да      | Дата окончания `YYYY-MM-DD` |
| `path` | string | да      | Путь категории в URL-кодировке |
| `fbs`  | int    | нет       | Учитывать FBS (1 — да) |

**Тело:** см. `pagination-filter-sort.md`.
