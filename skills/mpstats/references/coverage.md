# Покрытие MPSTATS скриптами

Этот файл отслеживает, насколько скрипты покрывают эндпоинты, описанные в `references/*.md`.

## Коротко

Да: все описанные методы теперь можно вызвать через скрипты.

## Как устроено покрытие

1. Отдельные обёртки для основных семейств:

- Аккаунт: `scripts/account/account-limits.sh`;
- Wildberries: `scripts/wb/*.sh`, включая subject, similar, analytics, compare, warehouses;
- Ozon: `scripts/ozon/*.sh`, включая compare;
- Яндекс Маркет: `scripts/ym/*.sh`, включая compare.

2. Универсальный запасной путь для любого эндпоинта:

- `scripts/request.sh <METHOD> <path> [query] [body_json]`;
- это гарантирует доступ, даже когда отдельная обёртка не является предпочтительным путём.

## Замечания

- Справочники остаются источником истины по точным контрактам эндпоинтов.
- Отдельные обёртки оптимизированы под типовые аналитические сценарии.
- «Какой скрипт запускать и когда» — в `scripts/README.md`.
- `subject/geography` для WB доступен в `scripts/wb/wb-subject.sh` через новый API `analytics/v1`.
- Все скрипты WB теперь используют базовый URL `https://mpstats.io/api/analytics/v1/wb/`.
- При переходе на v2 многие эндпоинты WB сменили метод с GET на POST.
