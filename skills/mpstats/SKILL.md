# API MPSTATS

MPSTATS — российская платформа аналитики маркетплейсов с данными по Wildberries, Ozon и Яндекс Маркету: исследование товаров, анализ категорий, мониторинг продавцов и брендов, продажи на уровне SKU, остатки и отзывы.

Работай через готовые shell-скрипты в `scripts/` — вызывай их инструментом Bash, а не пиши HTTP-код сам. Файлы в `references/` — это только контракты API.

## Настройка токена

Скрипты автоматически подхватывают токен из `config/.env` через `scripts/common.sh`. Переменная окружения `MPSTATS_TOKEN`, заданная для конкретной команды, перекрывает файл.

Настройка и где взять токен: `config/README.md`.

Если токена нет, предложи пользователю ровно два варианта, прежде чем продолжать:

1. Пользователь присылает токен в чат → агент сам создаёт `config/.env`.
2. Пользователь локально выполняет `cp config/.env.example config/.env` и вставляет токен в `config/.env`.

Страница токена: https://mpstats.io/userpanel (блок API token). Нужна действующая подписка MPSTATS.

## Оформление результата

Начинай с короткого вывода, затем доказательства. Для результатов по нескольким сущностям используй компактные таблицы, для трендов, сегментации и сравнений — графики. Не вываливай сырой JSON, если не просили — интерпретируй, что числа значат для решения. Для HTML/PDF-отчётов следуй фирменному стилю MPSTATS из `references/presentation.md`.

## Проверка вменяемости — отмечай аномалии, никогда не сообщай слепо

Данные MPSTATS могут содержать выбросы, ошибки продавцов, несовпадения единиц измерения и устаревшие строки. Сообщать о них как о факте — значит вводить пользователя в заблуждение. **Прежде чем показывать любое число, проверь его порядок величины.**

**Явно отмечай**, если видишь:

- **Цену далеко за пределами нормы категории** — например, салфетки по 500 000 ₽ за штуку, чехол для телефона за 50 ₽, холодильник за 200 ₽. Сравни с медианой категории; если расхождение примерно больше 10 раз, это почти наверняка ошибка цены на стороне продавца, несовпадение единиц (упаковка против штуки) или заглушка.
- **Неправдоподобные объёмы** — маленький продавец внезапно с 1 000 000 штук в месяц; выручка без продаж; выручка, не равная примерно `цена × количество`.
- **Нули, null и отрицательные значения там, где их быть не должно** — рейтинг 0 у SKU с отзывами, остаток = -5, «0 дней с последней продажи» у явно неактивного SKU.
- **Странности с датами и периодами** — запрошенный период не равен полученному, разрывы в ряду по датам, строки с датами в будущем.
- **Несовпадение единиц** — цена за упаковку, принятая за цену за штуку; м² против штуки; литры против миллилитров.

**Как отмечать, в таком порядке:**

1. Покажи аномальную строку явно, назвав значение (например, «500 000 ₽ за упаковку — похоже на ошибку ценника продавца»).
2. Скажи свою лучшую догадку о причине (несовпадение единиц, ошибка продавца, устаревшие данные, заглушка).
3. Либо исключи строку из агрегатов (и скажи об этом), либо отметь, что агрегаты из-за неё смещены.
4. Продолжай анализ на очищенных данных.

**Не** выбрасывай аномалии молча и **не** «округляй» их. **Не** сообщай о них так, будто они настоящие, оставляя абсурд замечать пользователю. Вывод должен опираться на очищенные данные; исходный выброс упоминается ради прозрачности.

## Скрипты

Готовые shell-скрипты в `scripts/`. Вызывай их через Bash, не переписывай HTTP. Полный каталог с назначением каждого скрипта и подсказками, какой выбрать: `scripts/README.md`. Любой скрипт запускай с `--help`, чтобы увидеть параметры.

| Скрипт | Назначение | Пример |
|--------|---------|-------|
| `account/account-limits.sh` | Проверить остаток квоты API | `./scripts/account/account-limits.sh` |
| `wb/wb-categories-list.sh` | Полное дерево категорий WB | `./scripts/wb/wb-categories-list.sh` |
| `wb/wb-category.sh` | Товары категории WB | `./scripts/wb/wb-category.sh "Электроника/Смартфоны" 2024-01-01 2024-03-01` |
| `wb/wb-category-stats.sh` | Разбивка категории WB (подкатегории, бренды, продавцы, тренды) | `./scripts/wb/wb-category-stats.sh "Электроника" subcategories` |
| `wb/wb-sku.sh` | Аналитика SKU WB (полная, продажи, остатки, ключевые слова, комментарии) | `./scripts/wb/wb-sku.sh 152490541 sales` |
| `wb/wb-card-content.sh` | Содержимое карточки WB (описание, характеристики, габариты) — через CDN WB, не MPSTATS | `./scripts/wb/wb-card-content.sh 290784358 .description` |
| `wb/wb-brand.sh` | Товары или аналитика бренда WB | `./scripts/wb/wb-brand.sh "Nike" products` |
| `wb/wb-seller.sh` | Товары или аналитика продавца WB | `./scripts/wb/wb-seller.sh 123456 products` |
| `wb/wb-search.sh` | Список предметов и ниш WB для исследования | `./scripts/wb/wb-search.sh` |
| `wb/wb-subject.sh` | Эндпоинты предмета WB (`products`, `categories`, `brands`, `sellers`, `trends`, `by_date`, `price_segmentation`, `keywords`, `similar`, `geography`, `warehouses`) | `./scripts/wb/wb-subject.sh 70 products` |
| `wb/wb-similar.sh` | Похожие семейства WB (`identical`, `identical_wb`, `similar`, `in_similar`) | `./scripts/wb/wb-similar.sh similar 72124874 products` |

| `ozon/ozon-categories-list.sh` | Полное дерево категорий Ozon | `./scripts/ozon/ozon-categories-list.sh` |
| `ozon/ozon-category.sh` | Товары или статистика категории Ozon | `./scripts/ozon/ozon-category.sh "Автотовары" products` |
| `ozon/ozon-sku.sh` | Отчёты по SKU Ozon (`sales`, `by_day`, `balance`, `categories`, `keywords`, `full`, `by_period`, `search_stats`, `stores`, `comments`) | `./scripts/ozon/ozon-sku.sh 123456789 keywords 2023-11-27 2023-12-26` |
