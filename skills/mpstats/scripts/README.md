# Скрипты MPSTATS

Скрипты сгруппированы по доменам:

- `scripts/account/` — проверки аккаунта и квоты;
- `scripts/wb/` — эндпоинты Wildberries;
- `scripts/ozon/` — эндпоинты Ozon;
- `scripts/ym/` — эндпоинты Яндекс Маркета;
- `scripts/request.sh` — универсальный запрос к любому методу API MPSTATS.

## Аккаунт

| Скрипт | Назначение | Когда использовать |
|---|---|---|
| `account/account-limits.sh` | Расход и остаток квоты API | Перед тяжёлыми прогонами и при разборе 429 |

## Wildberries

| Скрипт | Назначение | Когда использовать |
|---|---|---|
| `wb/wb-categories-list.sh` | Полный рубрикатор WB | Нужно дерево категорий или поиск пути |
| `wb/wb-category.sh` | Список товаров категории (`POST category/items`) | Анализ на уровне товаров в категории WB |
| `wb/wb-category-stats.sh` | Сводные отчёты по категории (`subcategories`, `brands`, `sellers`, `trends`, `by_date`, `price_segmentation`) | Структура рынка, тренды и сегментация |
| `wb/wb-brand.sh` | Товары и сводные отчёты по бренду | Аналитика на уровне бренда |
| `wb/wb-seller.sh` | Товары и сводные отчёты по продавцу | Аналитика на уровне продавца |
| `wb/wb-sku.sh` | Отчёты по SKU через `items/{id}/{report}` | Сведения о товаре, продажи, остатки, ключевые слова, комментарии, FAQ |
| `wb/wb-search.sh` | Список предметов и ниш (`POST subject/list`) | Поиск ниши и определение предмета |
| `wb/wb-subject.sh` | Методы уровня предмета (`subject/*`) | Аналитика по id предмета |
| `wb/wb-similar.sh` | Похожие семейства (`identical`, `identical_wb`, `similar`, `in_similar`) | Анализ похожих товаров по SKU или ссылке |
| `wb/wb-analytics.sh` | Прогнозы и сезонные эффекты | ИИ-прогнозы и сезонность |
| `wb/wb-warehouses.sh` | Разбивка по складам (`brand/warehouses`, `seller/warehouses`) | Распределение остатков по складам |
| `wb/wb-compare.sh` | Сравнение периодов для категории, бренда, продавца или предмета | Сравнение показателей двух периодов |

## Ozon

| Скрипт | Назначение | Когда использовать |
|---|---|---|
| `ozon/ozon-categories-list.sh` | Полный рубрикатор Ozon | Нужно дерево категорий Ozon |
| `ozon/ozon-category.sh` | Товары категории и сводные отчёты | Аналитика категории Ozon |
| `ozon/ozon-brand.sh` | Товары и сводные отчёты по бренду (`categories`, `sellers`, `by_date`, `price_segmentation`) | Аналитика бренда Ozon |
| `ozon/ozon-seller.sh` | Товары и сводные отчёты по продавцу (`categories`, `brands`, `by_date`, `price_segmentation`) | Аналитика продавца Ozon по id или имени |
| `ozon/ozon-sku.sh` | Отчёты по SKU (`sales`, `balance_by_day`, `balance_by_region`, `by_category`, `by_keywords`) | История по товару, остатки, позиции в категориях и по ключевым словам |
| `ozon/ozon-compare.sh` | Сравнение периодов для бренда, продавца или категории | Сравнение двух периодов |

## Яндекс Маркет

| Скрипт | Назначение | Когда использовать |
|---|---|---|
| `ym/ym-category.sh` | Товары категории и сводные отчёты | Аналитика категории Яндекс Маркета |
| `ym/ym-brand.sh` | Товары и сводные отчёты по бренду | Аналитика бренда на Яндекс Маркете |
| `ym/ym-seller.sh` | Товары и сводные отчёты по продавцу | Аналитика продавца на Яндекс Маркете |
| `ym/ym-sku.sh` | История продаж товара с необязательным диапазоном дат | История по товару Яндекс Маркета |
| `ym/ym-compare.sh` | Сравнение периодов для бренда, продавца или категории | Сравнение двух периодов |

## Универсальный

| Скрипт | Назначение | Когда использовать |
|---|---|---|
| `request.sh` | Прямой вызов любого пути методами GET или POST | Эндпоинт не покрыт отдельным скриптом или нужен быстрый прототип |
