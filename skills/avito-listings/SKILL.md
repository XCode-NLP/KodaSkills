# Объявления Авито

Через MCP-сервер `marketplaces-mcp-ru`, раздел Авито — 64 метода. Нет сервера —
`uvx marketplaces-mcp-ru`.

Авторизация у Авито по OAuth2: пара `AVITO_CLIENT_ID` и `AVITO_CLIENT_SECRET`
меняется на токен. Пара берётся в кабинете: Для бизнеса → Интеграции → API.

## Что можно

| задача | метод |
|---|---|
| данные объявления | `avito_get_item_info`, `avito_get_items_info` |
| статистика показов | `avito_item_stats_shallow` |
| подробная аналитика | `avito_item_analytics` |
| остатки | `avito_get_stocks_info` |
| цена | `avito_update_price` |
| заказы | `avito_get_orders`, `avito_get_order_status_v1` |
| платное продвижение | `avito_put_item_vas`, `avito_vas_prices` |
| прогноз по продвижению | `avito_get_bbip_forecasts_by_items_v1` |

## Разбор «мало откликов»

Иди по воронке сверху вниз, а не гадай:

1. **Показы** — `avito_item_stats_shallow`. Показов мало → проблема в категории,
   заголовке или цене, объявление просто не попадает в выдачу.
2. **Просмотры при живых показах** — дело в первом фото, заголовке и цене
   относительно соседей.
3. **Контакты при живых просмотрах** — дело в описании, условиях доставки
   или отзывах.

Называй человеку, на каком шаге воронка ломается. Совет «поднимите объявление»
без этого разбора бесполезен и стоит денег.

## Границы

Изменение цены и покупка продвижения — запись, идёт через `confirm_write`.
Деньги не тратятся без явного подтверждения человеком.
