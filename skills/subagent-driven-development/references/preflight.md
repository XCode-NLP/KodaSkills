# Предварительный поиск конфликтов

Часть навыка `superpowers:subagent-driven-development`. Выполняется один раз, до
запуска задачи 1.

Прежде чем запускать задачу 1, просмотри план один раз на конфликты, записывая
по ходу, что именно проверил:

- задачи, противоречащие друг другу или глобальным ограничениям плана;
- всё, что план прямо предписывает, а критерии проверки считают дефектом (тест,
  который ничего не проверяет; дословное дублирование блока логики).

Результат поиска — таблица, а не вердикт. Одна строка на каждую пару задач,
которые делят файл или интерфейс: обе задачи, что одна даёт против того, что
потребляет другая, и что ты нашёл. Одна строка на каждую задачу: согласуется ли её
собственный текст сам с собой — тесты, которые она задаёт, против кода, который
она задаёт; файлы, которые она создаёт, против файлов, которые она позже
трогает. «Поиск чист» без этих строк — это поиск, который ты не выполнял.

Запиши таблицу в журнал. Вынеси решение по всему найденному до начала
выполнения — каждое против текста плана, который это предписывает, — и запиши
каждое решение в журнал. Если поиск чист, продолжай без комментариев. Реши
каждый вскрытый конфликт — спецификация связывает, план — её аргумент, — запиши
решение рядом со строкой и запускай задачу 1. Цикл проверки остаётся сетью для
конфликтов, которые проявятся только при реализации.
