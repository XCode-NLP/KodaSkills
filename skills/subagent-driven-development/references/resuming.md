# Продолжение по существующему журналу

Часть навыка `superpowers:subagent-driven-development`. В рабочей области этого
плана уже есть журнал в `<workspace>/progress.md`.

Если первая строка журнала называет твой файл плана, задачи со строкой
`Task <N>: complete` СДЕЛАНЫ — не запускай их заново; продолжай с первой
задачи без такой строки. Задача, последняя строка которой — раунд исправлений,
находится посреди цикла: продолжай цикл со следующего раунда. Журнал, первая
строка которого называет другой файл плана, — или случайный журнал по старому
плоскому пути `.superpowers/sdd/progress.md` — это прогресс другого плана:
оставь его на месте и начни свой, с нуля.
