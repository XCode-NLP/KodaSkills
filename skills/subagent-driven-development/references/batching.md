# Объединение мелкой однотипной работы

Часть навыка `superpowers:subagent-driven-development`.

**Объединяй мелкую однотипную работу.** Когда план перечисляет несколько задач,
каждая из которых — мелкая независимая правка одного вида (одно и то же
исправление в одну строку, изменение константы или добавление поля, повторённое
по файлам), не запускай по субагенту на задачу. Составь ОДНО задание с
перечнем каждого файла и его изменения, отправь весь пакет одному субагенту и
проверь его дифф как единое целое. Запуск на каждую задачу оставь для работы,
которой нужны собственное суждение, собственные тесты или собственная поверхность
проверки.
