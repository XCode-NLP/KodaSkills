# Хорошие практики командной строки Unix

Это руководство описывает эффективные, безопасные и переносимые приёмы работы с текстом и поиска файлов из командной строки на macOS. По умолчанию в macOS используются утилиты из BSD (`grep`, `find`, `sed`, `awk`), которые имеют тонкие отличия от версий GNU в Linux.

Где возможно, используй высокопроизводительные замены (`ripgrep` и `fd`): они по умолчанию учитывают правила `.gitignore` и дают более удобный интерфейс.

## Современные высокопроизводительные замены

Используй эти инструменты вместо стандартных утилит BSD для работы с локальной кодовой базой.

### ripgrep (`rg`)

Считай `ripgrep` (`rg`) предпочтительным инструментом поиска текста. Он быстрее стандартного `grep` и по умолчанию учитывает правила `.gitignore`.

Частые случаи:

- `rg 'search_term'` — рекурсивный поиск в текущем каталоге.
- `rg -S 'term'` — поиск без учёта регистра, если в запросе нет заглавных букв. Для строгого игнорирования регистра используй `rg -i 'term'`.
- `rg -g '*.ts' -g '!*.spec.ts' 'term'` — поиск в `.ts`-файлах с исключением `.spec.ts`.
- `rg -v 'ignore_me'` — печать строк, не совпавших с шаблоном.
- `rg -l 'term'` — только имена файлов с совпадениями. В сочетании с `rg -0` даёт вывод с нулевым разделителем, удобный для `xargs`.
- `rg -F 'foo()'` — трактовать шаблон как фиксированную строку, а не регулярное выражение.
- `rg -w 'const'` — совпадение только целых слов.
- `rg -C 2 'term'` — две строки контекста вокруг. `rg -B 2` — контекст до, `rg -A 2` — после.

Полный список параметров — в `rg --help`.

### fd

Считай `fd` предпочтительным инструментом обхода файловой системы и поиска файлов. Он быстрее стандартного `find` и по умолчанию учитывает правила `.gitignore`.

Частые случаи:

- `fd 'pattern'` — найти файлы, у которых регулярное выражение совпадает с любой частью пути.
- `fd -e py -e txt` — фильтр по расширениям файлов.
- `fd -t d 'docs'` — искать каталоги. `fd -t f` — файлы, `fd -t l` — символические ссылки.
- `fd -H` — включить скрытые файлы, `fd -I` — включить игнорируемые (например, `node_modules`). `fd -HI` — искать везде.
- `fd -p 'src/assets'` — сопоставлять шаблон с полным путём, а не только с именем файла.
- `fd -e log -x rm` — выполнить команду для каждого найденного файла отдельно. `-X` (например, `fd -e log -X rm`) запускает команду один раз со всеми файлами в аргументах.
- `fd -a 'pattern'` — возвращать абсолютные пути вместо относительных.

Полный список параметров — в `fd --help`.

## Встроенные инструменты macOS и BSD

Используй эти встроенные утилиты, только когда `rg` и `fd` недоступны. Применяй точные фильтры, чтобы не терять в скорости.

### Эффективный поиск через grep

Не используй `grep | grep -v 'unwanted_dir'` для исключения каталогов: такой подход читает все файлы, а потом их отфильтровывает. Исключай каталоги на уровне файловой системы штатными аргументами:

```bash
# Медленно: читает бинарные и игнорируемые файлы
grep -R "pattern" . | grep -v "node_modules"

# Быстро: полностью пропускает каталог на уровне файловой системы
grep -R --exclude-dir=node_modules --exclude-dir=.git "pattern" .
```

Частые параметры `grep`:

- `-r` или `-R` — рекурсивный поиск. `-R` следует по символическим ссылкам, `-r` — нет.
- `-I` — игнорировать бинарные файлы: быстрее и чище вывод.
- `--exclude="*.min.js"` — игнорировать файлы по glob-шаблону.
- `--include="*.dart"` — искать только в файлах по glob-шаблону.
- `-l` — печатать только имена файлов с совпадениями.
- `-Z` — печатать нулевой байт после имени файла; удобно при передаче в `xargs -0`.

Пример безопасного удаления файлов, содержащих заданную строку:

```bash
grep -rlZ -I --exclude-dir=node_modules "DEPRECATED_API" . | xargs -0 rm
```

### Быстрый обход через find

Не давай `find` обходить ненужные деревья каталогов: используй параметр `-prune`.

```bash
# Медленно: обходит node_modules целиком, а потом фильтрует вывод
find . -name "*.ts" | grep -v "node_modules"

# Быстро: полностью пропускает node_modules
find . -name "node_modules" -prune -o -name "*.ts" -print
```

Выражение `-name "node_modules" -prune` останавливает обход, встретив каталог `node_modules`. Оператор `-o` (ИЛИ) означает, что для любого другого каталога или файла с расширением `.ts` путь печатается.

### Переносимость sed в macOS

В macOS используется BSD `sed`, который отличается от GNU `sed` обработкой правки на месте.

Используй параметр `-i` с явно заданным расширением резервной копии. Чтобы править на месте без резервной копии, передай пустую строку:

```bash
# Правка на месте без резервной копии
sed -i '' 's/oldName/newName/g' filename.txt

# Правка на месте с резервной копией filename.txt.bak
sed -i '.bak' 's/oldName/newName/g' filename.txt
```

Используй `-E`, чтобы включить расширенные регулярные выражения и не экранировать скобки и плюсы:

```bash
sed -E 's/(foo|bar)+/baz/g' file.txt
```

### Разбор кода через awk

Используй `awk` для построчного извлечения и обработки текста.

Частые случаи:

- Печать конкретных столбцов из ввода, разделённого пробелами:
  ```bash
  ls -l | awk '{print $1, $3}'
  ```
- Поиск и печать повторяющихся строк без предварительной сортировки:
  ```bash
  awk '!seen[$0]++' filename.txt
  ```
- Фильтрация строк по значению столбца (например, где третий столбец больше 100):
  ```bash
  awk '$3 > 100' data.txt
  ```
- Поиск строк по шаблону с печатью номера строки (`NR`) и содержимого:
  ```bash
  awk '/Error/ {print NR, $0}' server.log
  ```

### Безопасные конвейеры и параллелизм через xargs

Используй `xargs`, чтобы строить и выполнять команды из стандартного ввода. Всегда применяй `-0` (нулевой разделитель) при обработке путей: так имена с пробелами и специальными символами обрабатываются безопасно.

```bash
# Небезопасно: упадёт или сделает не то, если в именах есть пробелы
find . -name "*.log" | xargs rm

# Безопасно: корректно обрабатывает пробелы и специальные символы
find . -name "*.log" -print0 | xargs -0 rm
```

Используй `-P`, чтобы запускать задачи параллельно:

```bash
# До 4 процессов curl одновременно
cat urls.txt | xargs -n 1 -P 4 curl -O
```

### Утилиты, специфичные для macOS

Используй их для взаимодействия с возможностями операционной системы:

- `mdfind` — запрос к индексу Spotlight для быстрого глобального поиска файлов и содержимого без сканирования диска:
  ```bash
  # Поиск по имени файла
  mdfind -name "project_spec"

  # Поиск по тексту внутри файлов
  mdfind "kMDItemTextContent == 'TODO: Refactor'"
  ```
- `pbcopy` и `pbpaste` — работа с системным буфером обмена:
  ```bash
  # Скопировать содержимое файла в буфер
  cat ssh_key.pub | pbcopy

  # Вставить содержимое буфера в файл
  pbpaste > new_file.txt
  ```
- `open` — открыть файлы, каталоги и ссылки приложениями по умолчанию:
  ```bash
  # Открыть текущий каталог в Finder
  open .

  # Открыть локальный HTML-файл в конкретном приложении
  open -a "Google Chrome" index.html
  ```
