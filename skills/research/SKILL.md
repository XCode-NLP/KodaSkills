Запусти **фонового агента** для исследования, чтобы продолжать работу, пока он читает. Запускай его с чистым окном контекста.

Его задача:

1. Исследовать вопрос по **первоисточникам** (официальная документация, исходный код, спецификации, API первой стороны), а не по вторичным пересказам. Каждое утверждение доводить до источника, который за него отвечает.
2. Записать результаты в один файл Markdown, указав источник каждого утверждения.
3. Сохранить файл там, где в репозитории уже принято хранить такие заметки; следуй существующему порядку, а если его нет — положи в разумное место и скажи, куда.
