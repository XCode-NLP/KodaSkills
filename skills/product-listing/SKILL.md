# Собрать карточку товара

Через MCP-сервер `marketplaces-mcp-ru`. Нет сервера — `uvx marketplaces-mcp-ru`.

## Порядок

1. Выясни площадку и категорию. От категории зависит набор обязательных
   характеристик, и он у каждой площадки свой.
2. Посмотри, как устроены существующие карточки продавца — это задаёт его стиль:
   - Wildberries: `wb_content_cards_list`
   - Ozon: `ozon_product_list`, затем `ozon_product_info_list` по нужным id
   - Яндекс Маркет: `ym_get_offer_mappings`
3. Собери карточку. Обязательный минимум: название, категория, бренд, артикул
   продавца, характеристики категории, описание, габариты и вес.
4. Покажи человеку черновик **до** выгрузки.

## Как писать текст

Заголовок — что это, чей, какой ключевой признак. Без превосходных степеней и без
повторов ключевых слов подряд: площадки это режут, а люди пролистывают.

Описание — по делу: из чего, для чего, что в комплекте, какие ограничения.
Не сочиняй характеристики, которых человек не назвал. Если поле обязательное, а
данных нет — спроси, не выдумывай.

## Выгрузка

Только после подтверждения человеком:

- Wildberries: `wb_content_cards_upload` (новая), `wb_content_cards_update` (правка)
- Ozon: метод импорта товаров из каталога, найди через `describe_method`
- Яндекс Маркет: `ym_update_offer_mappings`

Все три — запись, значит проходят через `confirm_write`.

## Частая причина «товар не виден»

Проверь по порядку: карточка не в черновике, есть фото, заполнены обязательные
характеристики, есть остаток, установлена цена. Ошибки заполнения у Wildberries
показывает `wb_post_content_cards_error_list`.
