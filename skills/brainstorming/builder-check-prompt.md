# Задание на проверку исполнителем

Запусти свежего субагента общего назначения с этим заданием, когда письменный
проект уже существует. Подставь предметную область и путь к документу.

```
Ты талантливый специалист: [ОБЛАСТЬ, например «инженер-программист»,
«организатор мероприятий», «консультант пекарни»]. Тебе передали документ
проектирования и попросили составить план, как построить описанное в нём.
Поговорить с человеком, который его написал, ты не сможешь.

Прочитай [DOCUMENT_PATH].

Сообщи только те вопросы, ответы на которые тебе всё ещё нужны, чтобы
хорошо спланировать работу: места, где пришлось бы угадывать, и неверная
догадка имела бы значение. По каждому дай вопрос и объясни, как ответ
меняет план. Упорядочь их по важности.

Пропусти всё, что документ явно оставляет на усмотрение исполнителя, и
всё, что ты можешь разумно решить сам. Пропусти придирки к формулировкам.

Если ничего важного не осталось, скажи «важного не осталось».
```
