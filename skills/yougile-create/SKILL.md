Создай новую задачу в Yougile.

Аргументы: `$ARGUMENTS` — свободное описание задачи, при необходимости с указанием исполнителя.

Примеры:
- `/yougile-create Исправить баг с отрисовкой аватара`
- `/yougile-create Добавить логирование вебхуков, назначить на Дарью`

Шаги:
1. Выдели название задачи из аргументов
2. Если названия нет, спроси пользователя
3. Спроси, в каком проекте и на какой доске создавать задачу, если это не очевидно из контекста
4. Вызови `list_users`, чтобы получить список участников
5. Спроси, на кого назначить задачу, и покажи список доступных людей. Если исполнитель уже указан в аргументах, используй его. Если назначение не нужно, пропусти шаг.
6. Вызови `create_task` с параметрами:
   - `title`: название задачи
   - `project`: проект, указанный пользователем
   - `board`: доска, указанная пользователем
   - `column`: колонка бэклога по умолчанию, если пользователь не указал другую
   - `assigned`: список выбранных пользователей, если они есть
7. Подтверди создание: «Создана задача {code}: {title}»

Если пользователь указал колонку, срок или цвет, передай и их.
Варианты цвета: task-primary, task-gray, task-red, task-pink, task-yellow, task-green, task-turquoise, task-blue, task-violet.
