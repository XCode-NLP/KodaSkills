# Discord

Официальная документация: <https://discord.com/developers/docs>.
Создай приложение в Developer Portal, затем бота и получи токен.

## Два способа работы

| Способ              | Когда использовать                                                             | Особенности                                                                  |
|---------------------|--------------------------------------------------------------------------------|------------------------------------------------------------------------------|
| Gateway (WebSocket) | Бот читает сообщения, реагирует на события, работает с реакциями и участниками | Постоянное соединение, нужны intents, обязателен всегда запущенный процесс   |
| HTTP interactions   | Только slash-команды, кнопки и модальные окна                                  | Нужен публичный HTTPS-эндпоинт, проверка подписи Ed25519, ответ за 3 секунды |

Многие боты совмещают оба способа: Gateway для событий, HTTP interactions для команд.
Не запускай два процесса с одним токеном: это приводит к конфликтам и повторным ответам.

## Intents

Intents — это подписка на группы событий. Включи только необходимые.

- `Guilds` — базовые события серверов, доступен без дополнительных разрешений.
- `GuildMessages` — сообщения на сервере.
- `MessageContent` — **привилегированный** intent, нужен для чтения текста обычных сообщений.
- `GuildMembers` — **привилегированный** intent, нужен для событий участников.
- `Presence` — **привилегированный** intent, нужен для статусов.

Для новых ботов привилегированные intents включаются в Developer Portal.
Если intent не включён, бот получит ошибку при подключении или не увидит события.

## Slash-команды

- Регистрируй команды через `application.commands`, а не через устаревшие префиксные команды.
- Глобальные команды могут обновляться до часа; для разработки используй guild-команды, они появляются быстрее.
- Описывай параметры типами (`string`, `integer`, `boolean`, `user`, `channel`, `role`, `attachment`).
- Проверяй права пользователя через `interaction.memberPermissions`.
- Отвечай на interaction в течение 3 секунд: `reply`, `deferReply` или `deferUpdate`.
- Если работа дольше 3 секунд, сначала `deferReply`, затем `editReply`.

```js
import { SlashCommandBuilder } from 'discord.js';

export const data = new SlashCommandBuilder()
  .setName('remind')
  .setDescription('Напомнить о задаче')
  .addStringOption((option) =>
    option.setName('text').setDescription('Текст напоминания').setRequired(true).setMaxLength(500),
  );

export async function execute(interaction) {
  await interaction.deferReply({ ephemeral: true });
  const text = interaction.options.getString('text', true);
  // Поставь задачу в очередь, не блокируй interaction.
  await interaction.editReply(`Напоминание принято: ${text}`);
}
```

## Компоненты

- `ActionRow` содержит кнопки или один select-компонент.
- В одном сообщении до 5 рядов, в ряду до 5 кнопок.
- У кнопки есть `custom_id` (до 100 символов) или `url`.
- `ephemeral: true` делает ответ видимым только автору interaction.
- Модальные окна открываются через `showModal` в ответ на interaction.
- Select-меню поддерживает до 25 опций; для длинных списков используй пагинацию.

Не храни бизнес-данные в `custom_id`. Используй короткий ключ и состояние в БД.

## Ограничения

| Что                   | Ограничение                         |
|-----------------------|-------------------------------------|
| Текст сообщения       | 2000 символов                       |
| Заголовок embed       | 256 символов                        |
| Описание embed        | 4096 символов                       |
| Поля embed            | до 25, имя до 256, значение до 1024 |
| Все embed в сообщении | до 6000 символов суммарно           |
| Вложения              | до 10 на сообщение                  |
| ActionRow             | до 5 на сообщение                   |
| Кнопки                | до 5 в ряду                         |
| Опции select          | до 25                               |
| `custom_id`           | до 100 символов                     |
| Ответ на interaction  | 3 секунды                           |

Лимиты частоты у Discord сложные и зависят от маршрута. Клиентские библиотеки обрабатывают `429` автоматически, но не отключай это поведение и не отправляй массовые сообщения в цикле.

## Модерация

- Проверяй иерархию ролей: бот не может наказать пользователя с ролью выше своей.
- Используй `timeout` для временных ограничений и `ban` для постоянных.
- Логируй действия модерации в отдельный канал.
- Не удаляй сообщения без причины и не делай это в обход журнала аудита.
- Учитывай, что `MessageContent` может быть недоступен: не строй модерацию только на чтении текста.

## Безопасность

- Проверяй подпись HTTP interactions:

```js
import { verifyKey } from 'discord-interactions';

const isValid = await verifyKey(rawBody, signature, timestamp, process.env.DISCORD_PUBLIC_KEY);
if (!isValid) {
  return new Response('invalid request signature', { status: 401 });
}
```

- Не логируй токен и содержимое приватных сообщений.
- Ограничивай админские команды по ID пользователей или ролям.
- Не выполняй код и команды из пользовательского ввода.
- Для вебхуков и внешних URL проверяй домен и не делай запросы к внутренней сети.

## Деплой

- Gateway-боту нужен постоянный процесс; используй supervisor, systemd, Docker с `restart: unless-stopped` или оркестратор.
- HTTP interactions можно развернуть как обычный HTTP-сервис за обратным прокси.
- При завершении закрывай соединение корректно, чтобы Discord не считал бота активным.
- Для больших ботов (много серверов) используй шардирование, которое поддерживает библиотека.

## Тестирование

- Проверь команду без прав, с неверным типом параметра и с пустым значением.
- Проверь повторное нажатие кнопки и устаревший `custom_id`.
- Проверь ответ дольше 3 секунд: должен быть `defer`.
- Проверь отсутствие привилегированного intent: бот не должен падать.
- Проверь восстановление соединения после разрыва Gateway.

## Частые ошибки

| Симптом                      | Причина                                   | Решение                                           |
|------------------------------|-------------------------------------------|---------------------------------------------------|
| Бот не видит текст сообщений | Не включён `MessageContent`               | Включи intent в Developer Portal                  |
| `Used disallowed intents`    | Привилегированный intent не включён       | Включи его или убери из клиента                   |
| Interaction failed           | Ответ дольше 3 секунд                     | `deferReply` и последующий `editReply`            |
| Команда не появилась         | Глобальная регистрация ещё не применилась | Используй guild-команды при разработке            |
| Бот не может забанить        | Роль бота ниже роли пользователя          | Подними роль бота                                 |
| Двойные ответы               | Два процесса с одним токеном              | Один экземпляр на токен                           |
| `401` на interactions        | Неверная проверка подписи или public key  | Проверь `DISCORD_PUBLIC_KEY` и сырое тело запроса |
