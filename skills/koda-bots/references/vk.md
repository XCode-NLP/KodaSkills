# VK

Официальная документация: <https://dev.vk.com>.
Бот работает от имени сообщества: создай сообщество, включи «Сообщения» и получи токен в настройках.

## Доставка событий

| Способ       | Когда использовать                  | Особенности                                                  |
|--------------|-------------------------------------|--------------------------------------------------------------|
| Callback API | Продакшен                           | Нужен публичный HTTPS, подтверждение сервера, секретный ключ |
| LongPoll     | Локальная разработка, небольшой бот | Не требует домена, но нужен постоянный процесс               |

Callback API требует подтверждения адреса: VK присылает `type: confirmation`, сервер отвечает строкой подтверждения из настроек.
Укажи секретный ключ и проверяй поле `secret` в каждом запросе.
Отвечай `ok` быстро, а обработку выноси в очередь.

## Библиотеки

| Язык       | Библиотека | Когда выбирать                                    |
|------------|------------|---------------------------------------------------|
| Python     | `vkbottle` | Асинхронный бот, удобные правила и состояния      |
| TypeScript | `vk-io`    | Типизированный бот, сцены и управление сценариями |
| Любой      | HTTP API   | Полный контроль над запросами и версией API       |

Всегда указывай версию API явно. Поведение методов меняется между версиями.

## Основные методы

| Метод                            | Назначение             |
|----------------------------------|------------------------|
| `messages.send`                  | Отправить сообщение    |
| `messages.edit`                  | Изменить сообщение     |
| `messages.delete`                | Удалить сообщение      |
| `messages.getConversations`      | Список диалогов        |
| `messages.getHistory`            | История сообщений      |
| `groups.getLongPollServer`       | Параметры LongPoll     |
| `groups.getCallbackSettings`     | Настройки Callback API |
| `photos.getMessagesUploadServer` | Загрузка изображения   |

Загрузка файлов многошаговая: получи сервер, загрузи файл, сохрани результат, прикрепи `attachment`.
Не фиксируй URL загрузки: они возвращаются API и могут отличаться.

## Клавиатуры

- Клавиатура передаётся как JSON-строка в `keyboard`.
- До 10 кнопок, до 5 в ряду.
- Типы кнопок: `text`, `callback`, `open_link`, `open_app`, `location`, `vkpay`.
- Для callback-кнопок обрабатывай событие `message_event` и отвечай `messages.sendMessageEventAnswer`.
- `inline`-клавиатура прикрепляется к сообщению, обычная заменяет клавиатуру пользователя.
- Не клади в `payload` большие данные: это строка с ограничением по размеру.

```python
import os

from vkbottle.bot import Bot, Message
from vkbottle import Keyboard, KeyboardButtonColor, Text

bot = Bot(os.environ["VK_BOT_TOKEN"])

keyboard = (
    Keyboard(one_time=False, inline=False)
    .add(Text("Помощь"), color=KeyboardButtonColor.PRIMARY)
    .add(Text("Настройки"), color=KeyboardButtonColor.SECONDARY)
    .row()
    .add(Text("Отмена"), color=KeyboardButtonColor.NEGATIVE)
).get_json()


@bot.on.message(text="начать")
async def start(message: Message) -> None:
    await message.answer("Выберите действие", keyboard=keyboard)
```

## Сообщения и вложения

- Текст сообщения — до 4096 символов.
- До 10 вложений в одном сообщении.
- Карусель — до 10 элементов.
- Для упоминаний используй `[id123|Имя]`; не подставляй имя без экранирования.
- Для пересланных сообщений и reply проверяй `reply_message`, а не только текст.
- Не отправляй сообщения в цикле без задержки: сообщество быстро упрётся в лимиты.

## Лимиты

| Что               | Ограничение                                         |
|-------------------|-----------------------------------------------------|
| Текст сообщения   | 4096 символов                                       |
| Вложения          | до 10 на сообщение                                  |
| Кнопки клавиатуры | до 10, до 5 в ряду                                  |
| Элементы карусели | до 10                                               |
| Частота сообщений | около 20 сообщений в секунду для сообщества         |
| LongPoll          | один запрос на сообщество, ожидание около 25 секунд |

При ошибке `6 Too many requests` выдержи паузу и повтори с задержкой.
Не создавай несколько LongPoll-клиентов на одно сообщество.

## Рассылки

- Рассылка возможна только подписчикам, которые разрешили сообщения от сообщества.
- Учитывай `messages.isMessagesFromGroupAllowed` перед отправкой.
- Делай паузы и обрабатывай отписки.
- Не отправляй рекламу без согласия: это нарушает правила VK и приводит к блокировке сообщества.

## Безопасность

- Проверяй `secret` в Callback API.
- Не логируй токен и личные сообщения.
- Ограничивай админские команды по ID пользователей.
- Не выполняй команды из текста сообщения.
- Проверяй ссылки и не делай запросы к внутренней сети по пользовательскому URL.

## Тестирование

- Проверь подтверждение Callback API.
- Проверь запрос с неверным `secret`.
- Проверь повторную доставку события.
- Проверь callback-кнопку и ответ на `message_event`.
- Проверь поведение при ошибке API и при недоступности LongPoll.

## Частые ошибки

| Симптом                    | Причина                          | Решение                                  |
|----------------------------|----------------------------------|------------------------------------------|
| Callback не подтверждается | Неверный код подтверждения       | Скопируй строку из настроек сообщества   |
| `invalid secret`           | Не совпадает секретный ключ      | Проверь настройки и переменную окружения |
| Бот не отвечает в беседе   | Не включены сообщения сообщества | Включи «Сообщения» в настройках          |
| Кнопка не работает         | Не обработан `message_event`     | Добавь обработчик и ответ                |
| `6 Too many requests`      | Нет ограничения скорости         | Очередь и повтор с задержкой             |
| Вложение не отправляется   | Пропущен шаг сохранения файла    | Выполни полный цикл загрузки             |
| LongPoll отваливается      | Два клиента на одно сообщество   | Оставь один экземпляр                    |
