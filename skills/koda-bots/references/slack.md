# Slack

Официальная документация: <https://api.slack.com>.
Создай приложение в <https://api.slack.com/apps>, установи его в рабочее пространство и получи токены.

## Токены и scopes

| Токен                          | Назначение                     |
|--------------------------------|--------------------------------|
| Bot User OAuth Token (`xoxb-`) | Вызовы Web API от имени бота   |
| App-Level Token (`xapp-`)      | Socket Mode                    |
| Signing Secret                 | Проверка подписи HTTP-запросов |

Минимальные scopes зависят от задачи:

- `chat:write` — отправка сообщений.
- `commands` — slash-команды.
- `app_mentions:read` — упоминания бота.
- `channels:history`, `groups:history`, `im:history`, `mpim:history` — чтение истории.
- `files:write` — загрузка файлов.
- `users:read` — информация о пользователях.

Запрашивай только нужные scopes: лишние разрешения усложняют установку и проверку.

## Доставка событий

| Способ           | Когда использовать                  | Особенности                                          |
|------------------|-------------------------------------|------------------------------------------------------|
| HTTP Request URL | Продакшен с публичным HTTPS         | Нужна проверка подписи, ответ за 3 секунды           |
| Socket Mode      | Локальная разработка, закрытая сеть | Не нужен публичный URL, используется app-level token |

При HTTP-режиме Slack присылает `X-Slack-Signature` и `X-Slack-Request-Timestamp`.
Подпись считается как `v0=HMAC_SHA256(signing_secret, "v0:" + timestamp + ":" + raw_body)`.
Проверяй подпись и отклоняй запросы старше 5 минут, чтобы защититься от повторного воспроизведения.

```js
import crypto from 'node:crypto';

export function verifySlackRequest({ signingSecret, timestamp, signature, rawBody }) {
  const age = Math.abs(Date.now() / 1000 - Number(timestamp));
  if (age > 300) return false;

  const base = `v0:${timestamp}:${rawBody}`;
  const expected = `v0=${crypto.createHmac('sha256', signingSecret).update(base).digest('hex')}`;
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(signature));
}
```

## Bolt

Bolt есть для JavaScript, Python и Java. Он берёт на себя проверку подписи, маршрутизацию и ответы.

```js
import bolt from '@slack/bolt';

const app = new bolt.App({
  token: process.env.SLACK_BOT_TOKEN,
  signingSecret: process.env.SLACK_SIGNING_SECRET,
  socketMode: true,
  appToken: process.env.SLACK_APP_TOKEN,
});

app.command('/ping', async ({ ack, respond }) => {
  await ack();
  await respond({ response_type: 'ephemeral', text: 'pong' });
});

await app.start();
```

- `ack()` нужно вызывать в течение 3 секунд.
- Для долгой работы используй `respond` с `response_url` или `chat.postMessage` после `ack`.
- `respond` с `response_type: 'ephemeral'` отвечает только автору команды.

## Block Kit

Block Kit — конструктор сообщений из блоков.

| Блок      | Назначение                  | Ограничения            |
|-----------|-----------------------------|------------------------|
| `header`  | Заголовок                   | до 150 символов        |
| `section` | Текст, поля, аксессуар      | текст до 3000 символов |
| `context` | Мелкий текст и иконки       | до 10 элементов        |
| `divider` | Разделитель                 | —                      |
| `actions` | Кнопки, select, datepicker  | до 25 элементов        |
| `input`   | Поле ввода в модальном окне | до 10 на окно          |
| `image`   | Изображение                 | публичный URL          |

Ограничения: до 50 блоков в сообщении, до 100 блоков в модальном окне, до 5 кнопок в `actions` для одного ряда.
Текст в `mrkdwn` поддерживает `*жирный*`, `_курсив_`, `` `код` ``, `<https://example.com|ссылка>`.
Не смешивай `mrkdwn` и обычный текст в одном поле без необходимости.

## Slash-команды и интерактивность

- Slash-команда должна ответить `ack()` за 3 секунды.
- Для отложенного ответа используй `response_url`, который действует ограниченное время.
- Кнопки и меню присылают `payload` в `interactivity` Request URL.
- Для модальных окон используй `views.open`, `views.update`, `views.push`.
- `trigger_id` действует 3 секунды; не откладывай открытие окна.
- Проверяй `team_id` и `user_id`, если бот установлен в нескольких рабочих пространствах.

## Установка и распространение

- Для одного рабочего пространства достаточно внутренней установки.
- Для публикации в каталоге нужна OAuth-установка, проверка Slack и поддержка нескольких рабочих пространств.
- Храни токены по рабочему пространству, а не один общий токен на всех.
- При отзыве токена обрабатывай `token_revoked` и предлагай переустановку.

## Лимиты

| Что                    | Ограничение                                       |
|------------------------|---------------------------------------------------|
| Ответ на событие       | 3 секунды                                         |
| `trigger_id`           | 3 секунды                                         |
| Блоки в сообщении      | до 50                                             |
| Блоки в модальном окне | до 100                                            |
| `section`              | до 3000 символов                                  |
| `header`               | до 150 символов                                   |
| `actions`              | до 25 элементов                                   |
| Частота Web API        | зависит от метода, от 1 до 100+ запросов в минуту |

При `429` Slack возвращает `Retry-After`. Используй очередь и повтор с задержкой, не повторяй сразу.

## Безопасность

- Проверяй подпись каждого HTTP-запроса.
- Не логируй токены и содержимое приватных каналов.
- Ограничивай админские команды по `user_id`.
- Проверяй, что бот вызван в ожидаемом рабочем пространстве.
- Не выполняй команды из пользовательского текста.
- Для внешних ссылок и файлов проверяй домен и не делай запросы к внутренней сети.

## Тестирование

- Проверь команду без нужного scope: должна быть понятная ошибка, а не падение.
- Проверь повторную доставку события.
- Проверь `ack` при долгой операции.
- Проверь модальное окно с неверными данными и повторным открытием.
- Проверь установку в новом рабочем пространстве и хранение токенов.

## Частые ошибки

| Симптом                       | Причина                                | Решение                             |
|-------------------------------|----------------------------------------|-------------------------------------|
| `invalid_auth`                | Неверный или отозванный токен          | Переустанови приложение             |
| `missing_scope`               | Не хватает разрешения                  | Добавь scope и переустанови         |
| `operation_timeout`           | Нет `ack` за 3 секунды                 | Вызови `ack` до тяжёлой работы      |
| Подпись не проходит           | Считаешь подпись по распарсенному телу | Используй сырое тело запроса        |
| Модальное окно не открывается | Истёк `trigger_id`                     | Открывай окно сразу после `ack`     |
| Сообщение не отображается     | Неверная структура Block Kit           | Проверь блоки в Block Kit Builder   |
| Ответ виден всем              | Не указан `response_type: 'ephemeral'` | Добавь ephemeral для личных ответов |
