# Конвертация и проверка

Конвертация офисных форматов редко бывает идеальной.
Планируй проверку так же тщательно, как саму конвертацию.

## LibreOffice headless

LibreOffice — самый предсказуемый способ конвертировать DOCX, XLSX, PPTX и ODF в PDF и обратно.

```bash
soffice --headless --convert-to pdf --outdir output input.docx
soffice --headless --convert-to pdf --outdir output input.xlsx
soffice --headless --convert-to pdf --outdir output input.pptx
```

Полезные параметры:

| Параметр                                       | Назначение                                     |
|------------------------------------------------|------------------------------------------------|
| `--headless`                                   | Без графического интерфейса                    |
| `--convert-to <формат>`                        | Целевой формат, например `pdf`, `docx`, `xlsx` |
| `--outdir <директория>`                        | Куда сохранить результат                       |
| `--infilter=<фильтр>`                          | Явно указать входной фильтр                    |
| `--outfilter=<фильтр>`                         | Явно указать выходной фильтр                   |
| `-env:UserInstallation=file:///tmp/lo-profile` | Отдельный профиль для параллельных запусков    |

Правила:

1. Для параллельных конвертаций используй отдельный профиль на процесс, иначе LibreOffice блокирует запуск.
2. Не запускай конвертацию от `root` без необходимости.
3. Установи шрифты в образ или систему, иначе кириллица и фирменные шрифты подменятся.
4. Проверяй код возврата и наличие выходного файла.
5. Для больших файлов дай процессу больше памяти и времени.

```bash
soffice --headless \
  -env:UserInstallation=file:///tmp/lo-profile-$$ \
  --convert-to pdf \
  --outdir output \
  input.docx
```

## Pandoc

Pandoc удобен для текстовых форматов и DOCX.

```bash
pandoc report.md -o report.docx
pandoc report.docx -t markdown -o report.md
pandoc report.md -o report.pdf --pdf-engine=xelatex
```

- Для DOCX можно указать `--reference-doc=template.docx`, чтобы взять стили из шаблона.
- Для PDF нужен LaTeX-движок или `--pdf-engine=weasyprint`.
- Pandoc не сохраняет сложную вёрстку DOCX и не работает с макросами.
- Для таблиц и формул проверяй результат отдельно.

```bash
pandoc report.md \
  --reference-doc=corporate.docx \
  -o report.docx
```

## Выбор способа

| Из       | В        | Инструмент                                     | Качество                           |
|----------|----------|------------------------------------------------|------------------------------------|
| DOCX     | PDF      | LibreOffice                                    | Высокое, зависит от шрифтов        |
| XLSX     | PDF      | LibreOffice                                    | Высокое, проверь масштаб печати    |
| PPTX     | PDF      | LibreOffice                                    | Высокое, проверь шрифты и эффекты  |
| DOCX     | Markdown | Pandoc                                         | Хорошее для текста, теряет вёрстку |
| Markdown | DOCX     | Pandoc                                         | Хорошее при наличии reference-doc  |
| PDF      | DOCX     | LibreOffice, Abbyy, специализированные сервисы | Низкое, требует ручной правки      |
| PDF      | текст    | `pypdf`, `pdfplumber`                          | Зависит от структуры PDF           |
| ODF      | OOXML    | LibreOffice                                    | Хорошее                            |

Конвертация PDF в DOCX не восстанавливает исходные стили и структуру.
Если нужен редактируемый документ, лучше запросить исходник.

## Шрифты

- В Linux-образе установи `fonts-dejavu`, `fonts-liberation`, `fonts-noto` и корпоративные шрифты.
- Для кириллицы подходят DejaVu Sans, Liberation Serif, Noto Sans.
- Проверь, что в документе не осталось шрифтов, которых нет в системе.
- В DOCX можно встроить шрифты, но не все редакторы это поддерживают.
- Для PDF встраивай шрифты, иначе на другой машине вид изменится.

```dockerfile
RUN apt-get update && apt-get install -y --no-install-recommends \
    libreoffice-writer \
    libreoffice-calc \
    libreoffice-impress \
    fonts-dejavu \
    fonts-liberation \
    fonts-noto \
    && rm -rf /var/lib/apt/lists/*
```

## Проверка результата

### Программная

- Открой файл библиотекой и проверь, что он читается.
- Сравни число страниц или листов с ожидаемым.
- Извлеки текст и сравни ключевые фрагменты.
- Проверь, что таблицы и изображения на месте.
- Проверь метаданные и размер файла.

```python
from pypdf import PdfReader

reader = PdfReader("output/report.pdf")
assert len(reader.pages) > 0
text = "\n".join(page.extract_text() or "" for page in reader.pages)
assert "Итоги квартала" in text
```

### Визуальная

- Открой результат в LibreOffice, Word, Excel или PowerPoint.
- Просмотри все страницы или слайды.
- Проверь переносы, отступы, границы таблиц, шрифты и кириллицу.
- Экспортируй в PDF и сравни с эталоном.
- Для регрессии сохраняй эталонные PDF и сравнивай постранично.

### Приёмочная

- Проверь документ на той версии офисного пакета, которая есть у пользователя.
- Проверь печать и поля страницы.
- Проверь, что ссылки и оглавление работают.
- Проверь, что формулы пересчитались.

## Автоматизация в CI

1. Установи LibreOffice и шрифты в образ.
2. Запускай конвертацию в отдельной директории.
3. Проверяй код возврата и наличие файла.
4. Сохраняй логи и артефакты при падении.
5. Не запускай несколько конвертаций с одним профилем LibreOffice.
6. Ограничивай время выполнения.

```yaml
- name: Convert DOCX to PDF
  run: |
    mkdir -p output
    soffice --headless \
      -env:UserInstallation=file:///tmp/lo-profile-ci \
      --convert-to pdf \
      --outdir output \
      report.docx
    test -f output/report.pdf
```

## Ограничения окружения

- Разные версии LibreOffice дают разную вёрстку.
- Отсутствие шрифтов приводит к подмене и сдвигам.
- Локаль влияет на форматы чисел и дат.
- В контейнере нет доступа к пользовательским шрифтам хоста.
- Макросы и внешние связи могут не работать без дополнительных настроек.
- Пароли и защита документов могут блокировать конвертацию.

## Частые ошибки

| Симптом                    | Причина                             | Решение                                |
|----------------------------|-------------------------------------|----------------------------------------|
| LibreOffice зависает       | Один профиль на несколько процессов | Отдельный `UserInstallation`           |
| Кириллица в квадратах      | Нет шрифта                          | Установи шрифты в систему или образ    |
| Съехала вёрстка            | Другая версия офисного пакета       | Проверяй на целевой версии             |
| Пустой PDF                 | Ошибка конвертации                  | Проверь код возврата и логи            |
| Формулы не пересчитаны     | Нет пересчёта при конвертации       | Открой в Excel или настрой LibreOffice |
| PDF->DOCX не редактируется | PDF не хранит структуру             | Запроси исходный DOCX                  |
| Разные форматы чисел       | Локаль                              | Явно задавай локаль и формат           |
