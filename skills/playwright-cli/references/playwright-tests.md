# Запуск тестов Playwright

Чтобы запустить тесты Playwright, используй команду `npx playwright test` или скрипт менеджера пакетов. Чтобы интерактивный HTML-отчёт не открывался, задай переменную окружения `PLAYWRIGHT_HTML_OPEN=never`.

```bash
# запустить все тесты
PLAYWRIGHT_HTML_OPEN=never npx playwright test

# запустить все тесты через свой npm-скрипт
PLAYWRIGHT_HTML_OPEN=never npm run special-test-command
```

# Отладка тестов Playwright

Чтобы отладить падающий тест Playwright, запусти его с опцией `--debug=cli`. Эта команда приостановит тест на старте и напечатает инструкции по отладке.

**ВАЖНО**: запускай команду в фоне и проверяй вывод, пока не появится «Debugging Instructions». Не забудь остановить команду, когда закончишь.

Как только появятся инструкции с именем сессии, подключись к сессии через `playwright-cli` и исследуй страницу.

```bash
# запустить тест
PLAYWRIGHT_HTML_OPEN=never npx playwright test --debug=cli
# ...
# ... инструкции по отладке для сессии "tw-abcdef" ...
# ...

# подключиться к тесту
playwright-cli attach tw-abcdef
```

Держи тест запущенным в фоне, пока исследуешь и ищешь исправление.
Тест приостановлен на старте, поэтому пройди по шагам или остановись в том месте,
где проблема наиболее вероятна.

Каждое действие, которое ты выполняешь через `playwright-cli`, порождает соответствующий код Playwright на TypeScript.
Этот код появляется в выводе, и его можно скопировать прямо в тест. Чаще всего нужно обновить конкретный локатор или ожидание, но это может быть и баг в приложении. Решай сам.

После исправления теста останови фоновый запуск. Запусти снова, чтобы проверить, что тест проходит.
