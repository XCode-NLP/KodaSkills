# Трассировка

Снимай подробные трассы выполнения для отладки и анализа. Трассы включают снимки DOM, скриншоты, сетевую активность и логи консоли.

## Базовое использование

```bash
# открыть браузер (для трассировки нужен открытый браузер)
playwright-cli open

# начать запись трассы
playwright-cli tracing-start

# выполнить действия
playwright-cli goto https://example.com
playwright-cli click e1
playwright-cli fill e2 "test"

# остановить запись трассы
playwright-cli tracing-stop
```

## Файлы трассы

Когда ты начинаешь трассировку, Playwright создаёт директорию `.playwright-cli/traces/` с несколькими файлами:

### `trace-{timestamp}.trace`

**Журнал действий** — основной файл трассы, содержащий:
- каждое выполненное действие (клики, заполнения, переходы);
- снимки DOM до и после каждого действия;
- скриншоты на каждом шаге;
- информацию о времени выполнения;
- сообщения консоли;
- исходные расположения.

### `trace-{timestamp}.network`

**Журнал сети** — полная сетевая активность:
- все HTTP-запросы и ответы;
- заголовки и тела запросов;
- заголовки и тела ответов;
- тайминги (DNS, соединение, TLS, TTFB, загрузка);
- размеры ресурсов;
- неудавшиеся запросы и ошибки.

### `resources/`

**Директория ресурсов** — закэшированные ресурсы:
- изображения, шрифты, таблицы стилей, скрипты;
- тела ответов для воспроизведения;
- ресурсы, нужные для восстановления состояния страницы.

## Что фиксируют трассы

| Категория | Подробности |
|----------|---------|
| **Действия** | Клики, заполнения, наведения, ввод с клавиатуры, переходы |
| **DOM** | Полный снимок DOM до и после каждого действия |
| **Скриншоты** | Визуальное состояние на каждом шаге |
| **Сеть** | Все запросы, ответы, заголовки, тела, тайминги |
| **Консоль** | Все сообщения console.log, warn, error |
| **Тайминги** | Точное время каждой операции |

## Сценарии использования

### Отладка неудавшихся действий

```bash
playwright-cli open
playwright-cli tracing-start
playwright-cli goto https://app.example.com

# этот клик падает — почему?
playwright-cli click e5

playwright-cli tracing-stop
# открой трассу, чтобы увидеть состояние DOM в момент попытки клика
```

### Анализ производительности

```bash
playwright-cli open
playwright-cli tracing-start
playwright-cli goto https://slow-site.com
playwright-cli tracing-stop

# посмотри водопад сетевых запросов, чтобы найти медленные ресурсы
```

### Сбор доказательств

```bash
# запиши полный пользовательский сценарий для документации
playwright-cli open
playwright-cli tracing-start

playwright-cli goto https://app.example.com/checkout
playwright-cli fill e1 "4111111111111111"
playwright-cli fill e2 "12/25"
playwright-cli fill e3 "123"
playwright-cli click e4

playwright-cli tracing-stop
# трасса показывает точную последовательность событий
```

## Трасса, видео и скриншот

| Возможность | Трасса | Видео | Скриншот |
|---------|-------|-------|------------|
| **Формат** | файл .trace | видео .webm | изображение .png/.jpeg |
| **Инспекция DOM** | Да | Нет | Нет |
| **Подробности сети** | Да | Нет | Нет |
| **Пошаговое воспроизведение** | Да | Непрерывное | Один кадр |
| **Размер файла** | Средний | Большой | Маленький |
| **Лучше всего для** | Отладки | Демонстраций | Быстрой фиксации |

## Рекомендации

### 1. Начинай трассировку до появления проблемы

```bash
# трассируй весь сценарий, а не только падающий шаг
playwright-cli open
playwright-cli tracing-start
playwright-cli goto https://example.com
# ... все шаги, ведущие к проблеме ...
playwright-cli tracing-stop
```

### 2. Удаляй старые трассы

Трассы могут занимать много места на диске:

```bash
# удалить трассы старше 7 дней
find .playwright-cli/traces -mtime +7 -delete
```

## Ограничения

- Трассировка добавляет накладные расходы к автоматизации.
- Большие трассы могут занимать много места на диске.
- Некоторое динамическое содержимое может воспроизводиться не идеально.
