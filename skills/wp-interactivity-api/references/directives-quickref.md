# Краткая памятка по директивам (обзор)

Частые директивы, которые нужно узнавать в разметке:

- `data-wp-interactive`: объявляет интерактивную область (и часто пространство имён
  хранилища);
- `data-wp-context`: передаёт отрисованный на сервере контекст и состояние;
- `data-wp-on--event`: подключает обработчики событий (например, `click`, `submit`);
- `data-wp-on-async--event`: асинхронные обработчики событий (предпочтительны для
  большинства действий);
- `data-wp-bind--attr`: привязывает атрибуты DOM к состоянию;
- `data-wp-class--name`: переключает CSS-классы в зависимости от состояния.

Используй их как поисковые ориентиры при разборе ошибок.

## Уникальные идентификаторы директив (WordPress 6.9+)

HTML не допускает повторяющихся атрибутов. Чтобы подключить несколько обработчиков
одного типа из разных плагинов, используй разделитель `---`:

```html
<button
  data-wp-on--click---plugin-a="actions.handleA"
  data-wp-on--click---plugin-b="actions.handleB"
>
```

Сработают оба обработчика. Идентификатор после `---` должен быть уникальным в пределах
элемента.

## Устаревшая директива

- **`data-wp-ignore`**: устарела в WordPress 6.9. Она должна была предотвращать
  гидрацию области, но ломала наследование контекста и клиентскую навигацию. Будет
  удалена в будущих версиях. Не используй её.
