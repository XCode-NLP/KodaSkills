# Поиск навыков

Этот навык помогает находить и устанавливать навыки из открытой экосистемы агентских навыков.

## Когда использовать

Используй навык, когда пользователь:

- спрашивает «как сделать X», а X может быть типовой задачей с готовым навыком
- говорит «найди навык для X» или «есть ли навык для X»
- спрашивает «ты умеешь X», где X — специализированная возможность
- хочет расширить возможности агента
- хочет найти инструменты, шаблоны или сценарии работы
- говорит, что ему нужна помощь в конкретной области (дизайн, тестирование, развёртывание и подобное)

## Что такое командная строка навыков

Командная строка навыков (`npx skills`) — менеджер пакетов открытой экосистемы агентских навыков. Навыки — модульные пакеты, которые расширяют возможности агента специальными знаниями, сценариями работы и инструментами.

**Основные команды:**

- `npx skills find [query] [--owner <owner>]` — поиск навыков в интерактивном режиме или по ключевым словам, при необходимости в пределах указанного владельца на GitHub
- `npx skills add <package>` — установка навыка с GitHub или из другого источника
- `npx skills update` — обновление всех установленных навыков

**Каталог навыков:** https://skills.sh/

## Как помогать пользователю искать навыки

### Шаг 1: пойми, что нужно

Когда пользователь просит помочь с чем-то, определи:

1. область (например, React, тестирование, дизайн, развёртывание)
2. конкретную задачу (например, написать тесты, сделать анимацию, проверить пул-реквест)
3. достаточно ли задача распространена, чтобы для неё существовал навык

### Шаг 2: сначала посмотри таблицу лидеров

Прежде чем запускать поиск в командной строке, посмотри [таблицу лидеров skills.sh](https://skills.sh/): возможно, известный навык для этой области уже есть. Таблица упорядочивает навыки по общему числу установок, показывая самые популярные и проверенные на практике.

Например, среди ведущих навыков для веб-разработки:

- `vercel-labs/agent-skills` — React, Next.js, веб-дизайн (более 100 тыс. установок у каждого)
- `anthropics/skills` — фронтенд-дизайн, обработка документов (более 100 тыс. установок)

### Шаг 3: ищи навыки

Если в таблице лидеров нужного нет, запусти поиск:

```bash
npx skills find [query] [--owner <owner>]
```

Например:

- пользователь спрашивает «как ускорить приложение на React?» → `npx skills find react performance`
- «поможешь с проверкой пул-реквестов?» → `npx skills find pr review`
- «мне нужно сделать журнал изменений» → `npx skills find changelog`

### Шаг 4: проверь качество до рекомендации

**Не рекомендуй навык только по результатам поиска.** Всегда проверяй:

1. **Число установок** — предпочитай навыки с 1000+ установок. К навыкам с числом меньше 100 относись осторожно.
2. **Репутация источника** — официальные источники (`vercel-labs`, `anthropics`, `microsoft`) надёжнее неизвестных авторов.
3. **Звёзды на GitHub** — посмотри репозиторий-источник. К навыку из репозитория с числом звёзд меньше 100 относись скептически.

### Шаг 5: покажи варианты

Найдя подходящие навыки, покажи пользователю:

1. название навыка и что он делает
2. число установок и источник
3. команду установки
4. ссылку на страницу навыка на skills.sh

Пример ответа:

```
Нашёл навык, который может помочь! Навык "react-best-practices" содержит
рекомендации по производительности React и Next.js от Vercel Engineering.
(185 тыс. установок)

Установка:
npx skills add vercel-labs/agent-skills@react-best-practices

Подробнее: https://skills.sh/vercel-labs/agent-skills/react-best-practices
```

### Шаг 6: предложи установить

Если пользователь согласен, установи навык за него:

```bash
npx skills add <owner/repo@skill> -g -y
```

Флаг `-g` устанавливает навык глобально (для пользователя), `-y` пропускает подтверждения.

## Частые категории навыков

При поиске учитывай эти категории:

| Категория | Примеры запросов |
| --------------- | ---------------------------------------- |
| Веб-разработка | react, nextjs, typescript, css, tailwind |
| Тестирование | testing, jest, playwright, e2e |
| Развёртывание и эксплуатация | deploy, docker, kubernetes, ci-cd |
| Документация | docs, readme, changelog, api-docs |
| Качество кода | review, lint, refactor, best-practices |
| Дизайн | ui, ux, design-system, accessibility |
| Продуктивность | workflow, automation, git |

## Советы для результативного поиска

1. **Используй конкретные ключевые слова**: «react testing» лучше, чем просто «testing».
2. **Пробуй другие формулировки**: если «deploy» не дал результата, попробуй «deployment» или «ci-cd».
3. **Проверяй популярные источники**: многие навыки приходят из `vercel-labs/agent-skills` и `ComposioHQ/awesome-claude-skills`.

## Когда ничего не нашлось

Если подходящих навыков нет:

1. скажи, что готового навыка не нашлось
2. предложи решить задачу своими силами, используя общие возможности
3. подскажи, что пользователь может создать собственный навык командой `npx skills init`

Пример:

```
Я искал навыки по запросу "xyz", но ничего не нашёл.
Я всё равно могу помочь с этой задачей сам! Продолжаем?

Если ты делаешь это часто, можно создать собственный навык:
npx skills init my-xyz-skill
```
