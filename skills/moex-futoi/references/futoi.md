# Справочник по FUTOI MOEXAlgo

## Импорты и авторизация

```bash
python -m pip install "moexalgo[dataframe]" python-dotenv
```

```python
import os
from dotenv import load_dotenv
from moexalgo import session, Market, Ticker

load_dotenv()
session.TOKEN = os.environ["APIKEY"]
```

На бесплатном токене «Стартовый» FUTOI отстаёт на `T - 15 дней`; `Promo` даёт более полный и онлайн-доступ в рамках текущей подписки. FUTOI относится только к фьючерсам: это не акции, не валюта, не опционы, не данные отдельных трейдеров и не точное позиционирование FIZ и YUR по одному контракту.

## Сигнатуры методов

```text
Market("FO").futoi(date=None, native=False)
Ticker(...).futoi(start=None, end=None, native=False)
```

Передавай даты явно. В текущем коде репозитория пропуск `date` в методах рынка или `start` и `end` в методах тикера приводит к `prepare_from_till_dates(...)`, который выбрасывает исключение, а не молча берёт сегодняшнюю дату.

FUTOI реализован только для срочного рынка. `Ticker(...).futoi(...)` разрешает тикер в идентификатор FUTOI, который использует эндпоинт. Вечные фьючерсы вроде `USDRUBF`, `EURRUBF`, `CNYRUBF`, `IMOEXF`, `GLDRUBF`, `SBERF` и `GAZPF` библиотека обрабатывает особым образом.

## Оговорки по параметрам библиотеки

Методы FUTOI в библиотеке не дают `latest` и `offset`. Для больших промежутков итерируй по явным датам или диапазонам на уровне библиотеки. Прямой REST-эндпоинт FUTOI бери, когда пользователю нужны сырые средства управления вроде `latest`, `start` или `limit` конкретного маршрута.

## Примеры

Все фьючерсы за одну дату:

```python
fo = Market("FO")
df = fo.futoi(date="2025-01-10")
```

Диапазон по одному инструменту:

```python
si = Ticker("SiH5")
df = si.futoi(start="2025-01-10", end="2025-01-10")
```

По умолчанию используй DataFrame. Если пользователь явно просит итераторы или словари, упомяни `native=True` как запасной выход.

## Поля

| Поле | Значение |
| --- | --- |
| `sess_id` | Идентификатор торговой сессии |
| `seqnum` | Технический порядковый номер |
| `tradedate` | Дата |
| `trade_session_date` | Дата торговой сессии, если есть |
| `tradetime` | Время снимка |
| `ticker` | Код базового актива или инструмента |
| `clgroup` | `FIZ` — физические лица, `YUR` — юридические |
| `pos` | Нетто-позиция: длинные минус короткие |
| `pos_long` | Валовые длинные открытые позиции в контрактах |
| `pos_short` | Валовые короткие открытые позиции в контрактах; сырые значения могут быть отрицательными |
| `pos_long_num` | Число участников с длинными позициями |
| `pos_short_num` | Число участников с короткими позициями |
| `systime` | Время загрузки или системы, если есть |

## Оговорки по агрегации

- FUTOI агрегирует активные серии контрактов по базовому активу или инструменту.
- Позиции участника сначала сальдируются в рамках одного контракта.
- Участник может попасть и в длинные, и в короткие, если он длинный по одному контракту и короткий по другому.
- Нулевые нетто-позиции исключаются из подсчёта участников.
- Не выводи личности участников и точное разбиение FIZ и YUR по одному контракту из агрегированных строк.

## Работа с DataFrame

Строй таблицу или график из полей, которые запросил пользователь. Начни с создания столбца метки времени, когда выводу нужны сортировка или график:

```python
df = Market("FO").futoi(date="2025-01-10")
df["datetime"] = df["tradedate"].astype(str) + " " + df["tradetime"].astype(str)
```

Для передачи отбирай запрошенные поля:

```python
df = Ticker("SiH5").futoi(start="2025-01-10", end="2025-01-10")
table = df[["tradedate", "tradetime", "ticker", "clgroup", "pos", "pos_long", "pos_short"]]
```

Группировки и сводные таблицы pandas применяй только когда пользователь просит агрегат:

```python
latest_time = df["tradetime"].max()
latest = df[df["tradetime"] == latest_time]
by_group = latest.groupby(["ticker", "clgroup"], as_index=False)["pos"].sum()
```

Защищайся от деления на ноль и отсутствующих строк при расчёте отношений.
