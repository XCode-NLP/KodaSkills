# Документация платформы 1С — bsl-platform-help

MCP-сервер **bsl-platform-help** даёт доступ к документации API платформы 1С:Предприятие. Поддерживает поиск по ключевым словам, семантический (эмбеддинги) и гибридный (слияние RRF с реранкером).

## Когда использовать

- проверка существования встроенных процедур, функций, методов и свойств;
- поиск методов и типов по описанию на естественном языке;
- получение сигнатуры и параметров метода;
- просмотр всех членов типа (методы и свойства);
- получение конструкторов типа;
- проверка версии платформы.

## Инструменты

### `search` — поиск по документации (основной)

Заменяет `docsearch`. Поддерживает три режима поиска.

| Параметр | Обязательный | Описание |
|---|:---:|---|
| `query` | да | Запрос (русский или английский, CamelCase, естественный язык) |
| `mode` | нет | `keyword`, `semantic` или `hybrid` (по умолчанию `hybrid`) |
| `type` | нет | Фильтр: `method`, `property`, `type` |
| `limit` | нет | Максимум результатов (от 1 до 50, по умолчанию 10) |

Примеры:

- `search("ТекущаяДата")` — точное ключевое слово;
- `search("как записать файл на диск", mode="semantic")` — семантический поиск;
- `search("HTTP запрос POST", mode="hybrid")` — гибридный поиск.

### `info` — подробные сведения

Полное описание элемента API: сигнатура, параметры, возвращаемое значение, описание.

| Параметр | Обязательный | Описание |
|---|:---:|---|
| `name` | да | Точное имя (русское или английское): `НайтиПоСсылке`, `FindByRef` |
| `type` | да | `method`, `property`, `type` |

### `get_member` — метод или свойство типа

Сведения о конкретном члене конкретного типа.

| Параметр | Обязательный | Описание |
|---|:---:|---|
| `type_name` | да | Имя типа: `ТаблицаЗначений`, `ValueTable` |
| `member_name` | да | Имя члена: `Добавить`, `Add` |

### `get_members` — все члены типа

Полный список методов и свойств типа.

| Параметр | Обязательный | Описание |
|---|:---:|---|
| `type_name` | да | Имя типа |

### `get_constructors` — конструкторы типа

Сигнатуры конструкторов для создания экземпляров типа.

| Параметр | Обязательный | Описание |
|---|:---:|---|
| `type_name` | да | Имя типа |

### `get_platform_info` — версия платформы

Текущая версия, путь к HBK, список доступных версий. Параметров нет.

## Типичные сценарии

### Проверка встроенной функции

1. `search("ТекущаяДата")` — найти.
2. `info(name="ТекущаяДата", type="method")` — получить детали.

### Изучение типа

1. `get_members("ТаблицаЗначений")` — все методы и свойства.
2. `get_member("ТаблицаЗначений", "Добавить")` — детали конкретного метода.
3. `get_constructors("ТаблицаЗначений")` — как создать экземпляр.

### Поиск по описанию

1. `search("записать данные в XML файл", mode="semantic")` — семантический поиск.
