## Приведение типов (ВЫРАЗИТЬ)

Явно приводит значение к конкретному типу. **Необходимо для полей составного типа.**

```
ВЫРАЗИТЬ(<выражение> КАК <тип>)
```

Примеры:

```
// Сузить составную ссылку до конкретного типа:
ВЫРАЗИТЬ(Регистратор КАК Документ.РеализацияТоваровУслуг)

// Привести число к заданной точности:
ВЫРАЗИТЬ(Сумма КАК ЧИСЛО(15, 2))

// Привести к строке:
ВЫРАЗИТЬ(Код КАК СТРОКА(10))

// Привести к булеву:
ВЫРАЗИТЬ(Значение КАК БУЛЕВО)

// Привести к дате:
ВЫРАЗИТЬ(Значение КАК ДАТА)
```

Примитивные типы для приведения: `ЧИСЛО(<длина>, <точность>)`, `СТРОКА(<длина>)`, `БУЛЕВО`, `ДАТА`.

## Агрегатные функции

Используются с `СГРУППИРОВАТЬ ПО`, `ИМЕЮЩИЕ`, `ИТОГИ` и `УПОРЯДОЧИТЬ ПО`.

| Функция | Описание | Пример |
|----------|-------------|---------|
| `СУММА(<поле>)` | Сумма | `СУММА(Количество)` |
| `СРЕДНЕЕ(<поле>)` | Среднее | `СРЕДНЕЕ(Цена)` |
| `МИНИМУМ(<поле>)` | Минимальное значение | `МИНИМУМ(Дата)` |
| `МАКСИМУМ(<поле>)` | Максимальное значение | `МАКСИМУМ(Дата)` |
| `КОЛИЧЕСТВО(*)` | Количество всех строк | `КОЛИЧЕСТВО(*)` |
| `КОЛИЧЕСТВО(<поле>)` | Количество значений, отличных от NULL | `КОЛИЧЕСТВО(Контрагент)` |
| `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ <поле>)` | Количество различных значений | `КОЛИЧЕСТВО(РАЗЛИЧНЫЕ Контрагент)` |

**Правило:** не используй поля группировки внутри агрегатных функций (кроме полей вложенных таблиц).

## Функции даты и времени

### Извлечение компонентов

| Функция | Возвращает | Пример |
|----------|---------|---------|
| `ГОД(<дата>)` | Год | `ГОД(Дата)` → 2024 |
| `КВАРТАЛ(<дата>)` | Квартал (1–4) | `КВАРТАЛ(Дата)` → 1 |
| `МЕСЯЦ(<дата>)` | Месяц (1–12) | `МЕСЯЦ(Дата)` → 3 |
| `ДЕНЬГОДА(<дата>)` | День года (1–366) | `ДЕНЬГОДА(Дата)` |
| `ДЕНЬ(<дата>)` | День месяца (1–31) | `ДЕНЬ(Дата)` → 15 |
| `ДЕНЬНЕДЕЛИ(<дата>)` | День недели (1 — понедельник, 7 — воскресенье) | `ДЕНЬНЕДЕЛИ(Дата)` |
| `ЧАС(<дата>)` | Час (0–23) | `ЧАС(Дата)` |
| `МИНУТА(<дата>)` | Минута (0–59) | `МИНУТА(Дата)` |
| `СЕКУНДА(<дата>)` | Секунда (0–59) | `СЕКУНДА(Дата)` |

### Границы периода

| Функция | Описание |
|----------|-------------|
| `НАЧАЛОПЕРИОДА(<дата>, <период>)` | Начало периода. `<период>`: МИНУТА, ЧАС, ДЕНЬ, НЕДЕЛЯ, МЕСЯЦ, КВАРТАЛ, ГОД, ДЕКАДА, ПОЛУГОДИЕ |
| `КОНЕЦПЕРИОДА(<дата>, <период>)` | Конец периода (те же варианты периода) |

```
НАЧАЛОПЕРИОДА(Дата, МЕСЯЦ)    // первый день месяца
КОНЕЦПЕРИОДА(Дата, КВАРТАЛ)    // последний момент квартала
```

### Арифметика дат

| Функция | Описание |
|----------|-------------|
| `ДОБАВИТЬКДАТЕ(<дата>, <период>, <количество>)` | Прибавить N периодов к дате |
| `РАЗНОСТЬДАТ(<дата1>, <дата2>, <период>)` | Разница между датами в периодах |

```
ДОБАВИТЬКДАТЕ(Дата, МЕСЯЦ, 3)         // прибавить 3 месяца
ДОБАВИТЬКДАТЕ(Дата, ДЕНЬ, -7)          // отнять 7 дней
РАЗНОСТЬДАТ(ДатаНач, ДатаКон, ДЕНЬ)   // дней между датами
```

Варианты периода: `СЕКУНДА`, `МИНУТА`, `ЧАС`, `ДЕНЬ`, `МЕСЯЦ`, `КВАРТАЛ`, `ГОД`.

## Строковые функции

| Функция | Описание | Пример |
|----------|-------------|---------|
| `ПОДСТРОКА(<строка>, <начало>, <длина>)` | Подстрока (нумерация с 1) | `ПОДСТРОКА(Код, 1, 3)` |
| `ДЛИНАСТРОКИ(<строка>)` | Длина строки | `ДЛИНАСТРОКИ(Наименование)` |
| `ЛЕВ(<строка>, <n>)` | N символов слева | `ЛЕВ(Код, 5)` |
| `ПРАВ(<строка>, <n>)` | N символов справа | `ПРАВ(Код, 3)` |
| `СТРЗАМЕНИТЬ(<строка>, <найти>, <заменить>)` | Заменить подстроку | `СТРЗАМЕНИТЬ(Имя, " ", "_")` |
| `СОКРЛ(<строка>)` | Убрать ведущие пробелы | `СОКРЛ(Код)` |
| `СОКРП(<строка>)` | Убрать хвостовые пробелы | `СОКРП(Код)` |
| `СОКРЛП(<строка>)` | Убрать пробелы с обеих сторон | `СОКРЛП(Код)` |
| `ВРЕГ(<строка>)` | Верхний регистр | `ВРЕГ(Наименование)` |
| `НРЕГ(<строка>)` | Нижний регистр | `НРЕГ(Наименование)` |

**Замечание:** `ПОДСТРОКА` в основном условии ГДЕ мешает использованию индекса. Применяй только в дополнительных условиях.

## Функции типов

| Функция | Описание | Пример |
|----------|-------------|---------|
| `ТИПЗНАЧЕНИЯ(<выражение>)` | Возвращает тип значения | `ТИПЗНАЧЕНИЯ(Ссылка)` |
| `ТИП(<имя_типа>)` | Возвращает объект типа для сравнения | `ТИП("Справочник.Контрагенты")` |
| `ССЫЛКА` | Оператор проверки типа ссылки | `Рег ССЫЛКА Документ.Реализация` |
| `ПРЕДСТАВЛЕНИЕ(<выражение>)` | Человекочитаемое представление ссылки | `ПРЕДСТАВЛЕНИЕ(Контрагент)` |
| `УНИКАЛЬНЫЙИДЕНТИФИКАТОР(<ссылка>)` | UUID ссылки строкой | `УНИКАЛЬНЫЙИДЕНТИФИКАТОР(Ссылка)` |

```
// Фильтр по типу значения:
ГДЕ ТИПЗНАЧЕНИЯ(Субконто1) = ТИП("Справочник.Контрагенты")
```

## Логические функции и функции NULL

| Функция | Описание |
|----------|-------------|
| `ЕСТЬNULL(<выражение>, <значение_по_умолчанию>)` | Возвращает значение по умолчанию, если выражение NULL (аналог COALESCE из двух аргументов) |

```
ЕСТЬNULL(Ост.КоличествоОстаток, 0)
```

**ВЫБОР:** см. [query-syntax-reference.md](query-syntax-reference.md#выбор).

## Математические функции

| Функция | Описание |
|----------|-------------|
| `ОКР(<число>, <точность>)` | Округлить до N знаков после запятой |
| `ЦЕЛ(<число>)` | Отбросить дробную часть (в сторону нуля) |

```
ОКР(Сумма / Количество, 2)   // округлить до 2 знаков
ЦЕЛ(Сумма / 100)             // целая часть
```

**Точность вычислений:** не менее 8 знаков после запятой. Результаты могут немного различаться между СУБД.

## Тригонометрические функции

Стандартные математические функции с той же семантикой, что и в большинстве языков.

| Функция | Описание |
|----------|-------------|
| `SIN(<x>)` | Синус (радианы) |
| `COS(<x>)` | Косинус |
| `TAN(<x>)` | Тангенс |
| `ASIN(<x>)` | Арксинус |
| `ACOS(<x>)` | Арккосинус |
| `ATAN(<x>)` | Арктангенс |

## Специальные функции

| Функция | Описание |
|----------|-------------|
| `EXP(<x>)` | e в степени x |
| `LOG(<x>)` | Натуральный логарифм |
| `LOG10(<x>)` | Десятичный логарифм |
| `POW(<основание>, <показатель>)` | Возведение в степень |
| `SQRT(<x>)` | Квадратный корень |
| `АВТОНОМЕРЗАПИСИ()` | Автоматический номер строки в результате |
| `РАЗМЕРХРАНИМЫХДАННЫХ(<поле>)` | Размер хранимых данных поля в байтах |
| `СГРУППИРОВАНОПО(<поле>)` | ИСТИНА, если строка получена группировкой по этому полю (для группирующих наборов) |

## Арифметические операторы

`+`, `-`, `*`, `/` — обычная арифметика. Точность: не менее 8 знаков после запятой.

**В ГДЕ:** используй только в дополнительных условиях: в основном условии арифметика мешает использованию индекса.

## Константы и литералы

| Тип | Синтаксис | Пример |
|------|--------|---------|
| Булево | `ИСТИНА` / `ЛОЖЬ` | `ГДЕ Проведен = ИСТИНА` |
| Число | Десятичный литерал | `1000`, `3.14` |
| Строка | Двойные кавычки | `"Текст"` |
| Строка с кавычками | Экранировать `"` удвоением | `"Компания ""Рога и Копыта"""` |
| Дата | `ДАТАВРЕМЯ(<Г>, <М>, <Д> [, <Ч>, <Мин>, <С>])` | `ДАТАВРЕМЯ(2024, 1, 15)` |
| NULL | `NULL` | `ЕСТЬNULL(X, 0)` |
| Неопределено | `НЕОПРЕДЕЛЕНО` | |
| Перечисление и предопределённое | `ЗНАЧЕНИЕ(...)` | `ЗНАЧЕНИЕ(Перечисление.Типы.Оптовая)` |
| Пустая ссылка | `ЗНАЧЕНИЕ(Справочник.X.ПустаяСсылка)` | |

**Параметры:** `&Имя` — внешние значения, передаваемые в запрос. Всегда предпочитай параметры склеиванию строк.
