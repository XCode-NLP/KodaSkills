## ВЫБОР

Условное выражение — аналог CASE в SQL.

```
ВЫБОР
    КОГДА <условие1> ТОГДА <результат1>
    КОГДА <условие2> ТОГДА <результат2>
    ИНАЧЕ <значение_по_умолчанию>
КОНЕЦ
```

Может использоваться в списке полей, в ИМЕЮЩИЕ и в ИТОГИ. **Нельзя** использовать как часть индексируемого (основного) условия ГДЕ.

Пример:

```
ВЫБРАТЬ
    Наименование,
    ВЫБОР
        КОГДА Сумма > 100000 ТОГДА "Крупный"
        КОГДА Сумма > 10000 ТОГДА "Средний"
        ИНАЧЕ "Мелкий"
    КОНЕЦ КАК Категория
ИЗ Документ.РеализацияТоваровУслуг
```

## ОБЪЕДИНИТЬ

Объединяет результаты двух и более запросов в один набор строк.

```
ВЫБРАТЬ Поле1, Поле2 ИЗ Таблица1
ОБЪЕДИНИТЬ [ВСЕ]
ВЫБРАТЬ Поле1, Поле2 ИЗ Таблица2
```

**Правила:**

- `ОБЪЕДИНИТЬ` убирает дубликаты (как UNION);
- `ОБЪЕДИНИТЬ ВСЕ` оставляет дубликаты (как UNION ALL, быстрее);
- число колонок должно совпадать во всех запросах;
- имена и типы колонок берутся из **первого** запроса;
- если структуры вложенных таблиц различаются, используй `ПУСТАЯТАБЛИЦА` в запросе, где вложенной таблицы нет.

## УПОРЯДОЧИТЬ ПО

```
УПОРЯДОЧИТЬ ПО <поле_или_псевдоним> [ВОЗР | УБЫВ] [, ...]
```

- `ВОЗР` — по возрастанию (по умолчанию);
- `УБЫВ` — по убыванию;
- можно ссылаться на псевдонимы полей из списка выборки;
- можно использовать результаты агрегатных функций при группировке;
- **не используй агрегатные функции напрямую** для сравнения в УПОРЯДОЧИТЬ ПО.

Пример:

```
ВЫБРАТЬ Контрагент, СУММА(Сумма) КАК Итого
ИЗ Документ.РеализацияТоваровУслуг
СГРУППИРОВАТЬ ПО Контрагент
УПОРЯДОЧИТЬ ПО Итого УБЫВ
```

## АВТОУПОРЯДОЧИВАНИЕ

Добавляет автоматический порядок по представлению (человекочитаемому имени) ссылочных полей. Ставится после УПОРЯДОЧИТЬ ПО или отдельно.

```
ВЫБРАТЬ Контрагент, Сумма
ИЗ Документ.РеализацияТоваровУслуг
АВТОУПОРЯДОЧИВАНИЕ
```

Нужно редко: явное `УПОРЯДОЧИТЬ ПО` предпочтительнее ради предсказуемого результата.

## ИТОГИ

Вычисляет строки промежуточных итогов и чередует их со строками детализации.

```
ИТОГИ
    [<агрегатное_выражение> [КАК <Псевдоним>] [, ...]]
ПО
    [ОБЩИЕ]
    [, <точка_контроля> [, ...]]
```

**Составляющие:**

- `ОБЩИЕ` — общий итог по всему результату;
- точки контроля — поля, по которым считаются промежуточные итоги; могут быть иерархическими;
- `ПЕРИОДАМИ(<Период>, <ДатаНачала>, <ДатаОкончания>)` — для полей типа даты; `<Период>` — одно из: `СЕКУНДА`, `МИНУТА`, `ЧАС`, `ДЕНЬ`, `НЕДЕЛЯ`, `МЕСЯЦ`, `КВАРТАЛ`, `ГОД`, `ДЕКАДА`, `ПОЛУГОДИЕ`.

Пример:

```
ВЫБРАТЬ
    Контрагент, Номенклатура, Количество, Сумма
ИЗ Документ.РеализацияТоваровУслуг.Товары
ИТОГИ СУММА(Количество), СУММА(Сумма)
ПО ОБЩИЕ, Контрагент
```

**Итоги периодических регистров:** включай (`РАЗРЕШИТЬ ИТОГИ`), только когда объём данных велик, в запросах среза нет даты и RLS простая.

## Группирующие наборы

Несколько группировок за один проход ради производительности.

```
СГРУППИРОВАТЬ ПО ГРУППИРУЮЩИМ НАБОРАМ
    (
        (НаборПолей1),
        (НаборПолей2)
    )
```

Порядок полей внутри набора и порядок наборов важны. Функция `СГРУППИРОВАНОПО(<поле>)` показывает, какой набор дал строку.

Пример:

```
ВЫБРАТЬ Контрагент, Номенклатура, СУММА(Сумма) КАК Итого
ИЗ Документ.РеализацияТоваровУслуг.Товары
СГРУППИРОВАТЬ ПО ГРУППИРУЮЩИМ НАБОРАМ
    (
        (Контрагент),
        (Номенклатура),
        (Контрагент, Номенклатура)
    )
```

## ПОДОБНО

Оператор сопоставления строк с шаблоном.

```
ГДЕ Наименование ПОДОБНО "Шаблон"
```

**Символы шаблона:**

| Символ | Значение | Пример |
|-----------|---------|---------|
| `%` | Любая строка (0 и более символов) | `"%молоко%"` — содержит «молоко» |
| `_` | Ровно один символ | `"__-__"` — совпадёт с «12-34» |
| `[abc]` | Один символ из набора | `"[АБВ]%"` — начинается с А, Б или В |
| `[^abc]` | Один символ НЕ из набора | `"[^0-9]%"` — начинается не с цифры |
| `[a-z]` | Один символ из диапазона | `"[А-Я]%"` — начинается с заглавной кириллицы |

**Символ экранирования:** используй `СПЕЦСИМВОЛ`, чтобы экранировать символы шаблона:

```
ГДЕ Код ПОДОБНО "%#_%" СПЕЦСИМВОЛ "#"
// совпадёт с буквальным подчёркиванием в Код
```

**Производительность:** шаблон НЕ должен начинаться с `%` или `_`, если он используется в индексируемом (основном) условии: такие шаблоны мешают использованию индекса.

## ССЫЛКА

Проверяет, указывает ли значение ссылочного типа на конкретную таблицу. Применяется с полями составного типа.

```
ГДЕ Регистратор ССЫЛКА Документ.РеализацияТоваровУслуг
```

Часто используется вместе с `ВЫРАЗИТЬ`:

```
ВЫБРАТЬ
    ВЫБОР
        КОГДА Регистратор ССЫЛКА Документ.Реализация
            ТОГДА ВЫРАЗИТЬ(Регистратор КАК Документ.Реализация).Контрагент
        КОГДА Регистратор ССЫЛКА Документ.Поступление
            ТОГДА ВЫРАЗИТЬ(Регистратор КАК Документ.Поступление).Контрагент
    КОНЕЦ КАК Контрагент
ИЗ РегистрНакопления.ОстаткиТоваров
```

## Подзапросы в В

Проверка вхождения в результат подзапроса:

```
ГДЕ Контрагент В (
    ВЫБРАТЬ Ссылка ИЗ Справочник.Контрагенты ГДЕ Город = &Город
)
```

**Правила:**

- подзапрос должен возвращать ровно одну колонку;
- избегай сложных подзапросов (соединения, обращение к составному типу, вложенные подзапросы) — используй временные таблицы;
- для больших наборов фильтров временная таблица с `В (ВЫБРАТЬ ... ИЗ ВТ)` эффективнее литерального списка.

## ПУСТАЯТАБЛИЦА

Используется в ОБЪЕДИНИТЬ, когда у одного запроса есть вложенная таблица (табличная часть), а у другого нет.

```
// В запросе 1 есть вложенная таблица Товары
ВЫБРАТЬ Ссылка, Товары.(Номенклатура, Количество)
ИЗ Документ.РеализацияТоваровУслуг

ОБЪЕДИНИТЬ ВСЕ

// В запросе 2 её нет — подставь совпадающую пустую таблицу
ВЫБРАТЬ Ссылка, ПУСТАЯТАБЛИЦА.(Номенклатура, Количество)
ИЗ Документ.ВозвратТоваров
```

Имена псевдонимов внутри `ПУСТАЯТАБЛИЦА.(...)` должны совпадать с псевдонимами соответствующей реальной вложенной таблицы из другого запроса.
