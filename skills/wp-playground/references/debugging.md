## Отладка WordPress Playground

- Запусти CLI с Xdebug: `server --auto-mount --xdebug`. CLI выведет хост, порт и ключ
  IDE для настройки отладчика; если справка установленного CLI отличается, следуй
  `npx @wp-playground/cli@latest server --help`.
- Если точки останова не срабатывают, проверь:
  - слушает ли IDE порт, который вывел CLI;
  - включены ли в отображение путей пути виртуальной файловой системы, которые
    использует Playground.
- Если запуск медленный или зависает:
  - добавь `--verbosity=debug`, чтобы видеть журналы уровня шагов;
  - используй `--debug`, чтобы вывести журнал ошибок PHP при сбое загрузки;
  - настрой число воркеров запросов через `--workers=<n|auto>`; используй
    `--workers=1`, чтобы изолировать поведение, связанное с воркерами.
- Если проблемы с примонтированными путями:
  - предпочитай абсолютные пути в `--mount`;
  - используй `--mount-before-install`, когда файлы нужны шагам установщика раньше.
- Чтобы посмотреть состояние среды выполнения:
  - открой консоль браузера Playground: Service Worker пишет события сети и файловой
    системы;
  - используй вкладку «Terminal» (если доступна), чтобы запустить WP-CLI внутри
    экземпляра.
