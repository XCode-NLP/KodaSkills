# Нацеливание в сети сайтов

Используй этот файл всякий раз, когда работа может идти в сети сайтов.

## Ключевые флаги

- `--url=<адрес-сайта>` нацеливает на конкретный сайт или блог;
- `--network` применяется ко всей сети, где это поддерживается.

## Частые команды

- список сайтов:
  - `wp site list`;
- опции конкретного сайта:
  - `wp option get siteurl --url=<адрес-сайта>`.

## Ограничения

- всегда указывай `--url`, когда имеешь в виду «один сайт» в сети;
- если нужно выполнить что-то по всем сайтам, предпочитай скрипт:
  - получить список сайтов → перебрать → выполнить безопасную команду для каждого.
