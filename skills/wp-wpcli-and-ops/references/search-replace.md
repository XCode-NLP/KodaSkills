# Безопасный `wp search-replace`

Используй этот файл при переносе доменов, переключении с http на https и смене
путей.

## Рекомендуемый порядок работы

1. Резервная копия:
   - `wp db export`.
2. Пробный запуск:
   - `wp search-replace OLD NEW --dry-run`.
3. Настоящий запуск (аккуратно выбери область):
   - рассмотри `--all-tables-with-prefix`, если нужно включить таблицы с префиксом
     WP, не относящиеся к ядру.
4. Сброс:
   - `wp cache flush`;
   - `wp rewrite flush`.

## Замечания о сети сайтов

Для сети сайтов реши, что именно заменяешь:

- один сайт (`--url=...`), или
- всю сеть (`--network` либо перебор через `wp site list`).

Прочитай:

- `multisite.md`

## Частые флаги

- `--dry-run`;
- `--precise` (медленнее, но может быть безопаснее в сложных случаях);
- `--skip-columns=...` (не трогать большие и двоичные столбцы);
- `--report-changed-only`.

## Осторожность с сериализацией

`search-replace` в WP-CLI умеет обрабатывать сериализованные данные PHP, но всё
равно нужно:

- не заменять внутри двоичных столбцов и столбцов типа blob;
- проверять результат дымовыми тестами приложения.
