# Автоматизация с WP-CLI

Используй этот файл, когда превращаешь последовательность операций в повторяемый
скрипт или задание CI.

## `wp-cli.yml`

Если в репозитории есть `wp-cli.yml`, используй его для единообразия:

- `path:` (корень WordPress);
- `url:` (сайт по умолчанию);
- настройки PHP (ограничения памяти).

## Скрипты оболочки

Ограничения для скриптов:

- `set -euo pipefail`;
- печатай команды перед запуском;
- разрушительные операции должны требовать явного флага (например, `--apply`).

## Задания CI

Предпочитай задания CI, которые по умолчанию только читают:

- `wp core version`;
- `wp plugin list`;
- `wp theme list`.

Записывающие операции включай только в отдельных сценариях развёртывания и
обслуживания.
