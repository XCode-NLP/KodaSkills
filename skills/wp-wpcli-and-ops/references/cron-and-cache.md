# Cron, кэш и правила перезаписи

Используй этот файл при отладке фоновых задач и ситуации «изменения не видны».

## Cron

- список запланированных событий:
  - `wp cron event list`;
- запуск конкретного события сейчас:
  - `wp cron event run <hook>`.

## Кэш и правила перезаписи

- сброс объектного кэша:
  - `wp cache flush`;
- сброс правил перезаписи:
  - `wp rewrite flush`.

## Ограничения

- не запускай «все события cron» в рабочей среде, не понимая последствий;
- сброс кэша может вызвать всплеск нагрузки, при необходимости согласуй его.
