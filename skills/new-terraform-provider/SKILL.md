Чтобы создать каркас нового провайдера Terraform на Plugin Framework:

1. Если ты уже в рабочей области провайдера Terraform, подтверди, что хочешь создать новую рабочую область. Если новую рабочую область создавать не нужно, пропусти все оставшиеся шаги.
2. Создай корневую директорию новой рабочей области. Имя корневой директории должно начинаться с «terraform-provider-». Все последующие шаги выполняй в этой новой рабочей области.
3. Инициализируй новый Go-модуль.
4. Выполни `go get -u github.com/hashicorp/terraform-plugin-framework@latest`.
5. Напиши файл main.go по [примеру](assets/main.go).
6. Напиши файл `internal/provider/provider.go` по [примеру](assets/provider.go). Переименуй провайдер `demo`, переменные окружения `DEMO_*` и атрибуты аутентификации так, чтобы они соответствовали целевому API.
7. Удали комментарии TODO из `main.go` и `provider.go`.
8. Выполни `go mod tidy`.
9. Выполни `go build -o /dev/null`.
10. Выполни `go test ./...`.

Каркас получает учётные данные из явной конфигурации с откатом на переменные окружения. Чтобы вырастить из этого полную цепочку источников учётных данных (общие файлы учётных данных, профили, удостоверение платформы, проверка на этапе настройки), используй навык `provider-configuration` (если доступен). Чтобы добавить первый ресурс или источник данных, используй навык `provider-resources` (если доступен).
